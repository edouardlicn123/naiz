# PC-98 Memory Switches（内存开关）

> **来源**: http://radioc.web.fc2.com/column/pc98bas/pc98memsw_en.htm
> **用途**: N88-BASIC(86) 和启动配置参数

---

## 概述

PC-98 有两类配置开关：
- **DIP 开关**（硬件开关或系统设置菜单）
- **内存开关**（存储在易失性内存中，需电池维持）

内存开关存储在 NVRAM 中，电池耗尽或 CMOS 清除后数据丢失。设置方法：

1. **Disk BASIC**: 启动 N88-BASIC(86)，运行 `run "switch.n88"`
2. **MS-DOS**: 使用 `SWITCH` 命令
3. **监视器模式**: N88-BASIC(86) 中输入 `mon`，使用 `ssw` 命令

默认值: `48-05-04-00-01-00`

## SW1 — 串行通信参数

**地址**: N88BASIC — A3FE2h / Hires — E3FE2h

| Bit | 功能 | 值 | 含义 |
|-----|------|----|------|
| 7,6 | 停止位长度 | 11=2bit, 10=1.5bit, 01=1bit, 00=0.5bit |
| 5 | 奇偶校验方式 | 1=偶校验, 0=奇校验 |
| 4 | 奇偶校验启用 | 1=启用, 0=禁用 |
| 3,2 | 数据位长度 | 11=8bit, 10=7bit, 01=6bit, 00=5bit |
| 1 | 通信方式（终端模式） | 1=半双工, 0=全双工 |
| 0 | X 参数（XON/XOFF 流控） | 1=启用, 0=禁用 |

## SW2 — 串行发送参数

**地址**: N88BASIC — A3FE6h / Hires — E3FE6h

| Bit | 功能 | 值 | 含义 |
|-----|------|----|------|
| 7 | S 参数 (SI/SO 切换 ANK 库) | 1=启用, 0=禁用 |
| 6 | 发送换行码 | 1=CR+LF, 0=CR |
| 5 | 接收换行操作 | 1=CR+LF→CR+LF, CR→CR+LF; 0=CR→CR |
| 4 | 汉字 Shift 码 | 1=KI:1A70h KO:1A71h; 0=KI:1B4Bh KO:1B48h |
| 3-0 | 传输速率 | 1001=19200, 1000=9600, 0111=4800, 0110=2400, 0101=1200, 0100=600, 0011=300, 0010=150, 0001=75 |

## SW3 — 系统参数

**地址**: N88BASIC — A3FEAh / Hires — E3FEAh

| Bit | 功能 | 值 | 含义 |
|-----|------|----|------|
| 7 | DEL 码操作（编辑器模式） | 1=NUL, 0=DEL |
| 7 | DEL 码操作（终端模式） | 1=NUL, 0=BS |
| 6 | 文本色 | 1=绿, 0=白 |
| 5 | V30 协处理器时钟 | 1=8MHz, 0=5/10MHz |
| 4 | V30 协处理器 | 1=使用, 0=不使用 |
| 3 | 8086/286/386 协处理器 | 1=使用, 0=不使用 |
| 2-0 | 常规内存大小 | 101=768KB(仅高分辨率模式), 100=640KB, 011=512KB, 010=384KB, 001=256KB, 000=128KB |

## SW4 — 扩展 ROM 启用

**地址**: N88BASIC — A3FEEh / Hires — E3FEEh

| Bit | 地址范围 | 设备 |
|-----|----------|------|
| 7 | CE000h–CFFFFh | 扩展 ROM |
| 6 | CA000h–CBFFFh | 扩展 ROM |
| 5 | D4000h–D5FFFh | GP-IB 板 BIOS |
| 4 | D0000h–D3FFFh | RS-232C 扩展板 BIOS |
| 3 | CC000h–CFFFFh | 声卡 BIOS (PC-9801-26) |
| 2 | C8000h–C9FFFh | 扩展 ROM |
| 1,0 | — | 保留（始终 0） |

## SW5 — 启动与硬件配置

**地址**: N88BASIC — A3FF2h / Hires — E3FF2h

| Bit | 功能 | 值 | 含义 |
|-----|------|----|------|
| 7-4 | 引导设备选择 | 1100=SCSI HDD #1, 1011=HDD #2, 1010=HDD #1, 1000=ROM BASIC, 0110=MO, 0100=1MB FDD, 0010=640KB FDD, 0000=默认, 其他=ROM BASIC |
| 3 | 硬件屏幕复制颜色 | 1=彩色, 0=单色 |
| 2 | 使用 HDD 用户 ID | 1=启用, 0=禁用 |
| 1 | 先分配 HDD 设备名 | 1=启用, 0=禁用 |
| 0 | PC-PR201 系列打印机 | 1=启用, 0=禁用 |

## SW6 — 杂项

**地址**: N88BASIC — A3FF6h

| Bit | 功能 | 值 | 含义 |
|-----|------|----|------|
| 5 | 调制解调器 NCU 控制 | 1=启用, 0=禁用 |
| 4 | 扩展屏幕复制 | 1=启用, 0=禁用 |
| 3 | 监视器模式 | 1=启用, 0=禁用 |
| 2-0 | 保留 | — | 始终 0 |
