## 对 Naiz 最有价值的部分

1. **Part 4-3 I/O 映射** (~85624–88700)：完整 I/O 端口寄存器级参考
2. **Part 2-7 图形 GDC** (~18224–20575)：GDC 命令集、VRAM 布局、GRCG/EGC 编程
3. **Part 2-6 文本显示** (~16387–18266)：文本 VRAM 格式、CG 访问
4. **Part 4-1 GRCG/EGC** (~2918)：硬件加速器完整细节
5. **Part 2-10 RS-232C** (~56836–58486)：串口 BIOS + 直接 8251 编程
