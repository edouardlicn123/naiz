## I/O 端口总览（PC-9801VX 硬件手册参考）

| 地址范围 | 设备（偶地址） | 设备（奇地址） |
|----------|---------------|---------------|
| 000–007h | 中断控制器 Master (8259) | DMA 控制器 (8237) |
| 008–00Fh | 中断控制器 Slave (8259) | — |
| 020–02Fh | 日历时钟 (1990,4990) | DMA Bank (8237) |
| 030–03Fh | **RS-232C** (8251) | **系统端口** (8255) |
| 040–04Fh | **打印机** (8255) | **键盘** (8251) |
| 050–05Fh | NMI | 320KB FDD (8255) |
| 060–06Fh | **GDC 文本** (7220) | 保留 |
| 070–07Fh | **CRTC 行/滚动控制器** (52611) | **定时器** (8253) |
| 080–08Fh | 硬盘接口 | 保留 |
| 090–097h | 1MB FDD (765) | CMT (8251) |
| 0A0–0AFh | **GDC 图形** (7220) | **字符 ROM** |
| 188–18Fh | 声音板 (YM2203) | — |
| 1A0–1AFh | EGC 扩展地址 | 保留 |

**I/O 地址镜像**：000–0FFh 实际硬件地址在 0xx–3xx 范围镜像多次。

## 关键 I/O 端口速查

### 系统端口 (30h/32h) — 8255A

| 端口 | 读 | 写 |
|------|-----|-----|
| 31h (A=0) | DIP SW 读（SW1–SW8, 反相） | — |
| 33h (A=1) | 状态读（!CI, !CS, !CD, INT3, CRT type, EM CK, RTC） | — |
| 33h (A=1) | — | 控制字：TXEE/RXRE/TXRE/BUZ/MMCKE/!PSTBE |

### RS-232C (30h/32h) — 8251A

| A0 | 读 | 写 |
|----|-----|-----|
| 0 | 数据读 | 数据写 |
| 1 | 状态读（DSR, SYNDET, FE, OE, PE, TxE, RxRDY, TxRDY） | 模式/命令写 |

### 键盘 (41h/43h) — 8251A

| A0 | 读 | 写 |
|----|-----|-----|
| 0 | 数据读（make/break code） | 数据写（命令） |
| 1 | 状态读（FE, OE, PE, -, RxRDY, -） | 模式/命令写 |

波特率：19200bps 固定，8bit，1 stop bit，奇校验。

### GDC 文本 (60h–6Fh)

| 地址 | A2/A1/A0 | 读 | 写 |
|------|----------|-----|-----|
| 60h | 000 | 状态读 | 参数写 |
| 62h | 001 | 数据读 | 命令写 |
| 64h | 010 | — | VSYNC 触发 |
| 68h | 100 | 模式 F/F 状态1（部分模型） | **模式 F/F 设置1** |
| 6Ah | 101 | 模式 F/F 状态2（部分模型） | **模式 F/F 设置2** |
| 6Ch | 110 | — | **边框颜色** |
| 6Eh | 111 | 显示状态 | **显示控制** |

### GDC 图形 (A0h–AFh)

| 地址 | A2/A1/A0 | 读 | 写 |
|------|----------|-----|-----|
| A0h | 000 | 状态读 | 参数写 |
| A2h | 001 | 数据读 | 命令写 |
| A4h | 100 | 显示页面选择（部分模型） | **显示页面/GRCG 模式**（hires） |
| A6h | 101 | 绘制页面选择（部分模型） | **绘制页面/GRCG Tile**（hires） |
| A8h–AEh | — | 调色板读/写 | 调色板设置 |

### CRTC (70h–7Ah)

| 地址 | 写功能 |
|------|--------|
| 70h | 字符位置行数 (PL) |
| 72h | Body 面行数 (BL) |
| 74h | 字符行数 (CL) |
| 76h | 平滑滚动行数 (SSL) |
| 78h | 滚动区域上边界行数 (SUR) |
| 7Ah | 滚动区域行数 (SDR) |

### 定时器 (71h/75h/77h) — 8253

| 地址 | 功能 |
|------|------|
| 71h | Counter 0（系统定时器） |
| 75h | Counter 1（定时器 1） |
| 77h | Counter 2（扬声器） |
| 77h (mode) | 8253 模式控制 |

### GRCG (7Ch/7Eh / A4h/A6h)

**Normal 模式**：
| 端口 | 写功能 |
|------|--------|
| 7Ch | GRCG 模式寄存器（bit7=CGmode, bit6=RMWmode, bit3–0=plane enable） |
| 7Eh | GRCG Tile 寄存器（写入 4 次，自动递增计数器） |

**Hires 模式**：
| 端口 | 写功能 |
|------|--------|
| A4h | GRCG 模式寄存器（同上 + bit5–4 平面选择） |
| A6h | GRCG Tile 寄存器 |

### EGC (4A0h–4AEh) — 仅 Word 访问

| 端口 | 写功能 |
|------|--------|
| 4A0h | EGC 寄存器1：平面启用 (P0EN#–P7EN#) |
| 4A2h | EGC 寄存器2：FGC/BGC 选择、模式平面 |
| 4A4h | EGC 寄存器3：ROP 代码、移位/模式选择 |
| 4A6h | EGC 寄存器4：Foreground 颜色 |
| 4A8h | EGC 寄存器5：Mask 寄存器 |
| 4AAh | EGC 寄存器6：Background 颜色 |
| 4ACh | EGC 寄存器7：位移位方向/地址 |
| 4AEh | EGC 寄存器8：位计数 |

### 声音卡 (188h/18Fh)

| 端口 | 功能 |
|------|------|
| 188h | YM2203（OPN）数据/地址，或 PC-9801-26K 声音板 |
| 18Fh | YM2203 状态，或 PC-9801-86 声音板 |

### 其他

| 端口 | 功能 |
|------|------|
| 00F0h | **Shutdown**（286+ 保护→实模式切换） |
| 0035h bit7 | NMI 屏蔽 |
| 005Fh | NMI 触发/清除 |
| 031h bit7 | GDC 时钟选择（1=5MHz, 0=2.5MHz） |
| 0810h–081Fh | 软件 DIP 开关（部分模型） |

### 扩展 I/O 端口（非 0xx 镜像范围）

| 端口 | 功能 | 芯片/设备 |
|------|------|-----------|
| 188h–18Fh | 声音板 (YM2203) | PC-9801-26K |
| 1A0h–1AFh | EGC 扩展地址 | EGC 寄存器 |
| 288h–28Fh | 86 声音板 (YM2608) 备用地址 | PC-9801-86 |
| 3FCh–3FFh | 蜂鸣器频率 (8253 Counter 2, 镜像) | 8253 |
| 7FD9h | 鼠标状态 (按钮 + X/Y 移动量) | 鼠标接口 (8255) |
| 7FDBh | 鼠标模式端口 B (DIP 开关) | 鼠标 |
| 7FDDh | 鼠标模式端口 C (HC/SX/SH/IN) | 鼠标 |
| 9A0h | 读取端口设置 | 扩展显示 |
| 9A8h | 显示时钟设置 | 扩展显示 |
| BFD8h–BFDBh | 鼠标中断轮询时间 | 鼠标 |
| 3FDAh–3FDBh | 蜂鸣器频率 (8253, 镜像) | 8253 |
