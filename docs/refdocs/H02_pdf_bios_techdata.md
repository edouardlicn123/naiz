## 关键 BIOS 功能示例

### 键盘 BIOS (INT 18h)

| AH | 功能 | 说明 |
|----|------|------|
| 00h | 键盘数据读 | 从环形缓冲区读取键码 |
| 01h | 键盘状态缓存 | 不删除缓冲区的状态读取 |
| 02h | 移位键状态 | 获取 Shift/Ctrl/Grph 等状态 |
| 03h | 键盘模式设置 | 设置重复率、LED 等 |
| 06h | 缓冲区内容设置 | 向缓冲区写入键码 |
| 0Ah | 光标位置写 | 设置文本光标位置 |
| 0Fh–11h | 显示控制 | 字体、滚动、模式设置 |

### CRT BIOS (INT 18h)

| AH | 功能 | 说明 |
|----|------|------|
| 0Ah | 光标位置写 | |
| 10h–12h | 显示模式控制 | |
| 1Ch | GDC 控制 | |
| 1Eh | 光标格式设置 | CSRFORM |
| 1Fh–20h | 字体模式读/注册 | 24 点阵字体 |
| 23h | 蜂鸣器音调设置 | |
| 24h | 蜂鸣器持续设置 | |

### 磁盘 BIOS (INT 1Bh)

| AH | 功能 | 说明 |
|----|------|------|
| 06h | READDATA | 读扇区 |
| 07h | WRITEDATA | 写扇区 |
| 08h | READDIAG | 诊断读 |
| 09h | WRITEDIAG | 诊断写 |
| 0Ah | SEEK | 寻道 |
| 0Bh | READID | 读 ID |

## 对 Naiz 的实用价值

- 直接相关：**键盘 (INT 18h)**、**CRT (INT 18h)**、**磁盘 (INT 1Bh)**、**定时器 (INT 1Ch)**、**图形 (INT 1Dh)** BIOS
- OCR 严重影响可用性，函数名称和寄存器值幸存
- Naiz 引擎使用**直接端口 I/O** 而非 BIOS，但仍可作为参考对照
