# AT 互換機 → PC-98 移植ガイド

> **来源**: 多个 PC-98 移植文档汇编
> **原文**: ハードウェア・ソフトウェア両面の差異

---

## 1. CPU 差异

| 项目 | AT (IBM-PC) | PC-98 |
|------|-------------|-------|
| CPU | 8086/286/386/486+ | 8086/286/386/486+ (同一系列) |
| 初始模式 | 实模式 | 实模式 |
| 保护模式 | 标准 | 标准 |
| CPU I/O | x86 I/O space | 同一, 但端口映射不同 |

## 2. BIOS 差异

### INT 入口

| 中断 | AT | PC-98 | 备注 |
|------|----|-------|------|
| INT 10h | VGA BIOS 图形 | — | PC-98 无 |
| INT 13h | 磁盘 I/O | — | PC-98 用 INT 1Bh |
| INT 16h | 键盘输入 | — | PC-98 用 INT 18h AH=00h |
| INT 18h | ROM BASIC | **BIOS 入口** | PC-98 的主 BIOS 入口 |
| INT 1Bh | — | 磁盘 I/O | PC-98 磁盘功能 |
| INT 21h | DOS 功能 | DOS 功能 | 兼容 (文件系统) |
| INT 33h | Microsoft Mouse | Microsoft Mouse | 兼容 |
| INT 67h | EMS | EMS | 兼容 |

### BIOS 数据区

| 项目 | AT | PC-98 |
|------|----|-------|
| 配置数据 | 0040:0000 | 0050:0000 |
| 键盘缓冲 | 0040:001A | 0000:0502 |
| 磁盘参数 | 0040:00xx | 0150:0000 |
| 系统状态 | 0040:00xx | 0052:0000 |
| 定时器 tick | 0040:006C | 005A:001C |

## 3. 硬件差异

### 显示系统

| 项目 | AT (VGA) | PC-98 |
|------|----------|-------|
| 文本模式 | B800:0000 文字+属性 | A000:0000 文字+ A200:0000 属性 |
| 图形模式 | A000:0000 (Packed) | 4平面, 各 32KB (A800/B000/B800/E000) |
| 显示控制 | 3C0-3DFh | 60-6Fh / A0-AFh + 68-6Ah 模式触发器 |
| 调色板 | 3C8/3C9h | A8/AA/AC/AEh |
| CRT 控制 | 3B4/3B5h | GDC 内藏 |
| 256色 | Packed Pixel | Bank 切换方式 (E000:0100) |

### 键盘

| 项目 | AT | PC-98 |
|------|----|-------|
| 接口 | 8042 控制器 | PD8251 串行 |
| 扫描码 | IBM 扫描码 set 1/2 | 独自配置 (8bit 位置码) |
| 缓冲 | 0040:001A | 0000:0502 |
| Shift状态 | 0040:0017 | 0000:0522 |

### 磁盘

| 项目 | AT | PC-98 |
|------|----|-------|
| 接口 | IDE/PATA, SATA | SASI/SCSI (早期), IDE (后期) |
| IPL | MBR (512B) | 独自 (1-8 sector) |
| 分区 | MBR + 拡張 | MBR 互换 (DOS) |
| 磁盘 I/O | INT 13h | INT 1Bh + 端口 (FDC: 3F0-3F7相当) |

### I/O 端口差异 (图形相关)

| AT 端口 | PC-98 端口 | 功能 |
|---------|-----------|------|
| 3C0h | 68h/A8h | 调色板/模式 |
| 3C2h | 6Ah | 模式触发器 2 |
| 3C4h | A0h/A2h | GDC 命令 |
| 3CEh | 7Ch/7Eh | GRCG 相当 |
| 3CFh | A4h/A6h | 页面选择 |

## 4. 内存布局

### 标准系统内存映射

| AT 地址 | PC-98 地址 | 用途 |
|---------|-----------|------|
| 0000:0000 | 0000:0000 | 中断向量表 |
| 0000:0400 | 0000:0500 | BIOS 数据区 |
| 0040:0000 | 0050:0000 | BIOS 数据 |
| B800:0000 | A000:0000 | 文本 VRAM |
| A000:0000 | A800:0000 | 图形 VRAM |
| C000:0000 | C000:0000 | Option ROM |
| F000:0000 | F000:0000 | BIOS ROM |

## 5. 移植要点

### 显示

1. **文本模式**: AT 用直接写入 B800:0000, PC-98 用 INT 18h AH=71h 或直接写入 A000:0000 (JIS 转换必要)
2. **图形模式**: AT 为 Packed Pixel, PC-98 为 4 平面
3. **调色板**: 端口地址和格式不同

### 键盘

1. 扫描码映射不同
2. PC-98 使用 RS-232C 8251 协议
3. 缓冲管理地址不同

### 定时器

1. PIT 端口地址相同 (40-43h)
2. 定时器中断 INT 08h (AT) / INT 08h (PC-98) - **相同**
3. 但 tick 计数器和 BIOS 函数不同

### 内存分配

1. DOS 程序的内存分配 (INT 21h AH=48h) 兼容
2. EMS/XMS 接口兼容
3. BIOS 数据区地址不同

## 6. 关键移植原则

1. **不要依赖 AT BIOS**: 所有 VGA BIOS (INT 10h) 调用需要替换
2. **键盘 I/O**: INT 16h → INT 18h AH=00h
3. **端口直接访问**: 几乎所有端口地址不同
4. **VRAM 布局**: 从 Packed Pixel 改为 4 平面
5. **文件系统**: 兼容 (DOS FAT)
