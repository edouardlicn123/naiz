## 硬件规格

| 参数 | 值 |
|------|-----|
| 接口 LSI | 主板：μPD8251A（USART），键盘：μPD8048（MCU） |
| 数据线 | 6 线：GND, +5V, Data, 3 Control lines |
| 传输方式 | 异步串行通信 |
| 波特率 | **19200 bps 固定** |
| 数据长度 | 8 bits |
| 起始位 | 1 |
| 停止位 | 1 |
| 奇偶校验 | 奇校验 (Odd) |
| 电平 | TTL |

## 连接器引脚

| 引脚 | 名称 | 功能 |
|------|------|------|
| 1 | !RST | 复位输出到键盘 |
| 2 | GND | 地 |
| 3 | !RDY | 数据就绪（RxRDY 反映） |
| 4 | RXD | 接收数据（键盘→主机） |
| 5 | !RTY | 重试请求（主机→键盘） |
| 6 | NC | 未连接 |
| 7 | NC | 未连接 |
| 8 | +5V | 电源 |

## I/O 端口

### 数据端口 (41h)

| 方向 | 功能 |
|------|------|
| 读 | Make 码（00–7Fh）或 Break 码（80–FFh），FAh=ACK, FCh=NACK |
| 写 | 命令发送 |

### 状态端口 (43h 读)

| Bit | 名称 | 说明 |
|-----|------|------|
| 7 | DSR | 键盘连接状态（1=HIGH, 0=LOW） |
| 6 | SYNC/BRK | Break 检测（1=break, 0=无） |
| 5 | FE | Framing Error |
| 4 | OE | Overrun Error |
| 3 | PE | Parity Error |
| 2 | TxE | 发送完成 |
| 1 | RxRDY | 数据可读（对应引脚 !RDY） |
| 0 | TxRDY | 可发送 |

### 命令端口 (43h 写)

模式设置（初始化时写入一次）：
```
bit7–6: 停止位  01b = 1 stop bit
bit5–4: 奇偶校验 01b = 奇校验
bit3–2: 字符长度 11b = 8 bits
bit1–0: 波特率系数 10b = ×16
→ 模式值 = 0101_1110b = 5Eh
```

命令格式：
| Bit | 名称 | 功能 |
|-----|------|------|
| 6 | IR | 8251A 内部复位 |
| 5 | RTS | 键盘发送禁用 |
| 4 | ER | 错误标志清除 |
| 3 | SBRX | !RST 线拉低 ⇔ 键盘复位 |
| 2 | RxE | 接收启用 |
| 1 | DTR | !RTY 线控制（1=HIGH, 0=LOW） |
| 0 | TxEN | 发送启用 |

## 数据协议

### Make/Break 码

- 键按下 → 主机从 41h 读取 Make 码（bit7=0, 00h–7Fh）
- 键释放 → 主机从 41h 读取 Break 码（bit7=1, 80h–FFh）
  - Break = Make + 80h
- 按住超过 0.5 秒 → 键盘交替发送 Break/Make 码（重复）
- 键码顺序未定义（不同时按多个键时不保证顺序）

### 读数据流程

```
1. 读 43h, 检查 bit1 (RxRDY)
2. 如果 RxRDY=0 → 返回无数据
3. 如果 RxRDY=1 → 读 41h
4. 检查是否错误 (FE/OE/PE)
5. 如果 bit7=0 → Make 码 (键按下)
6. 如果 bit7=1 → Break 码 (键释放，码 & 7Fh 即为键号)
```

## 键盘命令

| 命令 | 功能 |
|------|------|
| 95h | 设置翻译键（新键盘，2 字节参数） |
| 96h | 模式查询（返回 A0h,86h 或 A0h,85h） |
| 99h | 未公开（返回 FBh） |
| 9Ch | 键盘重复速率设置（2 字节参数：delay + rate） |
| 9Dh | 键盘 LED 读取/设置（2 字节参数） |
| 9Fh | 键盘类型查询（返回 A0h,80h = 新键盘） |

### 重复速率参数 (9Ch)

字节 2 格式：
```
bit6–5: 延迟
  11b = 1000ms
  10b = 500ms
  01b = 500ms (默认)
  00b = 250ms
bit4–0: 重复速率
  11111b = 最慢
  00001b = 最快 (默认)
```

### LED 设置 (9Dh)

字节 2 格式：
```
bit3: [漢] LED
bit2: [CAPS] LED
bit0: [NUM] LED
1=ON, 0=OFF
```

## 键盘类型

| 类型 | 适用机型 |
|------|----------|
| 旧键盘 | PC-9801 E/F 代以外（标准 98 键盘） |
| 新键盘 | 98NOTE 系列、PC-9801-98（薄型）、PC-9801-106（Windows 键盘） |

复位后通过 9Fh 命令查询键盘类型：返回 A0h,80h 为新键盘。

### 键盘布局

标准 PC-98 键盘布局基于日本工业标准（JIS），与美式布局差异较大：

```
┌───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┐
│Esc│ 1 │ 2 │ 3 │ 4 │ 5 │ 6 │ 7 │ 8 │ 9 │ 0 │ - │ ^ │ ¥ │
├───┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┤
│ Tab │ Q │ W │ E │ R │ T │ Y │ U │ I │ O │ P │ @ │ [ │  │
├─────┴┬──┴┬──┴┬──┴┬──┴┬──┴┬──┴┬──┴┬──┴┬──┴┬──┴┬──┴┬──┴┐ │
│ CAPS │ A │ S │ D │ F │ G │ H │ J │ K │ L │ ; │ : │ ] │ │
├──────┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴───┘ │
│ SHIFT  │ Z │ X │ C │ V │ B │ N │ M │ , │ . │ / │SHIFT │ │
├────┬───┴┬──┴──┬┴───┴───┴───┴───┴───┴───┴──┬┴───┼────┤ │
│CTRL│GRPH│ KANA│   SPACE (空白)            │ NFER│XFER│ │
└────┴────┴─────┴───────────────────────────┴─────┴────┘ │
```

- **GRPH** = Alt 键（Windows 下），N88-BASIC 中用于输入图形符号
- **KANA** = 假名锁定
- **NFER** = 无变换（确定）
- **XFER** = 变换（空格）
- **HOME/CLR** = Home / 清除画面
- **HELP** = End（Windows 下）
- **ROLL UP** = PageDown
- **ROLL DOWN** = PageUp
- **STOP** = Ctrl+Break
- **COPY** = PrintScreen
- **vf1–vf5** = 功能键 F11–F15（Windows 下为 GRPH+F1–F5）

### 键盘硬件演进

| 年份 | 特征 |
|------|------|
| 1982–1983 | 大 DIN 连接器（仅初代 PC-9801） |
| 1983–1985 | Mini DIN 连接器 |
| 1985–1988 | 添加 NFER 键 |
| 1988–1992 | 添加 vf1–vf5 键，瞬时 Shift 开关带 LED |
| 1992–1994 | 机械→橡胶 Dome 键开关，左上角 LED |
| 1994–1995 | 弯头插头→直插头 |
| 1995– | 添加 Win 和应用键 |

### 键盘复位流程

```
开机/复位
  ↓
主机通过 !RST 线拉低 4ms 复位键盘
  ↓
键盘 μPD8048 初始化
  ↓
主机写 43h: 模式指令 (5Eh = 1 stop, odd, 8bit, ×16)
  ↓
主机写 43h: 命令 (RxE=1, TxEN=1, ER=1, IR=0)
  ↓
键盘发送 FAh (ACK)
  ↓
主机读 41h 确认 FAh
  ↓
就绪
```

### 读数据流程

```
开始
  ↓
读状态端口 43h
  ↓
检查 bit1 (RxRDY=1?)
  ├── 否 → 返回"无数据"
  └── 是 → 读数据端口 41h
              ↓
             检查错误 (FE/OE/PE)
             ├── 有错 → 清除错误标志 (ER=1)
             │           ↓
             │          丢弃数据
             └── 无错 → bit7=0? (Make/Break)
                          ├── 是 → Make 码 (键按下)
                          └── 否 → Break 码 (键释放, &7Fh)
                                  ↓
                         返回键码
```

## INT 09h

键盘硬件中断 IRQ 1 → INT 09h。当 8251A 从键盘接收到 Make 码时触发。
中断处理程序读取 41h 获取键码，存入键盘缓冲区（默认 0000:0502h 开始）。

## 键盘缓冲区 (0000:0502h–053Ah)

Hires 模式下缓冲区地址可通过 0000:0410h 自定义。
缓冲区大小见 0000:0522h。默认 32 字节环形缓冲区。
