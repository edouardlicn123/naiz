## 三、常用检索命令

```bash
# 1) 符号 → 文件:行（一次到位，替代多轮 grep）
python -m tools.diag.code_map --find "vm_delay"

# 2) 按函数名读片段（不用手算 offset/limit）
python -m tools.diag.read_slice core/lib/mag.c --symbol mag_decode

# 3) 按小节读文档（长文不必整篇读）
python -m tools.diag.read_slice docs/B97-场景过渡状态机规范.md --section "## 三"

# 4) 审计摘要（只看 RESULT，明细在日志）
python -m tools.audit.audit --summary
```
