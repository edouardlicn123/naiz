### 1.1 源码归类矩阵（C / py / nb / sh）

| 类别 | 语言 | 位置 | 说明 |
|---|---|---|---|
| 硬件/驱动 | C | `core/plat/` | HAL + GDC/video/serial/kbd/mouse/vram；`outb`/`inb`/`int 018h` 仅限此处（§4） |
| 引擎执行 | C | `core/engine/` | VM/NB 解释、渲染、图层、转场、存档、菜单、设置 |
| 平台无关库 | C | `core/lib/` | `font`/`cjk`/`mag`/`naiz_file`/`tr`，不触硬件 |
| 引擎脚本工具链 | py | `tools/` | 构建、素材转换、镜像注入、诊断、审计、环境 |
| 引擎脚本内容 | nb | `games/<game>/*.nb` | 数据编排，非源码 |
| 构建胶水 | sh | 根目录 + `core/build.sh` | 流水线装配 |

> **例外登记**：`tools/diag_c/` 即「diag 的 C 落地」，是 `tools/` 下唯一 C 源码 — VRAM/GDC 硬件诊断独立工具（非引擎部件），经 `core/Makefile` 以 `-DHAL_BUILD_ALLOWED` 编译为 `diag.exe`；**有意保留在 tools/**，为内容归类正确、物理位置例外的唯一一处。

> **naiz-guildbook 更新约定**：每次修改手写 HTML 文件后，需将 `naiz-guildbook/` 下所有文件的修改时间更新为当前时间（`touch naiz-guildbook/*.html naiz-guildbook/pages/*.html naiz-guildbook/imgs/*.png`）。sidebar 链接和 index.html 卡片需保持一致。文档页在 `pages/`，图片在 `imgs/`，相对引用需带 `../` 前缀。

## 2. 构建与测试

### 2.1 命令职责

| 命令 | 职责 | 产出 |
|---|---|---|
| `makegame.sh build <game>` | 准备游戏数据（素材→MAG→IMAGE.DAT，场景编译，引擎编译，运行时部署） | `games/<game>/` |
| `makegame.sh make <game>` | 纯 HDI 打包注入 | `disks/<game>.hdi` |
| `start.sh commercial` | 下载并解压商用资源包到 `tools_commercial/`（下载点选择 + sha256 校验） | `tools_commercial/` |
| `anima.sh`（无参数） | 交互式动画制作菜单（选项目 → 操作菜单[check/register/生成动画] → 脚本子菜单 → build/build --sync，镜像 makegame.sh 工作流；含 init 新建项目入口） | — |
| `anima.sh init <项目>` | 创建动画项目骨架（config.toml + scripts/ + db/，name 必须与目录同名） | `animation/projects/<项目>/` |
| `anima.sh register <项目>` | 扫描 `assets/<项目>/anim/` 登记 png/pal 裸名字索引（前置：项目已 init） | `animation/projects/<项目>/db/<项目>.db` |
| `anima.sh check <项目>` | 只读双向对账素材登记库（未登记/失效行/待更新；有差异 exit 1，不写库，前置：已 register 过一次） | — |
| `anima.sh build <项目>/<脚本> [--sync]` | 动画脚本(.na) → .ANI 容器（制作侧，devdoc 78/79；共享色板按脚本项目名从 IMG/SPR 推导） | `animation/output/<NAME>.ANI` |
| `anima.sh buildall [--flags]` | 编译全部项目的全部脚本（失败聚合汇总，M>0 exit 1） | 同上 |
| `anima.sh list` | 列出可用动画脚本（`<项目>/<脚本>`） | — |

> **动画目录约定**（2026-08-24 项目化改造；同日 `.na` 分离修订）：每个动画项目一个目录 `animation/projects/<项目名>/{config.toml,scripts/,db/}`——config.toml 的 `[project] name` 与目录同名（项目判定依据，由 `tools.naiz_build.anim_project` 强校验）；动画脚本平铺单层放该项目 `scripts/<名>.na`。`.na` 后缀专属动画脚本、与剧本脚本 `.nb` 严格分离（解析器入口拒绝非 `.na`，引擎零改动），原 `naizbook/*.nb` 约定废止。产物在全局 `animation/output/`；帧素材放 `assets/<项目名>/anim/`（png/pal）与构建管线同址、不迁入。`.ANI` 为独立产物，不入 ASSETS.DB / IMAGE.DAT（播放接入另行实施）。注意注册进项目的 MAG 文件名需 ≤11 字符（IMAGE.DAT TOC 名字段宽度）。

`build` 一次性完成从源素材到可部署数据的全流程，`make` 不做任何数据加工。

### 2.2 引擎编译

```bash
make -C core               # 仅编译（也可由 build 自动调用）
```

编译器：Open Watcom v2.0 `wcl386 -bt=dos -l=dos4g`，生成 MZ stub + LE + DOS/4GW。
DOS/4GW.EXE v4.45（265KB）在 `tools_commercial/dos_system/`，版本不可替换。
> **输出文件名约定**：`make -C core` 产出 `engine.exe` / `engine_a.exe`，均为小写。
> `games/<game>/` 下的运行文件同用小写。FAT16 不区分大小写，无实际影响。

### 2.3 编译隔离

Makefile 按模块划分编译标志（阶段三已实施）：
| 模块 | 包含路径 | 额外标志 |
|------|----------|---------|
| engine/ | `-Iengine -Ilib -Iplat` | — |
| plat/ | `-Iplat -Ilib -Iengine` | `-DHAL_BUILD_ALLOWED` |
| lib/ | `-Ilib` | — |

`plat/*.h` 头文件包含 `#error` 守卫（由 `HAL_BUILD_ALLOWED` 放行），防止 engine/ 代码意外 include 平台内部头文件。

### 2.4 Python 单元测试（pytest）

```bash
tools/env_setup/venv/bin/python -m pytest tools/tests/
```

- 测试位于 `tools/tests/`（`pytest.ini` 配置 `pythonpath = tools`），覆盖 `naiz_lib` 平台无关模块
- 用例覆盖：MAG 编解码往返、调色板工具、IMAGE.DAT 归档、C/Python 常量镜像一致性
- 新增核心逻辑后应补充对应测试；venv 已安装 pytest（`tools/env_setup/venv/`）

### 2.6 运行时链

```
CONFIG.SYS → DEVICE=A:\VEM486.EXE /U → DOS=HIGH,UMB

    └─ LE body → 引擎主逻辑
```

## 3. 运行时约束

### 3.1 必须

- **32-bit 保护模式**（DOS/4GW 首选，VEM486 DPMI 备选）
- PC-98 平台（NP2kai IA32 核心，`pc_model='VM'` 或 `'VX'`）
- 内存管理器仅限 VEM486.EXE

### 3.2 禁止

| 方案 | 原因 |
|------|------|
| 16-bit 实模式 (gcc-ia16) | 非 32-bit |
| DJGPP + Go32/Pmode/W | CR0 PE 位切换，NP2kai 不支持 |
| DOS/32A, HX DOS Extender | 同上 |
| INSTALL= 启动 | 非标准 |
| HIMEM+EMM386 | 与 VEM486 冲突 |

## 4. 架构约束

### 4.1 HAL 边界

`core/engine/` 只能通过 `core/plat/hal.h` 访问硬件。`outb()`, `inb()`, `int 0x18` 等只能在 `core/plat/` 中调用。

HAL 接口（`core/plat/hal.h`）：
```c
void hal_init(void);                           // 平台初始化（串口等）
void hal_log(const char *s);                   // 调试输出
void hal_set_palette(int idx, uint8_t r, uint8_t g, uint8_t b);  // 调色板
void hal_read_palette(int idx, uint8_t *r, uint8_t *g, uint8_t *b); // 调色板读取
void hal_vblank_wait(void);                    // 垂直同步等待
void hal_kbd_init/update/is_pressed/is_down/...(); // 键盘 API
void hal_mouse_init/update/get_x/get_y/...();  // 鼠标 API
void hal_video_init/exit/check_palette();      // 视频 API
void hal_bgm_play/stop/sound_play/voice_play(); // 音频 stub
```
> **阶段三已实施**：编译隔离已启用（`-DHAL_BUILD_ALLOWED`）。`engine/` 代码禁止直接 include `plat/keyboard.h`、`plat/mouse.h`、`plat/video.h`，必须通过 `hal.h` 调用。
> 同时循环依赖已解除：`plat/mouse.c` 不再 include `engine/render.h`，光标绘制逻辑移至 `engine/cursor.c`。

PC-98 实现在 `core/plat/hal_pc98.c`（41 个函数，全部对应 hal.h 声明）。移植新平台需实现 hal.h 声明的全部接口。

### 4.2 平台无关库（core/lib/）

以下模块零平台依赖，可被任何 C 项目复用：

| 模块 | 文件 | 功能 |
|------|------|------|
| **endian** | `lib/endian.h` | LE 16/32-bit 内联读取 |
| **naiz_file** | `lib/naiz_file.c/h` | 文件读取辅助（file_read_all） |
| **mag** | `lib/mag.c/h` | MAKI02 图像解码 |
| **font** | `lib/font.c/h` | ASCII 8×16 字形加载 |
| **cjk** | `lib/cjk.c/h` | CJK 16×16 字形加载（可选日志回调） |
| **tr** | `lib/tr.c/h` | i18n 翻译表加载/查询 |

### 4.3 数据管线

详细管线见 `docs/B92-NB脚本命令参考.md`（数据格式）与 `docs/B04-工具链API参考.md`。引擎不直接解析 PNG/TTF 等原始格式。

### 4.4 refdocs/ 分类索引

PC-98 外部知识参考文档见 `docs/refdocs/README.md`（按 A–H 类分组：系统架构/内存I/O/显示/输入/存储/声音/编程参考/PDF摘要）。
