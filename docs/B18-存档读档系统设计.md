# B18 — 存档/读档系统设计

> **最后更新**：2026-09-11（R9/R19/R22 同步：文件归位 `nb_saveload.c`/`nb_save_dialog.c`/`save_io.c`/`save_sys.c`；§5 快照系统改复合缓冲模型；补槽位页级缓存；常量改 `LAYER_DIALOG_*`）

## 1. 概述

Naiz 引擎提供两套存档/读档 UI：

| 入口 | 触发 | 作用域 | 文件 |
|------|------|--------|------|
| F5 | `main.c` 主循环 | 对话框内保存（仅保存） | `nb_save_dialog.c` `save_dialog_menu()` |
| F6 | `main.c` 主循环 | 全屏读档菜单 | `loadscene.nb` → `cmd_loadscene()` → `save_load_menu(1, 0)` |
| 主菜单 "load" | `cmd_mainmenu()` | 全屏读档菜单 | `loadscene.nb` → `cmd_loadscene()` → `save_load_menu(1, 0)` |

两份菜单共享同一套保存文件系统；对话框文字清除/恢复走对话框复合缓冲（`layer_dialog_restore()` = re-blit 复合缓冲，R19 语义）。

### 文件索引

| 文件 | 职责 |
|------|------|
| `core/engine/nb_saveload.c` | 全屏菜单 `save_load_menu()`（static）、`cmd_loadscene()`（:400）、页级槽位缓存（R22） |
| `core/engine/nb_save_dialog.c` | 对话框内保存菜单 `save_dialog_menu()`（static）、槽位格子、confirm |
| `core/engine/save.c` | `SaveData` 采集/应用、`save_game_temp/slot`、`load_game_temp/slot`、`slot_info` |
| `core/engine/save_io.c` | 文件级 I/O（`save_file_write/read`）、`save_checksum`、`save_read_header()`（头部解析收口，R9） |
| `core/engine/save_sys.c` | `SystemSave` 系统存档（`sys_save_*`） |
| `core/engine/layer_dialog.c` | 对话框复合缓冲 `dialog_layer`/`dialog_occluder`、`layer_dialog_restore()`、`layer_dialog_render_page()` |
| `core/engine/nb_dialog.c` / `nb_dialog.h` | 正常对话推进中的对白状态（`nb_dialog_get_text` 等访问器） |
| `core/engine/nb_menu.c` | 菜单调色板保存/还原 |

## 2. 保存文件系统

### 2.1 文件布局

| 文件 | 路径 | 用途 |
|------|------|------|
| `SAVE00.SAV` ~ `SAVE11.SAV` | 当前目录 | 12 个固定槽位 |
| —（内存） | — | 临时存档由 `save_game_temp()` 保存在内存，不落盘 |
| `SYSTEM.SAV` | 当前目录 | 系统存档（CG/结局/场景解锁） |

### 2.2 数据结构

#### SaveData（`save.h` — 每个槽位的完整存档）

```c
typedef struct {
    unsigned int magic;              // SAVE_MAGIC (0x4E41495A "NAIZ")
    unsigned int version;            // SAVE_VERSION (3)
    char         slot_name[32];      // "Slot 1" ~ "Slot 12"
    char         timestamp[20];      // "2026-06-29 14:00:00"
    unsigned int checksum;           // 字节累加和（magic+version 区零化后计算）
    int          var_values[NB_VAR_COUNT]; // 全部变量快照
    char         filename[64];       // 当前场景脚本名，如 "nbook001.nb"
    char         lang[8];            // 语言代码
    char         chapter_title[64];  // v3 新增，章节标题
} SaveData;
```

#### SlotInfo（`save.h` — 运行时查询结构）

```c
typedef struct {
    int     exists;
    unsigned int version;
    char    slot_name[32];
    char    timestamp[20];
    char    filename[64];
    char    chapter_title[64];
} SlotInfo;
```

#### SystemSave（`save.h` — 全局解锁状态）

```c
typedef struct {
    unsigned int magic;              // SYSTEM_SAVE_MAGIC (0x5953544D "YSTM")
    unsigned int version;            // SAVE_VERSION
    unsigned int checksum;
    unsigned int cg_flags[4];        // 128 CG 位
    unsigned int ending_flags[1];    // 32 ending 位
    unsigned int clear_count;        // 通关次数
    unsigned int scene_flags[4];     // 128 场景位
} SystemSave;
```

### 2.3 二进制格式（小端序）

| 偏移 | 大小 | 字段 |
|------|------|------|
| 0 | 4 | magic |
| 4 | 4 | version |
| 8 | 32 | slot_name |
| 40 | 20 | timestamp |
| 60 | 4 | checksum |
| 64 | NB_VAR_COUNT×4 | var_values[] |
| 64+NB_VAR_COUNT×4 | 64 | filename |
| 128+NB_VAR_COUNT×4 | 8 | lang |
| 136+NB_VAR_COUNT×4 | 64 | chapter_title（v3+） |

v2 兼容：version<3 时总大小 148 字节（无 chapter_title）。

### 2.4 核心函数

**`save.c`**：

| 函数 | 行 | 行为 |
|------|----|------|
| `save_game_temp()` | 86 | 分配 `SaveData*`，填入当前状态缓存到内存（不写盘） |
| `save_game_slot(slot)` | 97 | 填充 slot_name/timestamp，写入 `SAVE##.SAV` |
| `load_game_temp()` | 128 | 从内存缓存 `sd` 恢复状态 |
| `load_game_slot(slot)` | 136 | 读 `SAVE##.SAV`，调用 `save_apply()` |
| `slot_info(slot, &si)` | 163 | 读槽位元信息（不读完整存档），empty 时设默认名 |

**`save_io.c`**（R9 拆分，磁盘级 I/O 收口）：

| 函数 | 行 | 行为 |
|------|----|------|
| `save_file_write(path, data, sz, min_sz)` | 38 | 写文件 + 校验和字段回填 |
| `save_file_read(path, buf, bufsz, min_size)` | 75 | 读文件 + magic/version/校验和验证 |
| `save_read_header(path, &h)` | 142 | `offsetof`+SEEK_SET 直跳读头部（槽位查询/缓存来源） |

**`save_sys.c`**（R9 拆分，系统存档）：

| 函数 | 行 | 行为 |
|------|----|------|
| `sys_save_load()` | 34 | 启动时加载 `SYSTEM.SAV` |
| `sys_save_write()` | 45 | 写系统存档（static，置位后即时写盘） |
| `sys_save_unlock_scene(scene_id)` | 50 | 设 scene_flags 位 + 即时写盘（越界静默 return） |
| `sys_save_unlock_cg(cg_id)` | 58 | 设 cg_flags 位 + 即时写盘（1..CG_TOTAL，越界静默 return） |
| `sys_save_is_cg_unlocked(cg_id)` | 66 | 查询 cg_flags 位（CG 画廊网格用） |

> R22：全屏菜单按页缓存 `SlotInfo` 头部（`slot_label_cache[4][128]`/`slot_exists_cache[4]`，键 `slot_cache_page`），焦点/confirm 每帧不再重复 `slot_info` 读盘；`save_game_slot` 后失效重建。

### 2.5 临时存档与回退

`save_game_temp()` 在 F5/F6 触发时调用，保存当前现场到 `SaveData *sd`（静态指针）。退出存档菜单后：

- 全屏菜单 `from_mainmenu=0` → `load_game_temp()` 恢复
- 全屏菜单 `from_mainmenu=1` → `nb_load(orig_nb)` 返回调用场景
- 对话框保存菜单退出 → `layer_dialog_restore()` + 重绘对话文字

> 注：`save_load_menu(is_load, from_mainmenu)` 的参数取代了旧的 `g_reload_mode` 全局（R7 重构）。当前所有调用路径均传 `from_mainmenu=0`，保留参数位供未来主菜单直连入口使用。
>
> `save_game_temp()` 仅缓存内存，不写盘。`load_game_temp()` 只能调用一次，因为内部 `save_apply()` 会触发 `nb_load()` 重新初始化解释器。

## 3. 全屏存档菜单

### 3.1 入口流程

```
F6 或主菜单 "load"
  → save_game_temp()               // 缓存当前状态
  → nb_load("loadscene.nb")        // 加载临时场景
  → cmd_loadscene()                // loadscene.nb 中调用
  → save_load_menu(is_load=1, from_mainmenu=0)
```

全屏菜单通过 `loadscene.nb` 这个中间脚本调用 `cmd_loadscene`，由 NB 解释器执行。这样做的好处是：
- 与 NB 脚本系统统一入口
- `from_mainmenu` 参数兼容游戏进行中与主菜单两种退出上下文（当前均传 0）

### 3.2 UI 布局

菜单绘制完全由 `save_load_draw()` 控制，面板固定在屏幕中央：

```
                         SAVE / LOAD
    ┌──────────────────────────────────────────────────────┐
    │  Slot 1 — Chapter 1         2026-06-29 14:00:00   >  │  ← emboss rect
    │  Slot 2 — (Empty)                                    │
    │  Slot 3 — Chapter 2         2026-06-29 14:30:00   >  │
    │  Slot 4 — (Empty)                                    │
    │                   <  2/3  >                           │
    │  [ Back ]                                             │
    │         Save to Slot 1?                               │  ← confirm 时显示
    │              [ Yes ] [ No ]                           │
    └──────────────────────────────────────────────────────┘
```

**坐标常量**（`nb_saveload.c` 内定义）：

| 元素 | x | y | w | h | r |
|------|---|---|---|---|---|
| 槽位 | 80 | 90/146/202/258 | 480 | 44 | 5 |
| 分页 < | 56 | 318 | — | — | — |
| 分页 > | 576 | 318 | — | — | — |
| 页计数器 | 310 | 330 | — | — | — |
| Back 按钮 | 66 | 355 | 64 | 24 | 2 |
| Yes 按钮 | 250 | 370 | 60 | 22 | 2 |
| No 按钮 | 330 | 370 | 60 | 22 | 2 |

### 3.3 两阶段渲染

遵循 AGENTS.md §十四 菜单渲染规则：

| 阶段 | full 参数 | 绘制内容 | 触发条件 |
|------|-----------|----------|----------|
| 全量 | `full=1` | `vblank_wait()` → 标题 → 4 个 emboss 槽位 → 分页按钮 → Back → 确认弹窗按钮 | 首次绘制、分页切换、确认弹窗开关、空槽提示 |
| 增量 | `full=0` | 仅 slot_info 文字 + `>` 指示符颜色 | 选中项变化、焦点切换、Yes/No 切换 |

增量更新的判断（`nb_saveload.c` 行 390）：
```c
if (slot_idx != prev_slot || focus_on_back != prev_focus || confirm_yes != prev_cyes)
    save_load_draw(..., full=0);
```

### 3.4 输入处理

| 按键 | 普通模式 | 确认模式 |
|------|----------|----------|
| ↑↓ | 浏览 4 个槽位 / 切到 Back | — |
| ←→ | 翻页 | 切换 Yes/No |
| Enter/Space/XFER | 选中槽位 → 进入确认；Back → 退出 | Yes → 执行存档/读档；No → 退出确认 |
| ESC | 退出菜单 | 退出确认 |
| 鼠标 Back | 点击 Back 按钮 | 退出确认 |

### 3.5 空槽处理

读档时空槽不允许直接确认，显示 "No save data." 提示并等待按键：
```c
kbd_drain_advance();
kbd_wait_any();  // 阻塞等待（有 KBD_WAIT_MAX_ITER 超时保护）
kbd_drain_advance();
save_load_draw(..., full=1);  // 全量重绘
```

## 4. 对话框内保存菜单

### 4.1 入口流程

```
对话中按 F5
  → save_game_temp()               // 缓存当前状态
  → save_dialog_menu()             // 直接在对话框内弹出保存 UI（阻塞）
  → 返回后在 main.c 的 for(;;) 中 break，重新进入主循环处理
```

不经过 `loadscene.nb`，因为是纯保存（无需读档选择）。

### 4.2 状态存档

进入时保存当前对话框文字和偏移量（`nb_save_dialog.c` `save_dialog_menu()` 入口）：
```c
char saved_charname[64];
char saved_text[1024];
int  saved_offset;
int  has_text;
```

- `nb_dialog_get_charname()` → `saved_charname`
- `nb_dialog_get_text()` → `saved_text`
- `nb_dialog_get_offset()` → `saved_offset`

### 4.3 对话框文字清除

进入/退出菜单用 `layer_dialog_restore()`（= 将对话框复合缓冲 `dialog_layer` 重新 blit 到 VRAM，幂等地盖掉菜单覆盖层）。真正的文字清除发生在 RAM 复合缓冲——退出菜单时 `layer_dialog_render_page(saved_charname, saved_text, saved_offset)` 重画框+文字后整框发布（R19 收口）。

**进入时**（`nb_save_dialog.c`：`hal_mouse_erase_cursor()` → `layer_dialog_restore()` → `menu_save_item_palette()`）：
```c
hal_mouse_erase_cursor();
layer_dialog_restore();           // re-blit 复合缓冲（幂等）
menu_save_item_palette();
hal_kbd_drain_advance();
draw_text("SAVE", ...);           // header 标题
save_dlg_draw_slots(row, col);    // 2×6 格子
```

**退出时**：
```c
menu_restore_item_palette();
hal_mouse_erase_cursor();
if (has_text)                     // render_page 重画框+文字 → blit
    layer_dialog_render_page(saved_charname, saved_text, saved_offset);
```

**确认覆写弹窗**（`save_dlg_draw_confirm()`）：
```c
layer_dialog_restore();           // re-blit 复合缓冲（幂等）
draw_text("SAVE", ...);           // 补回 header
// 再画确认覆盖文字
```

### 4.4 UI 布局

对话框内 UI 全部在对话框区域内（x=80..560, y=280..395）：

```
┌──────────────────────────────────────────────────────────┐
│  SAVE                                                    │  ← DIALOG_Y + DIALOG_HEADER_Y (286)
│  [ 1] [ 2] [ 3] [ 4] [ 5] [ 6]                          │  ← DIALOG_Y + DIALOG_TEXT_Y (308)
│  [ 7] [ 8] [ 9] [10] [11] [12]                          │  ← +20 (328)
│            [Back]                                        │  ← +40 (348)
│  Overwrite Slot N?                                       │  ← confirm 时覆盖此区域
│  Chapter 1             2026-06-29 14:00:00               │
│  [Yes]          [No]                                     │
└──────────────────────────────────────────────────────────┘
```

**槽位坐标**（`save_dlg_draw_slots()`）：

| 变量 | 计算 | 值 |
|------|------|-----|
| content_x | `DIALOG_X + DIALOG_INDENT` | 92 |
| content_y | `DIALOG_Y + DIALOG_TEXT_Y` | 308 |
| content_w | `DIALOG_W - 2×DIALOG_INDENT` | 456 |
| slot_w | `content_w / 6` | 76 |

- 2 行 × 6 列 = 12 槽位
- 行高 20px
- 第 3 行（y = content_y + 40）："Back" 居中
- 选中格子用 `MENU_PAL_YELLOW`（251），其余用 `PAL_WHITE`（7）

### 4.5 输入处理

| 按键 | 普通模式 | 确认模式 |
|------|----------|----------|
| ↑↓ | 0↔1↔2 循环（含 Back） | — |
| ←→ | 0↔5 循环（仅 row 0-1，Back 行无效） | 切换 Yes/No |
| Enter/Space/XFER | 选中格子→确认；Back→退出 | Yes→保存并退出；No→返回槽位 |
| ESC | 退出菜单 | 返回槽位 |

↑↓ 的封装逻辑使用固定三态映射，避免越界：
```c
row = (row == 2) ? 1 : (row == 1 ? 0 : 2);   // ↑
row = (row == 2) ? 0 : (row == 1 ? 2 : 1);   // ↓
```

## 5. 对话框复合缓冲系统

### 5.1 生命周期

R19 起对话框改为 **RAM 复合缓冲**（`dialog_layer` 480×115 + `dialog_occluder` 活动底），无逐帧 VRAM 快照：

```
layer_dialog_show()（首次 dialog_show）
  → alloc dialog_layer / dialog_occluder（OOM → 直绘 VRAM 降级路径）
  → set_active(DIALOG, TEXT)
  → layer_sprite_sync_dialog_base()   // 种活动底（under_dialog 纯底 + 立绘框内像素）
  → dialog_paint_box(dialog_layer)    // 框（PAT75 洞孔透出活动底 = 伪透明）

layer_dialog_render_page(name, text, off)（每页/翻页/读档恢复）
  → dialog_seed_base()               // 重种底
  → dialog_paint_box()               // 重画框，擦上一页文字
  → text_set_target(dialog_layer) + draw_text(角色名/正文)
  → return draw_text 续显偏移         // 调用方决定是否暂停翻页

dialog_layer_store_render(name, text, off)  // 记录投影元数据（换图 recompose 用）

dialog_layer_blit()                    // 整框 vram_write 发布到 VRAM
layer_dialog_restore()                 // = dialog_layer_blit()（幂等 re-blit，盖菜单覆盖）
```

精灵变更/换背景走 `layer_sprite_sync_dialog_base()` 重建活动底（hide 时还原 `under_dialog` 纯底）。

### 5.2 复合缓冲内容

`dialog_layer` 包含：
- `dialog_paint_box()` 绘制的对话框背景（fill_rect_pattern 或 fill_rect）+ 白边
- 当前页角色名与正文文字（字形经 `text_set_target` 合成）
- 透过 pattern 孔洞可见的活动底像素（背景 + 立绘框内区，伪透明）

### 5.3 标准清除方法

"清掉菜单覆盖、回显对话"统一 `layer_dialog_restore()`（re-blit 复合缓冲）；"换一页文字"统一 `layer_dialog_render_page()` + 尾部 `blit`：

```c
layer_dialog_restore();               // 幂等 re-blit 当前页（框+文字）
layer_dialog_render_page(n, t, off);  // 缓冲内重画框+新文字（随后调用方 blit）
```

**禁止**：
- `fill_rect` / `fill_rect_pattern` → 会破坏 pattern 一致性，留下实心块或鬼影
- 直接向 VRAM 重画框体 → 绕过复合缓冲，破坏伪透明孔洞与翻页清除语义（除非 OOM 降级路径）

### 5.4 适用场景

| 场景 | 位置 | 调用 |
|------|------|------|
| 正常对话推进 | `layer_dialog.c: layer_dialog_render_page` 内部 | `text_set_target` + 尾部 blit |
| 保存菜单进入 re-blit | `nb_save_dialog.c: save_dialog_menu()` | `layer_dialog_restore()` |
| 存档覆盖弹窗 | `nb_save_dialog.c: save_dlg_draw_confirm()` | `layer_dialog_restore()` + draw "SAVE" |
| 保存菜单退出还原 | `nb_save_dialog.c: save_dialog_menu()` 退出 | `layer_dialog_render_page(saved_*)` + blit |
| 读档恢复文字 | `nb_save_dialog.c` 读档路径 | `layer_dialog_render_page` + 投影 + blit（菜单为暂态 VRAM 覆盖，缓冲为持久态） |

## 6. 输入循环约定

两个菜单均遵守 AGENTS.md §十四 的四条规则：

| 规则 | 实现 |
|------|------|
| 入口 drain | `kbd_drain_advance()` 在循环前调用 |
| 超时保护 | 忙等循环使用 `KBD_WAIT_MAX_ITER`（50000） |
| 语义查询 | 消费按键用 `kbd_is_down()`（边缘触发） |
| scene 切换 | `nb_load()` 末尾 `kbd_drain_advance()` + `kbd_set_ignore_frames(2)` |

空槽警告中的 `kbd_wait_any()` 内部已包含超时保护。

## 7. 菜单渲染约定

### 7.1 两阶段渲染（AGENTS.md §十四）

| 阶段 | 行为 | 示例 |
|------|------|------|
| 入口全量 | 画所有昂贵原语 | `save_load_draw(..., full=1)` |
| 循环内增量 | 只改文字颜色/可见性 | `save_load_draw(..., full=0)` |

**具体规则**：
- `draw_rounded_emboss` 只在全量阶段画一次
- 文字颜色切换通过同位置不同颜色 `draw_text` 完成，无需额外清除
- 指示符（`>`）清除用 `fill_rect` 擦除旧区域后再画
- 鼠标光标用 `mouse_draw_cursor()`（save/restore），全量重绘后用 `mouse_draw_cursor_force()`
- 全量重绘前调 `vblank_wait()` 防撕裂

### 7.2 禁止模式

- 循环内调用 `draw_rounded_emboss` 或 `fill_rect(0,0,640,400,0)`
- 使用 `mouse_draw_cursor_ez()` 黑色擦除
- 循环内每帧调 `slot_info()` 后全量刷新槽位 UI

## 9. 扩展指南

### 9.1 新增槽位/分页

- 修改 `SAVE_SLOTS`（`save.h`）
- 更新 `slot_y[]` 数组（`nb.c` `save_load_draw()`）
- 更新 `total_pages` 计算逻辑

### 9.2 添加新菜单类型

1. 遵循 §6 输入循环规则
2. 遵循 §7 两阶段渲染规则
3. 对话框内菜单先 `layer_dialog_restore()`（re-blit 复合缓冲）再绘制覆盖层，退出走 `layer_dialog_render_page()` 回显（R19 链路，勿直写 VRAM 清对话框）
4. 使用 `menu_save_item_palette()` / `menu_restore_item_palette()` 管理菜单颜色
5. 鼠标光标统一使用 `mouse_draw_cursor()` save/restore 模式

### 9.3 注意事项

- 临时存档 `save_game_temp()` 只缓存一次：`load_game_temp()` 会触发 `nb_load()` 重新初始化，不能重复使用
- 全屏菜单通过 `loadscene.nb` 脚本桥接 `cmd_loadscene()`（`save_load_menu` 已是 `nb_saveload.c` static，脚本是唯一合法入口）
- 对话框内保存菜单退出后不调用 `load_game_temp()`，因为 F5 触发的 `break` 会让主循环重新开始处理
- 对话框复合缓冲（`dialog_layer`）是持久态，需在有对话框的场景下使用；其分配失败会走直绘 VRAM 降级路径（`hal_log("OOM: ...")`）
