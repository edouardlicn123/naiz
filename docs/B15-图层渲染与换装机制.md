> **状态**：活跃维护（2026-09-11：按 R19/R20 图层化重写——对话框由 RAM 复合缓冲 `dialog_layer` + 活动底 `dialog_occluder` 承载，背景换图跨图存活，立绘全高绘制不再裁剪；R23 menu_layer 见 B93）。
> **创建**：2026-06-12（原 C04）/ 2026-06-18 迁入 B 类
> **依赖**：`B02-显示管线规范.md`（VRAM 布局、图元函数）、`B11-MAG图片加载与显示规范.md`（MAG 格式）、`B12-VRAM渲染策略：两趟叠加与局部刷新.md`（渲染顺序）、`B93-图层渲染与菜单图层规范.md`（当前图层范式，R19–R23）
>
> 本文定义 `scene_layers.h`（公开接口）与图层实现文件 `layer.c` / `layer_bg.c` / `layer_dialog.c` / `layer_sprite.c` / `menu_layer.c` 的完整设计——背景快照（源图直取零回读）、精灵注册表、换表情/换装/换位置的裁剪策略、对话框样式底层编码、对话框复合缓冲与活动底、clean reset 与 hideall。
>

## 1. 概述

### 1.1 解决的问题

PC-98 只有单层 VRAM，所有像素共享同一块 packed-pixel 缓冲区。实现"立绘在对话框之下"和"换表情不重绘对话框"需要一套统一的调度层。R19 起新增的约束是——**对话框与菜单是反复重绘的覆盖层**，直接写 VRAM 会产生中间态可见帧与大量 bank 端口开销，因此改为在 RAM 中离屏合成后原子发布。

### 1.2 核心思想

```
┌───────────────────────────────┐        ┌──────────────────────────────┐
│  精灵注册表                    │ ← 跟踪每个精灵的 id/位置/mirror     │
├───────────────────────────────┤        │  渲染目标路由（R19/R23）      │
│  bg_snapshot   640×400 全屏   │        │  render_set_target(buf,…)     │
│                快照（源图直取）│        │  text_set_target(buf,…)       │
├───────────────────────────────┤        │   → fill_rect/pattern/pset/   │
│  under_dialog  480×115 纯背景 │        │     draw_text 改落 RAM 缓冲   │
├───────────────────────────────┤        └──────────────────────────────┘
│  dialog_occluder 480×115 活动底│ ← 纯背景 + 立绘框内像素（伪透明孔）
├───────────────────────────────┤        ┌──────────────────────────────┐
│  dialog_layer  480×115 复合缓冲│ ← 框 + 当前页文字（不透明）→ 整框 blit
├───────────────────────────────┤        │  menu_layer（R23，见 B93）    │
│  dialog_drawn   0/1           │        │  opaque base 快照 / transparent│
├───────────────────────────────┤        │  镂空 + blit_rect 增量发布    │
│  决策分发 show/face/replace/hide│        └──────────────────────────────┘
└───────────────────────────────┘
```

**旧模型残留**（`bg_dialog_snapshot`、`dialog_snapshot`、`dialog_dirty`、`layer_dialog_snap`）已在 R19 删除；`under_dialog` 承接"对话框区域纯背景"职责（由背景源图 RAM 直拷，**零 VRAM 回读**），`dialog_occluder` 承接"对话框区域底层合成"职责（R20 引入）。详见 `B93` §1.2、§4。

## 2. 对话框样式底层实现

### 2.1 全局变量

```c
unsigned char g_dialog_style = 0;   /* SOLID_BLACK */
```

### 2.2 运行时切换

```
NB 命令（dlgstyle 变体）→ dlg_set_style(s) → g_dialog_style = s; dlg_update_palette()
```

`dlgstyle` 只改变 `g_dialog_style` 的值，**不重绘现有对话框**。若需立即生效，应在新行打印之前调用。可用 style 值 0-9。

### 2.3 与 `bg` 的交互

```
顺序（固定，由 layer_bg_change 收口）：
1. vram_blit(img, 0, 0)                    → 全屏新背景
2. layer_capture_bg_from_image(img→bg_snapshot)     → 全屏快照（RAM 直拷）
3. layer_capture_bg_dialog_from_image(img→under_dialog) → 对话框区纯背景（RAM 直拷）
4. layer_redraw_sprites()                  → 全身重绘，尾部 sync_dialog_base
5. dlg_update_palette() / btn_update_palette()
```

`layer_bg_change()`（`layer_bg.c`）是**统一入口**，`cmd_bg`/`cmd_cg`/动画帧推进均经它。对话框开启时，`layer_redraw_sprites` 尾部重建 `dialog_occluder`，随后 `layer_dialog_recompose` 重画框 + 当前页文字并 blit——**框+当前页文字跨图存活**（裁决 A，见 §7）。

### 2.4 调制色板

所有样式共用 palette 248 作为对话框底色。引擎通过 `dlg_update_palette()` 在样式切换或 `bg` 后动态改色：

```c
static const uint8_t COLOR_SCHEMES[5][3] = {
    {0x00, 0x00, 0x00},   /* 0: black    */
    {0x00, 0x00, 0xFF},   /* 1: blue     */
    {0x80, 0x00, 0x00},   /* 2: dark red */
    {0x00, 0x80, 0x00},   /* 3: green    */
    {0x80, 0x00, 0x80},   /* 4: purple   */
};
```

样式判断：
- 抖动/实心：`g_dialog_style & 1`（1=抖动，0=实心）
- 颜色索引：`g_dialog_style >> 1`（0-4）

### 2.5 调色板保护

| 索引 | 默认色 | 用途 |
|------|--------|------|
| 7 | `#FFFFFF` 白 | 文字、边框 |
| 15 | `#000000` 黑 | 精灵透明色 |
| **248** | 动态 | 对话框底色（由 COLOR_SCHEMES 决定） |
| 250–251 | 白/黄 | 菜单文字（`menu_layer` blending 同用） |

### 2.6 边框

边框始终保持 2px 白实线，不随样式变化。PAT75 由 layer_dialog.c 私有定义（`static const uint8_t PAT75[8]`），render.c 只按调用方传入的 pattern 填充。

## 3. API 参考

### 3.1 背景 / 统一入口

`layer_init()` 已 static 化于 `layer.c`，随 `nb_load()` 场景转换调用，释放快照/复合缓冲并清标志。

```c
void layer_bg_change(MagImage *img);
```
统一背景切换（见 §2.3）。内部完成 blit → 双快照捕捉（源图直拷）→ 全身重绘 → 调色板 → dialog recompose。**R19 阶段 C 收口**：不再让调用方手写 5~6 步仪式。

```c
void layer_capture_bg_dialog_from_image(const uint8_t *pixels, int img_w, int img_h,
                                        int src_x, int src_y);
```
从源图像素缓冲区（RAM 直拷）填充 `under_dialog`。行索引 `src_row-src_y` 与 `img_h` 夹逼（R14 C28 修复），cine 图（640×280）覆盖不到的对话框区行保持零化跳过。

### 3.2 对话框

```c
void layer_dialog_show(void);
```
首次 `dialog_show()` 时调用（`dialog_drawn==0`）。分配 `dialog_layer` + `dialog_occluder`（`layer_snapshot_alloc_dialog`，OOM 打 hal_log 并降级直绘 VRAM），设置 layer_active，`layer_sprite_sync_dialog_base()` 建活动底，然后 `dialog_paint_box` 画框进缓冲。**OOM 降级路径**：`dialog_paint_box(buf=NULL)` 直写 VRAM（legacy 语义）。

```c
int layer_dialog_render_page(const char *name, const char *text, int off);
```
把一页（角色名 + 正文）渲染进复合缓冲：`dialog_seed_base()`（occluder → under_dialog → 黑 逐级退化）→ `dialog_paint_box`（重画框擦除上一页文字）→ `text_set_target` + `draw_text` → 复位 target。返回正文 `draw_text` 续行偏移（翻页契约）或 -1。**不 blit**。

```c
void dialog_layer_store_render(const char *name, const char *text, int off);
```
记录当前页渲染投影（`dialog_render_name/text/off`，~1KB static 无堆），供换图后 `layer_dialog_recompose` 重绘（跨图存活）。

```c
void dialog_layer_blit(void);
```
整框 `vram_write(dialog_layer, 80,280,480,115)` 发布。

```c
void layer_dialog_hide(void);
```
`bg(hidedialog)`/`cg(hidedialog)`/`cg(){key}` 调用。`dialog_drawn==0` 时早退（避免冗余 55KB 写，R17）。否则 `vram_write(under_dialog)` 还原纯背景 → 清标志 → `layer_redraw_sprites()` 全身重绘（R19 OOM 决策 B：对话框关闭后立绘可延伸入 y≥280）。

```c
void layer_dialog_recompose(void);
```
`dialog_drawn && dialog_layer` 时，从渲染投影重画框 + 当前页文字并 blit（换图后跨图存活，裁决 A）。调用方：`layer_bg_change`。

### 3.3 精灵操作

```c
void layer_sprite_show(int sprite_id, int asset_id, int x, int y, int mirror);
```
初始化阶段使用（`dialog_drawn==0`）。全幅 200×400 绘制，同时记入精灵注册表。R20 后**全高绘制不裁剪**；尾部 `layer_sprite_sync_dialog_base()` 重建活动底使伪透明保留立绘。
`sprite_id` 为精灵注册表 ID（NB 解释器中传角色 ID），`asset_id` 为 IMAGE.DAT 中的图片 ID。

```c
void layer_sprite_face(int sprite_id, int asset_id, int x, int y, int mirror);
```
换表情。**仅重绘上半身 `y < LAYER_DIALOG_Y`（<280）的区域**：从 `bg_snapshot` 恢复该区域后绘制新表情，不碰对话框矩形。R20 保留上半身 clip（`calc_sprite_clip_h` 强制 clip_h=280-face_y）。

```c
void layer_sprite_replace(int sprite_id, int asset_id, int x, int y, int mirror);
```
换装/换位置。**全幅更新**（对话框开启时不再裁剪到 y<280）：从 `bg_snapshot` 恢复旧位∪新位的整块矩形（`clip_dialog=1` 跳过对话框区），全幅绘制新立绘，尾部 sync_dialog_base 重建 occluder；对话框本体的重绘由 recompose 处理。

```c
void layer_sprite_hide(int id);
```
隐藏指定 id 的精灵。从精灵注册表取出旧位置，从 `bg_snapshot` 恢复（`clip_dialog=1` 不盖框），尾部 sync_dialog_base。若隐藏后场景中无其他活跃精灵（1→0 过渡），执行 full-screen `layer_bg_restore_rect`。

```c
void layer_sprite_hide_all(void);
```
隐藏所有活跃精灵。遍历精灵注册表，逐个调用 `layer_sprite_hide()`。NB 中通过 `char(hideall)` 触发。

## 4. 内部数据结构

### 4.1 背景快照

```c
static unsigned char *bg_snapshot;     // 640×400 = 256,000 字节（源图直取，非 VRAM 回读）
static unsigned char *under_dialog;    // 480×115 = 55,200 字节（对话框区纯背景，源图直取）
static unsigned char  snapshot_valid;  // 0/1
```

`layer_bg_change` 内 `layer_capture_bg_from_image` 从 `img->pixels` 逐行 memcpy 到 `bg_snapshot`（越界行零化）；`layer_capture_bg_dialog_from_image` 从源图拷贝对话框区行到 `under_dialog`（`src_row-src_y` 与 `img_h` 夹逼）。**两只快照全程零 VRAM 回读**（R19 消除，规避 B16 条件跳过污染）。

### 4.2 精灵注册表

```c
#define MAX_SPRITES 16

typedef struct {
    unsigned char active;   // 0=空闲, 1=使用中
    int  id;                // 精灵注册表 ID（NB 中为角色 ID）
    int  asset_id;          // IMAGE.DAT 中的图片 ID
    int  x, y;              // 当前绘制位置
    int  mirror;            // 水平翻转
} SpriteEntry;

static SpriteEntry sprite_tbl[MAX_SPRITES];
```

### 4.3 对话框复合缓冲 / 活动底 / 文本投影

```c
static unsigned char *dialog_layer;    // 480×115：框 + 当前页文字（不透明）
static unsigned char *dialog_occluder; // 480×115：纯背景 + 立绘框内像素（活动底，伪透明孔）
static unsigned char dialog_drawn;     // 0=尚未绘制, 1=已绘
static char  dialog_render_name[64];   // 渲染投影（换图后重绘当前页用，~1KB static）
static char  dialog_render_text[1024];
static int   dialog_render_off;
static unsigned char dialog_render_valid;
```

`layer_dialog_show` 分配 `dialog_layer`+`dialog_occluder`（共 110,400 B）；`layer_dialog_reset`（scene_end）释放。`layer_sprite_sync_dialog_base` 维护 `dialog_occluder`：`dialog_occluder_sprite_blit` 逐 active 精灵把框内(立绘区 x∈[80,560])像素 RAM 落底。

## 5. 决策表（核心逻辑，R19/R20 形态）

```
事件                    dialog_drawn → 行为
────────────────────────────────────────────────────────────
bg(){key}/cg(){key}      无关
                          layer_bg_change(img):
                            blit → 双快照(源图直拷) → 全身重绘
                            → sync_dialog_base → （开框则）recompose → blit
                 cg 分支另有：layer_dialog_hide() + nb_dialog_reset()（全屏事件）
bg(hidedialog)/cg(hidedialog)
                          layer_dialog_hide(): under_dialog 还原 + 全身重绘
────────────────────────────────────────────────────────────
首次 dialog_show        0        layer_dialog_show()
                                 → alloc 双缓冲 → paint_box → render_page → blit
翻页 dialog_show        1        layer_dialog_render_page(新文字) → blit
────────────────────────────────────────────────────────────
layer_sprite_show()     0/1      全幅 blit + 注册 + sync_dialog_base
                                 （R20：全高绘制，不再与对话框矩形相交裁剪）
layer_sprite_face()     0        → 回退到 show
                        1        clip y [0, DIALOG_Y)：restore_rect(y<280, clip=1)
                                 + vram_blit_sprite_cropped()；不碰对话框 ✅
layer_sprite_replace()  0        → 回退到 show
                        1        union(旧位,新位) 整块 restore（clip=1）
                                 全幅 blit；sync_dialog_base 重建 occluder ✅
layer_sprite_hide()     0        注销即可
                        1        layer_bg_restore_rect(旧位, clip=1)
                                 尾部 sync_dialog_base
                                 if 1→0 last sprite → full bg restore
layer_sprite_hide_all() 0/1      反复 layer_sprite_hide()
```

### 5.1 `layer_bg_restore_rect` 辅助函数

```c
// 从 bg_snapshot 恢复指定矩形到 VRAM
// clip_dialog=1 且对话框已绘时，跳过与对话框矩形重叠的像素（不盖框）
void layer_bg_restore_rect(int x, int y, int w, int h, int clip_dialog);
```

精灵恢复一律 `clip_dialog=1`（R20 撤销 Option X 后，对话框合成在立绘之上，恢复路径不得碰框）。face 因不重绘对话框也走 clip=1。

## 6. 场景字节码操作码

### 6.1 立绘操作码

当前引擎运行在 NB 解释器路径下（`nb.c`），场景逻辑由 `cmd_bg`、`cmd_char` 等 NB 命令处理，不经过旧 `scene.c` 的字节码分发表。旧操作码表（`0x32`–`0x3A`）保留在 `scene.c` 中作为 MHVN98 协议兼容参考：

| 操作码 | 名称 | 参数 | 行为 |
|-------|------|------|------|
| `0x32` | `SPRITE_SHOW` | `uint16 id, uint16 x, uint16 y` | 自动分发：已存在 → `layer_sprite_replace(id, id, x, y, mirror)`，不存在 → `layer_sprite_show(id, id, x, y, mirror)` |
| `0x34` | `SPRITE_MIRROR` | `uint8 mirror` | 设置 `g_sprite_mirror`，影响后续精灵操作 |
| `0x38` | `SPRITE_HIDE` | `uint16 id` | `layer_sprite_hide(id)` |
| `0x39` | `SPRITE_FACE` | `uint16 id, uint16 x, uint16 y` | `layer_sprite_face(id, id, x, y, g_mirror)` |
| `0x3A` | `SPRITE_REPLACE` | `uint16 id, uint16 x, uint16 y` | `layer_sprite_replace(id, id, x, y, g_mirror)` |

**场景脚本示例**：

```sca
; 初始加载
bgload 0
sprite 1 10 0      ; 立绘 A（初始化阶段）
sprite 2 220 0
sprite 3 430 0
text 0             ; 对话框出现

; 换表情（只改脸）
sprite_face 1 10 0  ; 不重绘对话框 ✅

; 换装（全幅）
sprite_replace 1 10 0  ; 全高更新，活动底重建 ✅

; 隐藏
sprite_hide 1
```

### 6.2 精灵 MAG 调色板

精灵 MAG 中嵌有自己的调色板（索引 0–14 为角色实际色、索引 15 为透明色），但引擎**忽略它**——精灵渲染时使用背景的调色板。转换工具的调色板仅用于验证目的。

## 7. 渲染顺序（完整场景生命周期，R19/R20）

```
      ┌── bg_snapshot ──┐   ┌── under_dialog ──┐   ┌── dialog_occluder ──┐
      │ 640×400 源图直取│   │ 480×115 纯背景   │   │ 纯背景+立绘框内像素 │
      └─────────────────┘   └──────────────────┘   └──────────────────────┘
               ┌── dialog_layer（480×115 复合：框+当前页文字）──┐
               └────────── dialog_layer_blit() → 整框发布 ─────┘

(1) bg{background}
      vram_blit(img, 0, 0) + 双快照（源图直拷）→ 全身重绘
      └ 背景加载后 dialog_drawn 保持原值；开框则 recompose 跨图存活

(2) char fei l face                  ← show：全幅 200×400（不再裁剪）
      vram_blit_sprite(..., 15, clip_h) ← 跳过透明索引 15；尾部 sync_dialog_base

(3) fei{对话文字}（首次）
      dialog_drawn == 0
      → layer_dialog_show()：
          alloc dialog_layer+occluder → set_active → sync_dialog_base
          → dialog_paint_box（PAT75 孔洞透出 occluder 立绘）
      → layer_dialog_render_page：box 擦上一页 + text_set_target 写角色名/正文
      → dialog_layer_store_render（投影）
      → dialog_layer_blit()          ← 整框原子发布
      dialog_drawn = 1

(4) 后续翻页
      layer_dialog_render_page（重画框 + 新文字）+ blit   ← 无 VRAM 中间态

(5) face 1 x y  (换表情)
      layer_bg_restore_rect(x, y, 200, DIALOG_Y-y, clip=1)
      vram_blit_sprite_cropped(...)  ← 仅 y<DIALOG_Y；对话框不碰 ✅

(6) replace 1 x y  (换装/换位置)
      layer_bg_restore_rect(union_bbox, clip=1)
      vram_blit_sprite(...)          ← 全幅
      sync_dialog_base → recompose → blit（框与当前页文字重新盖回）

(7) bg(hidedialog)
      layer_dialog_hide()：vram_write(under_dialog) → 全身重绘
      dialog_drawn = 0

(8) char(hideall)
      layer_sprite_hide_all()        ← 逐个隐藏；最后一只 1→0 时 full bg restore
```

## 8. 性能分析

### 8.1 各操作耗时估计（486/33MHz，R19/R23 形态）

| 操作 | 像素操作量 | 归属 | 耗时估算 |
|------|-----------|------|---------|
| `bg_change` 快照捕捉 | 256KB + 55KB RAM memcpy（源图直拷，零 I/O） | RAM | ~1ms |
| `dialog_show`（首开） | 双缓冲 malloc + 55KB×2 合成 | RAM | ~2ms |
| `dialog_show`（翻页） | 55KB 重合成 + 55KB vram_write blit | RAM+VRAM | ~2.5ms |
| `render_page`（含 text_set_target） | 55KB 框擦除 + 字素写入缓冲 | RAM | ~1.5ms |
| `dialog_layer_blit` | 55KB vram_write（单 blit） | VRAM | ~1ms |
| `sprite_show/replace`（全幅） | ~80KB blit + 活动底重建 | RAM+VRAM | ~3ms |
| `sprite_face` | ~22KB restore + ~12KB blit（仅上半身） | VRAM | ~1.5ms |
| `sprite_hide` | ~40KB restore | VRAM | ~1.2ms |
| `menu_layer`（全量，R23） | 256KB 合成（全屏 opaque）+ 256KB blit | RAM+VRAM | ~2-4ms |
| `menu_layer_blit_rect`（增量） | 局部矩形 vram_write | VRAM | ≪1ms |

所有操作远低于 16.6ms 帧预算。**关键差异**：合成（复杂图案/文字/浮雕）全在 RAM，只保留了单次整框/整屏的 VRAM 发布写——中间态不可见，且 bank 端口写从逐像素降到逐行。

### 8.2 内存开销

| 项目 | 大小 | 时机 |
|------|------|------|
| `bg_snapshot` | 256,000 B | bg 捕捉 ~ 下次 bg change / reset |
| `under_dialog` | 55,200 B | bg 捕捉 ~ 下次 bg change / reset |
| `dialog_layer` | 55,200 B | 首开对话框 ~ reset（跨图存活） |
| `dialog_occluder` | 55,200 B | 与 dialog_layer 同生灭 |
| `dialog_render_*` 投影 | ~1,100 B static | 首开对话框 ~ reset |
| `menu_layer`（opaque 全屏） | base + composite = 512,000 B | open ~ close（R23） |
| 精灵注册表 | 16 × 8 B = 128 B | 始终 |

## 12. 史料：旧快照模型（已废弃）

R19 之前（≤0.2.088），对话框层是"VRAM 快照 ×3 + 惰性截图"模型：

| 旧符号 | 职责 | 去向 |
|--------|------|------|
| `bg_dialog_snapshot` | 对话框区**纯背景** VRAM 截图 | → `under_dialog`（源图直取，零回读）；改名见 layer_bg.c 注释 |
| `dialog_snapshot` | PAT75 + 背景 + 立绘（无文字）VRAM 截图 | **删除** → `dialog_layer` 复合缓冲 + `dialog_occluder` 活动底（程序化生成，无快照） |
| `dialog_dirty` / `layer_dialog_snap` | 惰性截图标志 / 消费 | **删除**（R19 阶段 B 删防腐账本） |
| `layer_capture_bg` / `layer_capture_bg_dialog` | 全屏 / 对话框区 VRAM 回读 | **删除** → `layer_capture_bg_from_image` / `layer_capture_bg_dialog_from_image`（RAM 直拷） |
| `scene_draw_dialog` | 画框到 VRAM | 内部化为 `dialog_paint_box`（可写缓冲或直写 VRAM） |
| `layer_dialog_refresh` / `layer_dialog_restore`（快照恢复） | 换装后重绘 / 翻页恢复 | 归一为 `dialog_layer_blit`（`layer_dialog_restore` 保留名称 = blit 薄封装） |

**废弃理由**（详见 `devdocs/96-对话框图层化四阶段.md`）：
- 多次 55KB `vram_read` 回读对话框区，受 B16 规则 1（条件跳过写入不可回读）污染风险约束，且每次交换装重建费用高
- 惰性截图在决定式场景下抖动/选择逻辑复杂
- 复合缓冲做法先把绘制成本降到 RAM，再单次整框发布——闪烁与 bank 开销一举消除

> 旧模型曾在 §5 决策表/§7 渲染顺序/§8 性能逐项对应，已随本版改写；历史文本见 git 历史或 `devdocs/0.1版开发文档总结.html`。
