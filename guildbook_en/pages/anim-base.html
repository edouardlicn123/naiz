base: The Palette Animation's Base Image

Created: 2026-08-29
Last updated: 2026-08-29

base is for palette animations (the kind whose header declaration picked palette). It declares the first base image — the picture as it looks before any changes; every later recolor is applied on top of this image. Back to the Syntax Overview.

1. How to write it

base(){素材昵称}

The braces hold exactly one asset nickname (the base image); no number goes in the parentheses.

2. A galgame example

# Flickering light: start from a base image at normal brightness, then darken and brighten it
animaconf(cine,palette,标题流光)
base(){正常亮度}
pal(0.2){暗一点}
pal(0.2){亮回来}

Each palette table that follows modifies the base image's colors on top of it — colors not mentioned keep the base image's look.

3. Things to watch out for

  • Only for palette animations (the header declaration picked palette). Writing base in a pixel animation is an error.
  • In a palette animation, base may be written only once.
  • It must come before pal (base image first, then the changes). Writing pal first and base after makes the tool raise an error.
  • The base image's nickname must also be registered with register first.

4. Common mistakes

  • Using base in a pixel animation by mistake → use frame instead.
  • Writing base twice → keep just one.
  • Writing pal before base → move base to the front.
