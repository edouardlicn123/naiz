mainmenu — Main Menu Command

Created: 2026-07-27
Last updated: 2026-09-11

The mainmenu() command builds the game's main menu. For the visual spec see cf04 — button style scheme; for the design guide see ui01 — main menu design.

1. Syntax

mainmenu(x, y, cols, _, opt1, opt2, opt3, ...)
ParameterTypeDescription
xintMain menu top-left x coordinate (0–640)
yintMain menu top-left y coordinate (0–400)
colsintColumn count (1 or 2)
_intReserved parameter, always pass 0
optNstringMenu options, ordered column-first

2. Options

OptionStatusBehavior
continueImplementedLoads the save with the newest timestamp; with no save, falls back to starting a new game at nbook001.nb
loadImplementedPreserves the current state (temporary save) and jumps to the load scene loadscene.nb (see sc05)
startImplementedStart a new game → nbook001.nb
scenesReservedScene selection is not implemented yet
specialReservedSpecial content is not implemented yet
musicReservedMusic gallery is not implemented yet
galleryImplementedJumps to the CG gallery scene cgview.nb (see sc06)
settingsReservedSystem settings live in startsetting() (sc13); the main menu entry is not wired up yet
exitImplementedQuit the game

3. Example

mainmenu(400, 200, 2, 0, continue, load, start, music, gallery, settings, exit)
