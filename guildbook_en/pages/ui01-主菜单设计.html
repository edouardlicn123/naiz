Main Menu Design

Created: 2026-06-27
Last updated: 2026-06-27

This page covers the main menu's scene flow, how to edit it, and multilingual translation. For command syntax see sc07-mainmenu.

1. Scene Flow

After the game starts, the scene chain is:

logo.nb → op.nb → mainmenu.nb
                       │
            start ─────┤
              ↓        │
         nbook001.nb   │
           ⋮           │
        scene(end) ────┘
                       │
            exit ──────┘
                  engine shuts down
  • The main story is triggered by start, beginning at nbook001.nb
  • scene(end) at the end of the story returns to the main menu automatically
  • While playing, press Esc to return to the main menu at any time
  • Choosing exit shuts the engine down and returns to DOS

2. Editing Example

The main menu is defined by the mainmenu.nb file. Remove an option to hide its button:

# two columns, keep only start, gallery, settings, and exit
mainmenu(400, 200, 2, 0, start, gallery, settings, exit)
RuleDescription
exit must come lastThe engine parses in order; options after it are not shown
16 items maximumA single mainmenu command holds at most 16 options
You cannot add option namesThe engine only recognizes the option names listed in the table above; custom names have no effect

3. Translation

Menu option labels are translated automatically through the multilingual system. There is no need to write per-language menus in the scenario — the engine looks up the translation in i18n/role_*.txt when displaying.

Example translation file:

# i18n/role_chi.txt
start=开始游戏
exit=退出游戏
continue=继续游戏
