pal: Making the Colors Change

Created: 2026-08-29
Last updated: 2026-08-29

pal is for palette animations (the kind whose header declaration picked palette). It states how the colors change this time and how long the result stays on screen. The image itself doesn't move — only its colors change — which makes it perfect for flickering lights, magic glows, and gradual color-tone shifts. Back to the Syntax Overview.

1. How to write it

pal(停留秒数){色表昵称}
  • The parentheses hold one number (seconds; decimals allowed).
  • The braces hold the palette-table nickname used by this change (a palette table says which colors become what). You may write several, separated by commas; they take effect in turn and share the same duration.

2. What a palette-table file (.pal) looks like

A palette table is a very simple text file; each line says: take the color with this index and change it to these red/green/blue values:

# Light example: change index 0 to red, index 15 to black
0 255 0 0
15 0 0 0
  • Each line has four numbers: index red green blue, all values between 0 and 255.
  • A # at the start of a line is a comment and is ignored.
  • Don't write the same index twice in one palette table.
  • Colors not mentioned keep how they looked after the previous step (so a chain of pal commands keeps building on the previous step).

3. A galgame example

# Title-screen light: normal → dark → bright, breathing back and forth
animaconf(cine,palette,标题流光)
base(){正常}
pal(0.2){暗}
pal(0.2){亮}

4. Things to watch out for

  • Only for palette animations (the header declaration picked palette). Writing pal in a pixel animation is an error.
  • It must come after base (base image first, then the changes).
  • A palette animation needs at least one pal.
  • The palette-table nickname must also be registered with register first; a malformed palette-table file (e.g. lines that aren't four numbers) makes the tool raise an error.

5. Common mistakes

  • Using pal in a pixel animation by mistake → use frame instead.
  • Writing pal before base → put base first.
  • It reports a malformed .pal → check that every line is the four numbers index red green blue and that no index is repeated.
