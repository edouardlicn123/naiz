settingmenu — Settings Menu

Created: 2026-08-29

The settingmenu command is reserved for opening the settings menu. The current engine version does not implement it yet.

1. Syntax

settingmenu
ParameterTypeDescription
——No parameters

2. Example

settingmenu

Reserved / TODO: the engine marks this command as "not implemented" (it only writes a debug log), so calling it has no effect today. To open the settings menu, use startsetting in the meantime.
