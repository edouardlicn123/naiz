NB Scenario Overview

Created: 2026-07-27
Last updated: 2026-10-03

1. Overview

NB (Naiz Book) is the Naiz engine's high-level scenario format: UTF-8 plain text, one command per line. The engine loads and executes NB files directly, with no compile step to bytecode.

2. File Organization

2.1 Naming Rules

FileScene
logo.nbStartup logo
op.nbOpening
mainmenu.nbMain menu
savescene.nbSave menu
loadscene.nbLoad menu
nbook001.nb ~ nbook020.nbStory scenes 001–020

2.2 Format Conventions

  • UTF-8 encoding, LF line endings
  • One command per line
  • Lines starting with # are comments
  • Blank lines are ignored
  • Parameters are comma-separated (the question and scene commands use a semicolon ; as the top-level separator, with commas inside sub-segments; a comma inside field content is escaped as \,, and \\ is a literal backslash — see sc08 question)
  • Parameters go inside (), text content goes inside {}
