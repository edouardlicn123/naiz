char — Sprites and Dialogue

Created: 2026-07-27

char() controls showing, hiding, and switching the expression of sprites. Character dialogue and narration also belong to this page.

1. Syntax

char(pos[, expr[, type]]){charname}
char(hideall)

The object (the character name) goes in the curly-brace payload; the parentheses carry the display parameters pos/expr/type. This follows the same convention as bg(effect){key}: "object in braces, parentheses = parameters ± keyword".

ParameterTypeDescription
charnamestringCharacter key, such as fei, ira, written in the curly-brace payload
posstringPosition: l (left), c (center), r (right)
exprstringOptional, default normal. Expression name
typestringOptional, inferred automatically by default. body (full body / costume change) or face (expression only)

2. Type Inference

If you omit type, the engine chooses:

  • Character not shown yet → body (first full-body display)
  • Character already shown → face (expression only, the dialogue box is not redrawn)

3. Subcommands

CommandDescription
char(hideall)Hide all sprites and do a clean reset

4. Example

char(l, normal, body){fei}    ← first display of fei at the left position
char(r, normal, body){ira}    ← first display of ira at the right position
char(r, smile){fei}           ← fei switches to the smile expression
char(r, sad, face){ira}       ← ira switches to the sad expression
char(hideall)                 ← hide all sprites

Note: the char(charname, pos, expr, type) form (character name written inside the parentheses) is deprecated and is rejected by the engine and the scenario validator — the character key must go inside the braces.

5. Character Dialogue

The charkey(){text} command shows a character's line. The character key matches the characters.key field, and characters.name is used automatically as the displayed name.

Syntax

charkey(){text}

Paging

The engine handles text overflow automatically. When the text exceeds the dialogue box height, it pauses and waits for a keypress; press any key to continue to the next page.

Example

fei(){Hello.}
ira(){Hi.}
neon(){Let's begin!}

6. Narration

The host(){text} command shows narration text with no character name and no name label.

Syntax

host(){text}

Example

host(){This is Naiz demo.}
