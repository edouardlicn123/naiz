frame: Placing an Image

Created: 2026-08-29
Last updated: 2026-08-29

frame is for pixel animations (the kind whose header declaration picked pixel). Each frame line is one image of the animation and states how many seconds that image stays on screen. Write several lines in a row and you get a moving picture. Back to the Syntax Overview.

1. How to write it

frame(停留秒数){素材昵称}
  • The parentheses hold one number (seconds; decimals allowed — 0.5 means half a second).
  • The braces hold the asset nickname used by this image (the name given at registration — no path needed).
  • To have several images play in turn while sharing one duration, put them on one line separated by commas: {图1,图2,图3}.

2. A galgame example

# Character blink: eyes open half a second, closed half a second, toggling back and forth
animaconf(fullscreen,pixel,主角)
frame(0.5){睁眼}
frame(0.5){闭眼}

# Clouds drifting slowly: three images, each held 0.3 seconds, shown in turn
frame(0.3){云1,云2,云3}

The tool converts your seconds into the animation's internal timing (60 ticks per second) automatically — just fill in seconds and don't worry about the details. If seconds×60 isn't a whole number, the tool only prints a notice; generation is unaffected.

3. Things to watch out for

  • Only for pixel animations (the header declaration picked pixel). Writing frame in a palette animation is an error.
  • A pixel animation needs at least one frame line, otherwise there is nothing to show.
  • Nicknames in the braces must already be registered in the asset nickname table (go run register); otherwise the tool says it can't find the name.
  • Every image in a fullscreen animation must be exactly 640×400.

4. Common mistakes

  • Using frame in a palette animation by mistake → use base + pal instead.
  • It reports an unregistered name → the asset wasn't registered; run register first.
  • It reports a wrong size → fullscreen animation images must be exactly 640×400.
