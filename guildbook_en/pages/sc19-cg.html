cg — Full-screen CG Display

Created: 2026-09-11

The cg() command displays a CG across the whole screen, or hides the dialogue box to restore the background area. Like bg(){key} (sc02) it follows the same convention: "the object lives in the brace payload, the paren slot holds parameters ± keywords".

1. Syntax

cg(){key}
cg(hidedialog)
ParameterTypeDescription
keystringCG asset name, matching asset_map.name (CG type), written in the brace payload
hidedialogkeywordOnly hides the dialogue box and restores the background area; no new image is loaded

2. Behaviour

  • Full-screen event: cg(){key} covers the whole screen with the CG and automatically hides the dialogue box and clears the current line — the next line pops a new box
  • Permanent unlock: a displayed CG is recorded in the unlock state (visible in the gallery cgvmenu(), see sc06)
  • Difference from bg: after bg(){key} changes the background the dialogue box survives across images (box + current page text kept); cg(){key} is a "full-screen event" and hides the box on its own — to hide it explicitly use cg(hidedialog)

3. Example

cg(){cg01}        # show the CG full-screen, hide the dialogue box, clear the line
cg(hidedialog)    # only hide the dialogue box and restore the background

Note: the cg(key) form (key inside the parentheses) is deprecated and is rejected by both the engine and the scenario validator — the CG key must go in the braces. The paren slot is reserved for future parameters.
