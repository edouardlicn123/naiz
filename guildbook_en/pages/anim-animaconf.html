animaconf: The Header Declaration

Created: 2026-08-29
Last updated: 2026-08-29

animaconf goes on the first line of the storyboard script (the .na file) and states the animation's basic setup — like announcing before you start shooting: fullscreen or a cine strip, frame-swap or recolor, and which project the assets belong to. Back to the Syntax Overview.

1. How to write it

animaconf(全屏还是横条, 整图还是变色, 项目名)

The three options go in the parentheses, separated by commas — no braces. For example:

animaconf(fullscreen,pixel,眨眼项目)
animaconf(cine,palette,标题流光)

2. What goes in each of the three options

PositionAllowed valuesMeaning
Firstfullscreen / cinefullscreen = an animation covering the whole screen; cine = only the strip above the dialogue box
Secondpixel / palettepixel = a pixel animation (images swapped one after another); palette = a palette animation (the image stays put, only the colors change)
ThirdYour project nameTells the tool which project's assets folder to look in; the project must already exist

3. Things to watch out for

  • It is required and must be written exactly once, at the very front of the script (blank lines or # comments may precede it).
  • Don't declare looping here — whether the animation plays once or loops is decided by the command that plays it in the game; the script doesn't handle that.
  • A misspelled option or a nonexistent project folder — the tool raises an error to alert you.

4. Examples

# A fullscreen pixel animation (e.g. an explosion, falling petals)
animaconf(fullscreen,pixel,特效合集)

# A cine-strip palette animation above the dialogue box (e.g. flickering lights)
animaconf(cine,palette,标题流光)

5. Common mistakes

  • Writing animaconf(){...} with braces → parentheses only here, no braces.
  • Omitting it, writing it twice, or not putting it on the first line → the tool reports a problem with animaconf.
  • A wrong project name or a project that hasn't been created yet → the tool reports the project as missing.
