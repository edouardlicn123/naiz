startsetting — Startup Settings

Created: 2026-08-29

The startsetting command opens the settings menu, saves the settings, and reloads the font and scenario language when the language changes. The command takes no parameters.

1. Syntax

startsetting
ParameterTypeDescription
——No parameters

2. Example

mainmenu start
startsetting

It calls the settings-menu run function internally; if the language changed, the CJK font and the NB text are reloaded (see cmd_startsetting in nb_mainmenu.c).
