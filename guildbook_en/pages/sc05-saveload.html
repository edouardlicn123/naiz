loadscene — Load Game

Created: 2026-07-27
Last updated: 2026-09-11

The loadscene() command opens the load menu.

1. Syntax

loadscene()
ParameterTypeDescription
——No parameters; calling it opens the load grid menu (9 slots per page)

2. Behavior

  • Load menu: use the arrow keys or the mouse to pick a slot, Enter to confirm the load, Del to delete a save
  • Save entry: saving is not triggered by a scenario command — it is opened from the main menu "Save" item or an in-game shortcut (see sc07-mainmenu.html)
