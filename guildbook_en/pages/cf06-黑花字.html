Blackletter

Created: 2026-08-04

Blackletter (Fraktur) is the classic decorative Latin typeface of Western printing; Naiz uses it to give the load/save page titles and the dialogue body text a decorative Latin font effect.

1. What it is

  • Built from the UnifrakturMaguntia typeface (SIL OFL 1.1 open license).
  • Contains Latin letters and punctuation only, with no CJK glyphs.
  • The deployed data comes in two parts:
    • BLACK.DAT — a 16×16 bitmap font used for ASCII text such as dialogue body text.
    • loadtitle.MAG / savetitle.MAG — full blackletter title images ("LOAD" / "SAVE") used for the load/save page titles.

2. Scope (important)

Blackletter contains Latin characters only, so it is effective only when the runtime language is non-CJK (such as eng). When the language is chi / jpn / kor, the engine falls back to the original font whatever the switches say, with no missing or garbled glyphs.

3. How to enable

Set the switches in the [blackletter] section of the project config.toml:

[blackletter]
# Whether the LOAD / SAVE titles on the load/save pages use the blackletter MAG
title = true
# Whether ASCII body text uses blackletter 16×16 (BLACK.DAT)
dialog = true
FieldDefaultScope
titlefalse The large title at the top of the load / save page (LOAD / SAVE). When on, a centered blackletter title image replaces the default large-text title.
dialogfalse ASCII text in dialogue, question options, save menus, and so on. When on, Latin characters in body text switch to the 16×16 blackletter bitmap.

Values must be the booleans true / false; do not add quotes ("true" is read as a string and wrongly treated as "on").

4. How it takes effect

After changing it, just rebuild the game:

./makegame.sh build <game>
  1. export_config.py reads the blackletter switches from config.toml and generates the NAIZ_BLACKLETTER_TITLE / NAIZ_BLACKLETTER_DIALOG macros in core/engine/nb_config.h, compiled into the engine.
  2. The engine does zero runtime parsing — both switches are constants at compile time, so changing them requires a recompile.
  3. They take effect when the runtime language is non-CJK; for CJK the original font is used automatically.

5. Relation to other settings

  • Blackletter applies to Latin text; CJK text always uses the CJK bitmap font and is unaffected.
  • The dialogue box style ([dialog] style in config.toml), the font, and other settings are independent of blackletter and can be used together.
  • For the full configuration format, see cf02 Project Configuration File.

6. Notes

  • The blackletter face is decorative and less readable than the default font; keep the default for long body text and use blackletter only for titles or short lines.
  • The switches affect non-CJK languages only; when you ship several languages, CJK players still see the original font, which is expected behavior.
  • After changing the switches you must rebuild with makegame.sh build (to generate nb_config.h) and makegame.sh make (to inject the HDI) before it takes effect — the macros are compile-time, and a build without a make still runs the old engine.
