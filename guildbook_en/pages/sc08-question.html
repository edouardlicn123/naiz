question — Choice Branches

Created: 2026-07-27 Last updated: 2026-10-03

The question() command shows choice branches whose options are tied to variables. For variable definitions see cf01 — variable system.

1. Syntax

question(text;opt1,var1,op1,delta1;opt2,var2,op2,delta2;...)

The semicolon ; is the top-level separator; inside each option segment, commas , separate four fields:

FieldDescription
textQuestion text (first segment)
labelOption display text
varVariable id (must be defined in variables.json)
opOperator: + (add), - (subtract), = (assign)
deltaInteger value

1.1 Commas Inside Fields (Escaping)

When the option label itself needs a comma, escape it with a backslash, \,:

question(Pick one?;Ira\, Jr.,bond_ira,+,1;Neon,bond_neon,+,1)
  • \, → a literal comma (stays in the label, not treated as a field separator)
  • \\ → a literal backslash
  • Any other \x is kept as-is (so C:\path does not lose its backslash)
  • Leading and trailing whitespace in a field is trimmed: Yes ,bond_ira,+,1 equals Yes,bond_ira,+,1
  • The question text text (first segment) is not split on commas — commas in it are literal and need no escaping

Escaping is handled by the engine's nb_next_field(); the scenario validator and the translation extractor use the same rule set, so the extracted translation keys always match the keys looked up at runtime.

2. Limits

  • At most 10 option segments (parser limit)
  • At most 4 options shown at once (UI limit)
  • On selection the op is applied, bounded by the min/max in variables.json
  • The result is stored in last_choice (0-based index)

3. Example

question(Where to?;Forest,bond_fei,+,5;Cave,bond_ira,=,10;Town,bond_neon,-,3)
  • Choose Forest → bond_fei += 5
  • Choose Cave → bond_ira = 10
  • Choose Town → bond_neon -= 3

When a label contains a comma (escaped as \,):

question(Go with whom?;Ira\, Jr.,bond_ira,+,1;Neon,bond_neon,+,1)
  • The first option displays as Ira, Jr.; written unescaped as Ira, Jr.,bond_ira,+,1 it is wrongly split into 5 fields, the label is left as Ira, and every following field is shifted
