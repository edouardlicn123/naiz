host — System Narration

Created: 2026-08-29

The host() command displays system narration (no character name). It differs from the fei/ira/neon character lines in sc03-char.html: narration shows no character-name prefix.

1. Syntax

host(){text}
ParameterTypeDescription
textstringNarration text (written in the brace payload; the paren slot takes no parameter)

2. Example

host(){暴风雨渐息，海面恢复平静。}

Narration is not shown with a character-name prefix; its layout is decided by the current dialogue style preset (see the cf03 page, Dialogue Style Presets).
