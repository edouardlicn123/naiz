Button Style Scheme

Created: 2026-06-27
Last updated: 2026-06-27

This page describes the visual specification and color schemes of in-game menu buttons. You set the button style through [button] style in the project configuration config.toml (compiled into the engine at build time).

1. Button specification

AttributeValue
Width100 px
Height34 px
Corner radius17 px
Border styleEmbossed (highlight on the top/left edge, shadow on the bottom/right edge)
TextCentered inside the button

All buttons have a fixed size and are not affected by the coordinate parameters of mainmenu().

2. Color schemes

style offers 5 color schemes (set style = N in the [button] section of config.toml, where N is 0–4):

StyleBase colorHighlightShadow
0 Black#000000#3F3F3F#000000
1 Blue#0000FF#3F3FFF#0000BF
2 Dark red#800000#9F3F3F#600000
3 Green#008000#3F9F3F#006000
4 Purple#800080#9F3F9F#600060

Text color is fixed white (unselected) and yellow (selected); it does not change with the color scheme.

3. How to configure

Set the style value in the [button] section of the project configuration config.toml:

style = 1     # Blue buttons
style = 3     # Green buttons

The style takes effect when the game starts, so restart the game after changing it.
