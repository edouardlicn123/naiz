market.sh Usage Guide

Created: 2026-09-27
Last updated: 2026-09-27

market.sh is the asset-market download tool: it downloads resources (e.g. scene backgrounds) whole-package on demand from the public GitHub market repo to your local machine, without adding to this repository's size. Downloads are read-only HTTPS (GitHub API + raw) and need no write access. For registering images into a project, see cf07 Image Registration.

1. Basic concept: packages

  • A top-level directory in the market repo = one resource package; downloads are always whole-package — there is no file-level selection.
  • Display-name rule: the directory name is split on _, the first segment is wrapped in (), and the remaining segments are joined with spaces (e.g. images_sample_scenebg → (images)sample scenebg); on the command line, both the raw directory name and the suffix kind name are accepted.
  • The default download destination is assets_samples/ (already gitignored); if a file with the same name already exists at the target path it is skipped by default (printing SKIP (exists)), and is overwritten only with --force.

2. Configuration (market.toml)

The repository root's market.toml:

[market]
repo = "edouardlicn123/naiz_assets"  # market repo owner/repo
ref = "main"                          # branch/ref
dest = "assets_samples"               # local destination

3. Subcommands

SubcommandWhat it does
listList all packages (display name / file count / total size)
catsPackage display names + file counts only
menu (default)Pick packages interactively by number (supports 1 2 and 1-3; pressing Enter downloads the whole package); the screen is cleared once at startup, later redraws do not clear it, and the download log stays above the menu
get <包>...Whole-package download from the command line (raw directory name or suffix kind name)
get-allDownload all packages

Common options (placed after the subcommand): --repo / --ref / --dest / --config / --dry-run (plan only, write nothing to disk) / --force (overwrite existing files).

Screen clearing applies only to menu, and only when the output is a terminal (when redirected to a file or piped, plain text is written with no escape sequences).

4. Common usage examples

# Interactive menu (recommended)
./market.sh
# Equivalent form
./market.sh menu

# See what packages exist
./market.sh list

# Download a specific package (both forms are equivalent)
./market.sh get images_sample_scenebg
./market.sh get scenebg

# Refresh already-downloaded files
./market.sh get scenebg --force

The downloaded files under assets_samples/ are raw assets; to use them in the game, copy them to assets/<game>/png/ and register them following the three steps in cf07 Image Registration.
