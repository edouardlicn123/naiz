sceneconf — Scene Configuration

Created: 2026-08-29

The sceneconf() command sets the chapter title, type and scene-list flag of the current scene. The title is recorded with the save, the type controls behaviour such as the save hotkey, and the list flag declares whether the scene is planned to appear in the scene menu.

1. Syntax

sceneconf(){title[, type[, onlist|outlist]]}

Brace-only form: the title, the type and the list flag all go in the brace payload (the paren alias is deprecated).

ParameterTypeDescription
titlestringChapter title text, recorded with the save and displayed (written in the brace payload)
typestringScene type normal / cg / menu, default normal
onlist / outlistkeywordScene-list flag, default outlist. onlist marks the scene as planned for the scene menu; any other value logs a WARN and falls back to outlist

1.1 Type Reference

TypeDescription
normalNormal scene (default)
cgCG gallery scene
menuMenu scene; the save hotkey is disabled

2. Example

sceneconf(){序章, normal}
sceneconf(){画廊, cg}
sceneconf(){, menu}                  # menu-type scene: the title may be omitted
sceneconf(){第五章, normal, onlist}  # planned for the scene menu

Note: with type=menu the save hotkey is disabled, so a save is not triggered by accident inside the main menu or a settings scene. At build time onlist is scanned by tools/naiz_build/scene_menu.py to generate the scene-menu table (thumbnail: first CG, else first animation frame, else the title's initial letter); the flag itself is not written to saves. Unplayed scenes stay locked: the file must be named nbookNNN.nb (the number is the unlock id); loading a scene sets its unlock bit in the system save, and the scene gallery only lists unlocked scenes — locked ones are hidden, not greyed out, and when nothing is unlocked the menu says "Play the story to unlock scenes."
