sceneconf — Scene Configuration

Created: 2026-08-29

The sceneconf() command sets the chapter title and type of the current scene. The title is recorded with the save, and the type controls behaviour such as the save hotkey.

1. Syntax

sceneconf(){title[, type]}

Brace-only form: both the title and the type go in the brace payload (the paren alias is deprecated).

ParameterTypeDescription
titlestringChapter title text, recorded with the save and displayed (written in the brace payload)
typestringScene type normal / cg / menu, default normal

1.1 Type Reference

TypeDescription
normalNormal scene (default)
cgCG gallery scene
menuMenu scene; the save hotkey is disabled

2. Example

sceneconf(){序章, normal}
sceneconf(){画廊, cg}
sceneconf(){, menu}   # menu-type scene: the title may be omitted

Note: with type=menu the save hotkey is disabled, so a save is not triggered by accident inside the main menu or a settings scene.
