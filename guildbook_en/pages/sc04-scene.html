scene — Scene Transitions

Created: 2026-07-27
Last updated: 2026-10-03

scene() jumps to another scene. Both unconditional jumps and conditional chain jumps (which rely on the variable system) are supported.

1. Unconditional Jumps

scene(target)
ParameterTypeDescription
targetkeyword / 3-digitScene name or number

Values for target:

ValueDescription
logoStartup logo scene (logo.nb)
opOpening scene (op.nb)
mainmenuMain menu scene (mainmenu.nb)
001–020Story scenes nbookXXX.nb
endEnd the game and return to the main menu

2. Conditional Chain Jumps

scene(var1,op1,val1,...,target1;var2,op2,val2,...,target2[;default])

Each ; segment consists of one or more var,op,val triples plus a final target. Multiple triples inside a segment are AND (all must match); segments are OR (the first matching segment wins).

FieldDescription
varVariable id (must be defined in variables.json)
opComparison operator: == != > >= < <=
valComparison value (integer)
targetJump target (3-digit, e.g. 002 → nbook002.nb)

Each segment supports 1–8 triples (SCENE_MAX_CONDS = 8); the last field is always the target.

Default value convention: if the last segment contains no comma (e.g. ;001), it is used as an explicit default jump target. If the last segment does contain a comma, all segments are conditional, and when nothing matches the engine falls back to the target of the first segment.

Commas inside fields: if a field itself contains a comma, write it exactly as in question — escape it as \, (\\ is a literal backslash). Escaping is handled in one place, the engine's nb_next_field(), and the validator and the translation extractor share the same rule. See sc08 question — choice branches §1.1.

3. Example

scene(003)                                          ← unconditional jump to nbook003.nb
scene(bond_fei,>=,5,005;001)                        ← single condition: bond_fei≥5→005, otherwise→001
scene(bond_ira,>=,5,bond_neon,>=,3,005;001)         ← AND: both affinity values reach the threshold→005, otherwise→001
scene(bond_ira,>=,5,005;bond_neon,>=,3,005;001)         ← OR: either one reaches the threshold→005, otherwise→001
scene(bond_ira,>=,5,005;bond_neon,>=,3,004)         ← no explicit default: each matching segment goes to its own target, otherwise fallback→005 (target of the first segment)

4. sceneconf — Scene Configuration

The sceneconf command declares the current scene's configuration: chapter title + scene type. It does not control jumps.

sceneconf(){A normal day, normal}
sceneconf(){, menu}   # menu-type scene: the title may be omitted
FieldRequiredDescription
titleNoChapter title. Stored with the save and shown on the save/load screens (falls back to the scene file name when unset)
typeNo (default normal)Scene type, see the table below

4.1 Scene Types

TypeDescription
normalRegular story scene (default)
cgCG showcase scene
menuMenu-type scene (main menu / save / load / logo etc.). In these scenes the F5 save / F6 load hotkeys are disabled

Convention: write sceneconf on the first line of the scene file. Menu-type scenes (mainmenu / loadscene / logo / op) must declare type=menu, otherwise the save hotkey stays wrongly active.
