var — Variable Operations

Created: 2026-07-27

The var() command reads and writes a single variable. For variable definitions see cf01 — variable system.

1. Syntax

var(id, op, value)
ParameterTypeDescription
idstringVariable identifier (must be defined in variables.json)
opstringOperator: = (assign), + (add), - (subtract)
valueintNumeric value

2. Behavior

  • = sets the variable to value
  • + adds value to the variable
  • - subtracts value from the variable
  • All operations are bounded by min / max in variables.json, and clamped automatically when out of range

3. Example

var(bond_fei, +, 3)    # bond_fei += 3
var(bond_ira, =, 50)   # bond_ira = 50
var(bond_neon, -, 10)  # bond_neon -= 10
