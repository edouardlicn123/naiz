Project Configuration File (config.toml)

Created: 2026-08-04

Every project root holds a config.toml that manages project-level global configuration (language, title, version, transition, blackletter switches). At build time several tools read it and generate the NAIZ_* macros in core/engine/nb_config.h, compiled into the engine; at runtime no project configuration file is deployed or parsed any more.

1. Value type conventions

TypeSyntaxExample
String Wrapped in double quotes title = "Demo-A2"
Boolean true / false, without quotes title = false
Integer Decimal integer frames = 2
String array Brackets, comma separated targets = ["chi", "jpn"]
Nested section Use [section name] [blackletter]
Reminder: do not quote booleans. "false" is a string, not a boolean, and the build tool reads it as "present → on", turning on a feature you meant to keep off.

2. Full configuration with comments

# =============================================================
# Naiz game project configuration (TOML) — # comments supported
# Sole exception: the version line below is maintained by
# bump_version; do not edit it by hand, other lines are free.
# =============================================================

# ---- Internationalization (i18n) ----
[i18n]
# Source language (text baseline), required. i18n_gen generates translations from it.
source_lang = "eng"
# Target languages to generate translations for (used by i18n_gen). Must not include source_lang itself.
targets = ["chi", "jpn"]

# ---- Project information ----
[project]
# Game title (shown on the main menu / startup screen)
title = "Demo-A2"
# Game description (short note, used only to identify the project)
description = "Naiz Engine 技术演示"
# Version number X.Y.ZZZ — maintained by bump_version, do not edit by hand
version = "0.1.053"

# ---- Scene transitions ----
[transition]
# Scene transition type: cut | fade | vblinds | hblinds | dblinds | rdblinds
type = "vblinds"
# Transition frame count (1-64); the higher the value the slower the transition
frames = 2

# ---- Blackletter ----
[blackletter]
# Whether the LOAD / SAVE titles on the load/save pages use blackletter MAG
title = false
# Whether ASCII body text uses blackletter 16×16 (BLACK.DAT)
dialog = false

For the blackletter fields, see cf06 Blackletter.

4. Toolchain consumption matrix

SectionKeyReading toolDestination / purpose
i18nsource_lang, targets tools/naiz_conv/i18n_gen.py Generates / merges translation files.
project / blacklettertitle, version, title / dialog tools/naiz_build/export_config.py Generates the NAIZ_VERSION / NAIZ_BLACKLETTER_TITLE / NAIZ_BLACKLETTER_DIALOG macros in nb_config.h, compiled into the engine.
transitiontype, frames tools/naiz_build/export_config.py Generates the engine header nb_config.h (macros NAIZ_TRANSITION_*), embedded at compile time.

5. Version bump

Run this after every source change:

python -m tools.naiz_build.bump_version <game>
  • Increments the rightmost segment of version (for example 0.1.052 → 0.1.053).
  • Writes back by line replacement: only the version = "…" line changes, while every other # comment and the layout stay intact (the TOML reader tomllib is read-only, so the file is no longer serialized back wholesale).
  • The version line must exist and must be exactly one line, otherwise the tool reports an error.

6. Runtime chain

  • Project-level configuration (version / dialogue box / buttons / blackletter / default language / transitions): everything goes through compile-time macros — config.toml → export_config.py → nb_config.h with its NAIZ_* macros → compiled into the engine, zero runtime parsing. The old settings.txt and its parser (settings.c / settings.h) are fully deleted; at build time a leftover settings.txt is only ever deleted from the deployment directory.
  • Compile-time group (transitions): config.toml → export_config.py → nb_config.h macros → embedded at engine compile time.
