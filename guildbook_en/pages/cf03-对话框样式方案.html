Dialogue Box Style Scheme

Created: 2026-06-10
Last updated: 2026-06-10

In the Naiz engine, the dialogue box is not just a container for text — it is part of the work's visual language. This page gives creators 10 preset styles: 5 colors × 2 densities (solid / 75% semi-transparent).

1. Style overview

Encoding rule

style = (color_index << 1) | dither_bit
  color_index: 0=black, 1=blue, 2=dark red, 3=green, 4=purple
  dither_bit:  0=solid, 1=75% dither

Range 0-9, contiguous with no gaps

1.2 75% semi-transparent (5 styles)

How it works: inside the dialogue box region the engine writes the overlay color (black / blue / red / green / purple) with a Bayer 4×4 ordered dither pattern, so 25% of the pixels keep the background. The dot pattern:

Row 0: ▓▓▓░▓▓▓░  (0xEE)
Row 1: ░▓▓▓░▓▓▓  (0x77)
Row 2: ▓░▓▓▓░▓▓  (0xBB)
Row 3: ▓▓░▓▓▓░▓  (0xDD)

Shared behavior:

  • Border: always a 2px solid white line
  • Text: white, with no solid backing — drawn directly on the semi-transparent background
  • Line advance: the old text area is covered with the same pattern as the dialogue box, then the new characters are drawn

Readability tip: white text sits on a semi-transparent background, so readability drops over busy artwork. Use a transparent style on simple backgrounds and fall back to solid on complex ones.

2. Selection guide

Scene typeRecommended style
Everyday dialogue — any sceneSOLID_BLACK (0)
Ocean, night sky, blue interiorsSOLID_BLUE (2) or DITHER75_BLUE (3)
Drama, memory, tensionSOLID_RED (4) or DITHER75_RED (5)
Forest, nature, calmSOLID_GREEN (6) or DITHER75_GREEN (7)
Mystery, romance, fantasySOLID_PURPLE (8) or DITHER75_PURPLE (9)
High readability + slight transparencyDITHER75_BLACK (1)

Golden rule: when the background is busy and varied, make SOLID_BLACK the default and use transparent or colored styles locally for special atmosphere.

3. Configuration and use

3.1 config.toml

[dialog] style = 3      # 0-9, matching the table above

3.2 Interaction with background loading

Order (fixed):
1. Switch background — the new background fills the screen and a snapshot is saved
2. First dialogue after that — the dialogue box is drawn in the current style

For implementation details, see B15-Layer Rendering and Costume Changes.md §2.3.
