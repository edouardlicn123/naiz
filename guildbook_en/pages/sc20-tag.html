tag — Scene Anchors

Created: 2026-11-05 Last updated: 2026-11-05

tag() declares a jump anchor inside the current script for jump — in-scene jump and jumpscene — cross-scene jump. It has no runtime effect of its own: normal sequential execution simply passes over the tag line.

1. Syntax

tag(name)
FieldDescription
nameAnchor name. ASCII letters, digits and underscores only ([A-Za-z0-9_]+), case-sensitive
tag(m1)             ← valid
tag(badge_01)       ← valid (underscore)
tag(第一章)          ← invalid (non-ASCII identifier)

2. Writing Rules

  • Must occupy its own line: no space between the command name and (. tag(m1) works; tag (m1) does not.
  • A trailing # comment is allowed, e.g. tag(m1) # forest branch.
  • Duplicate names in the same scene are allowed: the first match wins (top-down scan).
  • A tag is scoped to its scene file; same-named tags in different scenes are independent.
  • Tags do not need pairing, and there is no implicit “return to anchor” behavior — a backward jump is just a jump whose target lies above the current position.
  • The build-time validator only collects tag(name) written on its own line, inside parentheses. The same text inside dialogue, comments or other command arguments is not an anchor.

3. Landing Position

When jump / jumpscene hits a tag, execution resumes at the line after the tag; the tag line itself is not executed (and would be a no-op anyway).

tag(branch_a)
host(){Entering branch A}   ← execution starts here after the jump

Tags are therefore usually placed at the “entrance” of a story block. Note that lines before the tag are not replayed: if the target block needs a specific background, sprite or BGM, put those commands after the tag rather than relying on settings that “should have run” before it. The same applies to cross-scene landings (see sc22 §3).

4. Build-Time Validation

  • A tag referenced by jump must exist in the current scene, otherwise the validator reports an error before runtime.
  • A tag given as the third field of jumpscene must exist in the target scene, and that scene file must exist.
  • Runtime fallback: if a tag is missing anyway (e.g. a hot-edited script), the engine logs a WARN, does not jump, and continues with the line after the jump command; jumpscene instead plays the target scene from the top.

5. Example

# nbook001.nb
tag(m_start)
host(){Morning forest}

jump(Where to?;Forest,m_forest;Town,m_town)

tag(m_forest)
bg(normal){forest}
host(){You walk into the forest}

tag(m_town)
bg(normal){town}
host(){You arrive in town}
