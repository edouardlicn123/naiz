## 1. 需求与已确认决策

1. 在既有主菜单体系下新增「音乐鉴赏（Music Room）」界面，用于试听已登记的 BGM。
2. 界面外观与交互**照搬 LOAD/SETTING 列表范式**（整屏、emboss 圆角行、4 行/页、分页箭头、左下 Back、`focus_on_back` 模型）。
3. **曲目列表 = 资产表自动枚举全部 BGM**（对称于 CG 画廊枚举 `CG_COUNT`），新增 BGM 零维护。
4. **曲名来源**：`ASSETS.DB` 的 `img_map` 增加 `title` 列；为空则回落 `name`（脚本 key）。
5. **v1 不做解锁门控**：全部曲目可见，不新增存档位、不改存档格式。
6. 入口：`special.nb` 已有 `music` 键（`specialmenu(gallery,scenes,music)`）；`mainmenu` 命令亦保留 `music` 分支。

## 4. 界面规格（布局常量）

行几何与 `nb_setting.c:160-179` 对齐（`x=120/w=400/h=44`；比 load 的 `80/480` 窄，为右侧播放指示留位）：

```c
#define MUS_BTN_X    120
#define MUS_BTN_W    400
#define MUS_BTN_H    44
#define MUS_ROW_R    SAVE_SLOT_R
#define MUS_IND_LX   (MUS_BTN_X + 6)                /* '>' 焦点指示 */
#define MUS_LABEL_X  (MUS_BTN_X + 20)               /* 曲名，左对齐 */
#define MUS_LABEL_W  300
#define MUS_MARK_X   (MUS_BTN_X + MUS_BTN_W - 40)   /* '♪' 播放中标记 */
#define MUS_TITLE_Y  28
#define MUS_ARR_Y    318
#define MUS_COUNT_Y  330
#define MUS_BACK_Y   352
static const int mus_row_y[4] = { 90, 146, 202, 258 };
```

- 标题：`draw_title_large(tr("MUSIC"), 居中, MUS_TITLE_Y, 4, PAL_WHITE)`。
- 行体：`draw_rounded_emboss(MUS_BTN_X, y, MUS_BTN_W, MUS_BTN_H, MUS_ROW_R, BTN_FILL_IDX, BTN_HIGHLIGHT_IDX, BTN_SHADOW_IDX)`。
- 行内容：焦点 `>`（`MENU_PAL_YELLOW`）+ 曲名（左对齐；焦点黄色、非焦点 `PAL_WHITE`）+ 播放中 `♪`（`MUS_MARK_X`，`MENU_PAL_YELLOW`）。
- 页脚：`menu_pagenav_draw(MUS_ARR_Y, MUS_COUNT_Y, PAL_WHITE, page, total_pages)` / `menu_back_draw(MUS_BACK_Y, focus_on_back, emboss, PAL_WHITE)`。
- **两阶段绘制**（§十四 菜单 UI）：入口 / 翻页 `full=1` 画标题 + emboss 行体 + 分页 + Back 边框；焦点 / 播放状态变化 `full=0` 只改行文字与 Back 标签（`menu_layer_begin_draw()` → 绘制 → `menu_layer_commit()` → `menu_layer_blit()`）。
- **空列表**（`BGM_COUNT==0`）：仿 `nb_cggallery.c:322-341`，绘 `tr("No BGM available.")`，任意键 / 左键点击退出。
- 背景由 `music.nb` 的 `bg()` 提供；菜单层用 opaque 模式（`menu_layer_open(0,0,LAYER_SCREEN_W,LAYER_SCREEN_H,0)`），退出 `menu_finish()`。

## 5. 数据来源改造（方案 B）

1. **`ASSETS.DB` schema**：`img_map` 增加 `title TEXT DEFAULT ''`。现有库用

2. **登记约定**：BGM 行的 `title` 填人类可读曲名（如 `Melody Town Theme`）；空值 → 引擎回落 `name`（key）。
3. **`tools/naiz_build/export_asset_table.py`**（改 `:176-186` 区块）：

## 6. 交互规格

| 键 | 行为 |
|---|---|
| Up / Down | 移动焦点（行 ↔ Back） |
| Enter / Space | 播放当前行；**再按同一行 = 停止**（toggle） |
| Left / Right | 翻页（无值可步进，与 special 一致） |
| Esc | 停止并返回 |

鼠标：点行 = 播放 / 停止；点箭头 = 翻页；点 Back = 返回。
视觉：焦点行黄色 + `>`；播放中的行右侧显示 `♪`。
`focus_on_back` 模型与 `nb_special.c` / `nb_setting.c` 一致（Down 到底进 Back，Up 回行尾，Enter/Space/Esc 在 Back 上退出）。

> **有意偏离**：Left/Right 绑定**翻页**（同 `specialmenu`），而非 `settingmenu` 的「步进值」语义——音乐行没有可步进的值。

## 7. 音频通路

- 播放 `audio_bgm_start(key)`，停止 `audio_bgm_stop()`（`core/engine/audio.h:29-30`）。**不走 PCM 循环**（§十四 音频通路规则 3：单通道会被 SE 掐断且不自动恢复）。
- 菜单循环内**必须** `engine_frame_pump()`（`nb_setting.c:379`、`nb_special.c:144`、`nb_cggallery.c:360` 同款），否则 FM 泵停止 → 「点了没声」。
- `scene_switch()` 会触发 `audio_stop_all()`，进 / 出 music 场景天然静音，**无需**在脚本堆 `bgm(stop)`。
- BGM 开关：玩家在设置里关 BGM 时 `audio_bgm_start` 已静默。**音乐室不改 prefs**，仅在标题旁给 `BGM: Off` 提示，避免偷偷改玩家设置。
- 本地无 MPU-401 → FM 后端（可闻）；MIDI 路径静音，属设计内降级（§十四 规则 2/4）。验收以 FM 可闻为准。

### 14.3 实现中发现的偏差

- **播放中标记**：§4 原写「`♪`（`MUS_MARK_X`）」。`FONT.DAT` 为 8×16 ASCII 字库、无音符字形，`draw_text` 对非 ASCII 字节回落 CJK 字体亦无该字形（`render_text.c` `text_width:245` 按字节高位判宽）。实现改为 `music_draw_mark():94` 在 `MUS_MARK_X` 画 12×12 `MENU_PAL_YELLOW` 填充块——几何标记而非字符。
- **`nb_validator` 桩表**：`musicmenu` 原在 `STUBS` 中（构建时硬拒），实现后须同时清 `STUBS` 并在 `SIGNATURES` 登记，否则 `build` 报「unknown command」。此为「实现命令须同步校验器」的既有约定，非本方案遗漏。
