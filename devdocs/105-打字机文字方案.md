# 105-打字机文字方案

> 版本：0.2.125（已落地）
> 日期：2026-09-20
> 状态：**已落地** —— 给 VN 台词加"逐字揭示 + 四档可调速率"的打字机效果，行为对齐 Ren'Py `typewriter(slow_cps)` 手感。本文档独立成文，仅含方案；落地按 §4 执行，结果见 CHANGELOG 0.2.125 条目。

## 1. 背景

### 1.1 参照（Ren'Py 打字机）

Ren'Py 的 AtExtender typewriter 效果：台词以指定速率（字/秒，`slow_cps`）逐字出现（per-character reveal）。交互语义为：**揭示未完成时点击＝立即显示整页**；整页显示后再点击才是"翻页/收尾"。角色名整段先出（不同步逐字），正文逐字。揭示推进对剧本/执行层透明——只影响"文字显示总量"，不改变脚本控制流。

### 1.2 现状

naiz 台词是**整页瞬时弹出**（`dialog_show` → `layer_dialog_render_page` 一次画全页），点击只做翻页/收尾。没有逐字揭示、没有文字速度概念。devdoc 103 阶段 2 已把「翻页停在屏上」接进 pending 让位机制，拍击入口（wait loop）也已归拢成单点分发——打字机正好接过这些现成接缝。

### 1.3 治理原则

- **行为等价**：除"逐字揭示 + 揭示中点击仅跳满"两项新语义外，翻页/收尾/AUTOEXIT/打断路径与现状一致；`AUTOEXIT` 构建零变化（整页直通，不改动无头测试语义）。
- **单一事实源**：文本与页边界仍由 `DialogState` + layer 渲染投影持有，打字机只加"揭示量"一个状态。
- **外科手术**：不动 `draw_text` 核心、不动 VM/指令集/存档格式、不新增 NB 命令。
- **先借后造**：复用 pending 让位、渲染投影（`dialog_layer_store_render`）、`anim_tick` 挂点模式、设置菜单骨架。

## 2. 现状审计（证据）

### 2.1 对话框分页状态机（nb_dialog.c）

```c
typedef struct {
    const char *text;        /* 剧本行全文（多页时不变） */
    int         text_offset; /* 双语义：渲染前=本页起点；渲染后被更新为本页 next（下页起点） */
    const char *charname;    /* 角色名（不参与分页/揭示） */
    int         pending;     /* 页在屏上，脚本须让位（阶段 2B） */
} DialogState;
```

`dialog_show(text)`（nb_dialog.c:31-94）：
- 首帧（`text_offset<0`）：`str_copy` 全文进 `dialog_text_buf[1024]`（UTF-8 安全截断，尾字节剥 CJK 续字节），`text_offset=0`；
- 置 `pending=1` → `layer_dialog_show()` → `layer_dialog_render_page(charname, text, text_offset)` 整页渲染；
- 渲染返回 `next`（下页起点）：`next>=0 → text_offset=next`（页留待下次翻页）；否则 `text_offset=-1, text=NULL`（末页收尾 → 下次点击 dismiss）；
- `dialog_layer_store_render(charname, text, text_offset)` 存渲染投影（供 bg/cg 换图 recompose 重画）。

**关键事实**：渲染前后 `text_offset` 语义不同——渲染时是"本页起点"，渲染后被覆写为"下一页起点（即本页尾 `next`）"。打字机的"本页起点"必须单独留存，不能复用 `text_offset`（详见 §3.2）。

### 2.2 让位/唤醒（nb.c）

`nb_process` pending 块（nb.c:379-389）：`pending` 且 `offset>=0` → 调 `dialog_show`（渲染下一页）+ 暂停；否则 → `nb_dialog_dismiss()` + `hal_mouse_update()` + `continue`（收尾）。dispatch 后（nb.c:463-466）同样带 pending 让位。AUTOEXIT 在 `dialog_show` 内直通（nb_dialog.c:77-81：渲染后 `text_offset=-1/text=NULL`，脚本无需输入跑完）。

### 2.3 整页渲染（layer_dialog.c）

`layer_dialog_render_page(name, text, off)`（layer_dialog.c:258-287）：`dialog_seed_base` + `dialog_paint_box` 后 `text_set_target(dialog_layer, ...)`，角色名直接画（`draw_text(name,0,...)`），正文 `draw_text(text, off, ...)` 从 `off` 起按宽度回绕画到缓冲末尾，返回 `next`。OOM 退化路径直写 VRAM。`dialog_layer_store_render`（:292-306）把 name/text/off 快照进投影。**渲染层一次画满整页**，无"截止字节"概念——打字机需在调用侧提供截断串（§3.4 方案 A）。

### 2.4 输入接缝（main.c wait loop，:144-191）

`!vm_delay_active() && !PROCESS` 时进 wait loop，每帧 `vblank_wait` + `hal_kbd_update` + `anim_tick` + `audio_tick`：
- 鼠标左键 `hal_mouse_was_clicked` → `vm_request_process()`；`KC_SPACE` / `KC_ENTER` / `KC_XFER` → 同（:186-191）；
- F5/F6/ESC/F7（:163-185）各自打断到保存/读档/主菜单/图层 dump——**不受 reveal 影响**（场景切换直接 reset）；
- 输入在 `anim_waiting()` 时被吞。

打字机接缝点：鼠标与确认键分支（:157-162 / :186-191）在 `vm_request_process()` 前先判"揭示未完成"。

### 2.5 设置（settings.h / settings_menu.c）

`GameSettings`（settings.h）：`dialog_style / button_style / version / blackletter_title / blackletter_dialog / lang`；`settings_load/save` 走 settings.txt；访问器 `settings_get_*`。设置菜单 `settings_menu_run`（:197-284）现有两行（Language、Start Game）：`menu_hittest`（:112-125）三元素（左箭头/右箭头/Start）、focus 状态机 `FOCUS_LANG / FOCUS_START`（键盘左右调值、上下移动、回车/点击确认）、`settings_menu_draw(full)` 三态（full=1 全量 / full=2 语言变更 / full=0 焦点变更；动态区 `menu_layer_erase_to_base` 擦后重绘、增量 commit+blit）。常量：`MENU_X=30`、`SEL_Y`（语言行）、`START_X / START_BY`（Start）、`LABEL_X / LABEL_AREA_W / GAP / ARROW_W` 等。

新增「Text Speed」行走现有骨架：新行坐标 + 新元素 id + 新 focus 态 + 动态擦除区。

### 2.6 i18n 强制（AGENTS §十四）

系统界面硬编码文案一律 `tr()` + 登记 `tools/naiz_conv/i18n_gen.py::SYSTEM_UI_KEYS` + 各语言 `sys_<lang>.txt` 译文，否则重生成时被标 `# ORPHANED` 失效。新增 "Text Speed" 标签/档位显示串必须走此规则。

## 3. 方案

### 3.1 功能语义（对齐 Ren'Py typewriter）

- 台词正文**逐字揭示**（UTF-8 字符为最小单位）；角色名整段先出、不逐字。
- 揭示进行中：**任意确认输入（鼠标左键 / SPACE / ENTER / XFER）＝立即显示完当前整页**，不翻页；再给一次确认才翻页/收尾。
- 揭示完成后：维持现状行为（该页等待点击翻页；末页点击 dismiss）。
- 每页都重演揭示（多页台词逐页逐字）。
- **速度四档**（settings 可调，见 §3.5）：`Instant`（整页直出＝关闭打字机）/ `16` / `32` / `64` 字/秒。默认 `32`。
- `AUTOEXIT` 构建不受影响：直通整页（不揭示、无逐字），无头测试语义零变化。

### 3.2 状态扩展（nb_dialog.c）

`DialogState` 增三字段：

```c
int page_start;    /* current page first byte offset (UTF-8 safe boundary) */
int reveal_end;    /* bytes revealed so far on this page (absolute offset) */
int reveal_active; /* 1 while the page is still revealing */
```

- `dialog_show` 渲染页面前记录 `page_start = 本次渲染起点`（首帧 0，翻页取 `text_offset`），渲染后 `reveal_end = page_start`、`reveal_active = 1`。角色名/对话框框整段先出，正文随后逐步揭示。
- `AUTOEXIT` 分支（offset=-1/text=NULL 直通）保持不置 `reveal_active`，揭示零开销。
- `nb_dialog_dismiss/reset` 一并清 `page_start/reveal_end/reveal_active`。

新接口（nb_dialog.h）：

```c
void nb_dialog_reveal_tick(void);   /* per-frame: advance reveal (call from main loop) */
int  nb_dialog_reveal_active(void); /* 1 if the current page is still revealing */
void nb_dialog_reveal_finish(void); /* instantly complete the current page (no page turn) */
```

### 3.3 逐字推进（reveal_tick）

- 速率来自 `settings_get_text_speed()`。`Instant=0`：任何揭示瞬间完成（`dialog_show` 后即收尾）。
- 非 Instant：每帧推进量 = `speed/60` 字（60Hz vblank）；非整除余数用 tick 累加；字符按 **UTF-8 步进**（lead byte 决定 1..3 字节）从 `reveal_end` 向后数。
- `reveal_end` 越界：以当前页 `next`（＝渲染后 `text_offset`）为上限收敛（防止跳过换行边界）。
- `reveal_end` 达到页尾 → `reveal_active=0`（页整显，等待确认翻页）。

### 3.4 揭示渲染（方案 A：调用侧截断串，不动 draw_text）

- 理由：渲染层 `draw_text` 的 `off` 是"起点"，无"终点"。改核心 `draw_text` 加 max 参数（方案 B）会影响多处调用点与回绕/计数逻辑，风险与收益不成比例，**否定**。
- 方案 A：`reveal_tick` 推进后（或确认即跳满时），调用侧构一段截断串并经既有渲染路径整页重画：

  ```
  从 dialog_text_buf 取 [page_start, reveal_end) 子串（≤1KB，栈缓冲），
  draw_text 以起点 0 渲染（相对页起点），textarea 尺寸/坐标与现状一致；
  同步 dialog_layer_store_render(截断串, 0)，保证 bg/cg 换图 recompose 重画的是"揭示态"；
  每次重画 = 整页（box+角色名+截断正文）画进合成缓冲并 blit 一次。
  ```

  复用 `anim_tick` 先例：动画帧每帧 blit。揭示窗短、重画频率 60Hz 与动画同一量级，性能可接受；OOM 退化路径（无合成缓冲直写 VRAM）同样走截断串，行为一致。
- 页起点用 `page_start`（§2.1 说明 `text_offset` 渲染后被覆写为 next，不能直接当起点用）。

### 3.5 速度设置（settings + 设置菜单）

- `GameSettings` 增 `unsigned char text_speed`（取值 0/16/32/64，默认 32）；settings.txt 行 `text_speed=32`，`settings_load` 解析/校验（未知值回退默认），`settings_save` 写回；读写接口 `settings_get_text_speed()` / `settings_set_text_speed()`。
- 设置菜单（settings_menu.c）加第三行 **Text Speed**：语言行与 Start 之间（建议 y = SEL_Y+30）；布局/`menu_hittest` 加左/右箭头元素（同语言行箭头几何）；focus 状态机扩为 `FOCUS_LANG → FOCUS_SPEED → FOCUS_START`（上下切换、左右调档）；`settings_menu_draw` 增 new 动态区擦除模式（新增 `SPEED_CLEAR_*` / 指示器擦除区宏）。
- 档位显示：`Instant` / `16/s` / `32/s` / `64/s`（i18n 串，§3.6）。
- 即时生效：修改后**作用于下一对话页**（当前揭示页保持不打断，避免跳变）。

### 3.6 i18n

- 新键登记 `SYSTEM_UI_KEYS`：`"Text Speed"`、`"Instant"`（档位名）。
- 各语言 `sys_<lang>.txt` 提供译文；空值运行时回退英文。

### 3.7 行为矩阵（落地后目检比对）

| 场景 | 揭示中点击 | 整页后点击 | 判定 |
|---|---|---|---|
| 单页台词 | 跳满整页（不翻页） | dismiss，剧本继续 | 与现状比多一次点击（**有意变更**） |
| 多页台词 | 跳满本页 | 渲染下一页并开始该页揭示 | 逐页重演 |
| Instant 档 | — | 同现状（1 次点击翻页/收尾） | 与现状完全一致 |
| AUTOEXIT | 无点击（直通整页） | — | 零变化 |
| F5/F6/ESC | 打断→场景切换 reset（关闭揭示） | 同左 | 零变化 |
| 鼠标 vs 键盘 | 语义一致 | 语义一致 | 一致 |
| bg/cg 换图（揭示中） | recompose 用截断投影重画揭示态 | — | 依赖 §3.4 投影同步 |

## 4. 落地清单（代码后续单独执行，本轮不动）

## 5. 复用与边界

- 复用：pending 让位（2B）、渲染投影 `dialog_layer_store_render`、`anim_tick` 挂点模式、`menu_layer` 设置菜单骨架、`SYSTEM_UI_KEYS` i18n 管线。
- 边界：**不改** `draw_text`/render 核心、**不改** VM/指令集、**不改** 存档格式、**不新增** NB 命令、**不触碰** `nb_process` 主流程（揭示完全在显示侧 + wait loop 消费层完成）。
- 揭示推进与 `anim_waiting`/`vm_delay` 不冲突：揭示只发生在 pending 让位（脚本已暂停）期间。

## 6. 明确不做（记录在案，防复发）

- 逐字美化的后续可选：角色名先出再渐变、变速曲线、逐字音效、非 60Hz 揭示调制——不做。
- 本文档仅覆盖打字机文字效果；超出此范围的一切功能不在本文档定义内，一律不做（遵循 AGENTS 至简至上原则）。
