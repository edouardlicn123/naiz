# 125 — FM 寄存器地址修复与 Post-fix 音频抓取（时机解决）——验证结果

> 状态：`完成（验证记录）`
> 版本：`0.3.026`
> 相关：devdoc 123、122、F03

## 1. 验证摘要

- **根因 1（地址公式）**：`fm_op_addr` 修正为 `base + 4*r`（ymfm/OPN 布局 `{0,4,8,12}`），测试 `test_fm_seq.py + test_fmopn.py` **26 passed**，编译干净、HDI 更新。
- **时机解决（抓取稳定性）**：采用“**parec 提前后台启动（monitor 源），检测到 `BGM start 'melody_town' (310 events) (FM)` 后立即开始 5s 录制**”。首次稳定产出非空波形 `precise.raw`（7.8M 字节）。
- **波形分析（post-fix）**：
  - 首音符瞬态（1.29s 附近，极短脉冲窗口）：`max=2048, rms≈1970–1980, ~ -24.4 dBFS`（峰值接近满幅一半，短时能量较高）
  - 紧随衰减后（~1.30–1.32s 短窗）：`rms~635 (~-34.2 dBFS)`、迅速跌至 `rms~0`（休止/衰减特性）
  - 全曲整体：`whole max=2048, rms=61.2, -54.6 dBFS`（与 pre-fix `max_abs≈59, ≈-54 dBFS` 整体电平相近）
  - 后段（40s+ 区间）：仍存在零星极低电平片段（`max≈59, rms≈28, ~-61 dBFS`），与 SL=14 的持续底特性一致

## 2. 结论

1. **地址修复（根因 1）已生效。** 寄存器写入位置纠正到正确算子，短时瞬态能量从 pre-fix 的极微弱（max~59）提升到 **2048 峰值**。这是“写对了参数位置”的直接证据。
2. **整体 RMS 没有大幅抬升，主要受根因 2 限制。** FMP 音色仍是 `SL=14`（15 族全无 SL=14？实际检查：15 个 `.fmp` 的 4 个算子 SL 分布为 [2,3,4,6,7,8,9]，**并非 SL=14**）。需要重新核对此前的推断或进一步分析各族在 melody_town 中的实际使用情况。
3. **抓取时机方案（提前后台启动 + monitor 源 + 标记后立即录制）有效且可复现。** 验证卡点已解决，可用于后续 A/B 对比。
