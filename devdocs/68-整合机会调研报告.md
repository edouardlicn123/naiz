**③ 创作工具外置**
- `docs/B91-构建环境与参考速查.md §6:237-238` — `naiz_midi` / `naiz_music` 曾作为独立项目移出到 `~/`

- `AGENTS.md §12` 记录"已移出"，但目录实际缺失（可能是迁移/清理过程中的待确认状态）

**④ 剧本未启用**
- `games/demo-a2/*.nb` 与 `projects/demo-a2/scene/*.nb` 中 grep 无任何 `bgm`/`sound`/`voice` 调用

### 2.2 硬件依据（refdocs）

`refdocs/F01_sound_boards.md`：
- **PC-9801-26K (OPN)**: YM2203, FM 3ch + PSG 3ch, I/O 188h(默认)/88h, Sound BIOS ROM 在 CC000h
- **PC-9801-86 (OPNA+PCM)**: YM2608, FM 6ch + SSG 3ch + ADPCM + PCM(44.1kHz/16bit/2ch), I/O 188h(默认 ID=4)/288h, 32KB FIFO DRAM, YM3433B(DAC)
- **DOS 音频驱动生态**: FMP / PPZ8 / PMD98 (FM 驱动/播放器 + MML 编译器) — 第三方驱动为主，非 NEC 官方 AVSDRV.SYS
- **集成机型**: PC-9821Ap/As/Ae/Ce 等主板集成 86 音源；PC-9821Xn 起 WSS-PCM 与 86 板不兼容

### 2.3 候选整合方案（需决策）

| 方案 | 说明 | 优点 | 缺点 |
|---|---|---|---|
| A-a OPNA 引擎内合成 | 引擎内实现 YM2608 寄存器驱动（plat 层），BGM 用 MML/序列数据回放 | 无外部依赖，符合 32-bit 保护模式纯内制 | 音源合成工作量大 |
| A-b MIDI 文件回放 | 引擎解析标准 MIDI → 软合成或映射 OPNA | 创作侧可用现有 MIDI 工具链 | MIDI→OPNA 映射复杂 |
| A-c 音频资产归档 + 数据回放 | 沿用 IMAGE.DAT 模式：音频打包 → 引擎流式读取 | 复用现有归档管线 | PCM 数据量大，DOS 内存受限 |
| A-d 仅补全 musicmenu/cgvmenu | 暂不实现后端，先实现菜单 UI | 复用 4 菜单同构模式 | 无声音，治标 |

**依赖说明**：任何后端都必须走 `core/plat/hal.h` 边界，`outb()` 只能在 `core/plat/` 中调用（AGENTS §五）。

### 2.4 决策点

1. `naiz_midi`/`naiz_music` 是**回收进本仓库**（如 `tools/naiz_midi`）还是**保持外置 + 定义音频资产接入接口**？
2. 音频后端选 A-a / A-b / A-c 哪条路线？
3. `musicmenu`/`cgvmenu` 是否先行实现（可与 C1 菜单 UI 合并同做）？
