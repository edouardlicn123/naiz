## §三 既有模式复盘（先读后写依据）

- **桥接模式**：mainmenu.nb = `sceneconf(){, menu}` + `bg(...)` + `mainmenu(...)`（阻塞）。loadscene.nb = `sceneconf(){, menu}` + `bg(yellow_grid)` + `loadscene()`（阻塞 save_load_menu）。cgview.nb 照抄同构。
- **命令阻塞期间输入**：cmd 执行时 vm 处于 PROCESS 状态，main 循环（main.c:124-191）只在 `!vm_delay_active() && !(vm_get_flags() & VMFLAG_PROCESS)` 时进入等待分支；因此阻塞命令（save_load_menu、menu_show、未来 cgvmenu 网格）必须自理 ESC/点击。gallery 无游戏内 ESC→退出语义，退出统一 `nb_load("mainmenu.nb")`。
- **menu 场景类型**：`sceneconf(){, menu}` → `nb_is_menu_scene()` 为真（nb.c:203）→ main.c F5/F6 存档快捷键被禁用。画廊必须带 menu 类型。
- **nb_load 失败路径**：fopen 失败 → `vm_set_error()`（nb.c:155-158）→ nb_process 检测 VMFLAG_ERROR → `SCENE_STATUS_ERROR` → main loop `ENGINE_EXIT(1)`（main.c:134）。画廊路由无需额外错误处理——VM 层已有收尾。
- **菜单 UI 两阶段绘制**（AGENTS.md §十四）：入口全量绘制一次，循环内只增量改 + 光标；禁止循环内全量刷新。阶段 4 循环内零增量绘制，天然符合。

### C. `core/engine/nb_mainmenu.c` — cmd_cgvmenu 骨架（现第 107-111 行）

```c
/* cmd_cgvmenu — CG gallery menu (bridging script cgview.nb ends here).
 * Stage 4: skeleton — draw entry title/guides, then block on exit input.
 * Stage 5: fills grid traversal, unlock flags and paging inside this loop. */
void cmd_cgvmenu(int argc, const char **argv, const char *cmd_name)
{
    int running = 1;
    (void)argc; (void)argv; (void)cmd_name;

    NB_DEBUG("cgvmenu: CG gallery menu (Stage 4 skeleton)\r\n");

    hal_kbd_drain_advance();
    hal_mouse_erase_cursor();

    draw_text("CG GALLERY", 0, 20, 12, 240, 32, 1, PAL_WHITE);
    draw_text("Grid UI lands in Stage 5. ESC / SPACE / click to return.",
              0, 20, 44, 620, 60, 0, PAL_WHITE);

    hal_mouse_set_pos(LAYER_SCREEN_W / 2, LAYER_SCREEN_H / 2);
    hal_mouse_draw_cursor_force();

    while (running) {
        hal_kbd_update();
        hal_mouse_update();
        if (hal_kbd_is_down(KC_ESC) || hal_kbd_is_down(KC_ENTER) ||
            hal_kbd_is_down(KC_SPACE) || hal_kbd_is_down(KC_XFER))
            running = 0;
        if (hal_mouse_was_clicked(HAL_MOUSE_LBUTTON))
            running = 0;
        hal_mouse_draw_cursor();
    }
    hal_mouse_flush();
    nb_load("mainmenu.nb");
}
```

要点：

1. `hal_kbd_drain_advance()` 清主菜单确认键遗留（E8）。
2. `hal_mouse_erase_cursor()` → 全量绘制 → `hal_mouse_set_pos` 居中 → `hal_mouse_draw_cursor_force()`：入口两阶段绘制规范（§十四），避免旧光标残影（C17 防守）。
3. 循环体：键盘/鼠标读一遍、任一退出键置 running=0、仅画光标。阶段 5 在此处插入网格渲染 + 翻页 + 聚焦回看 + `sys_save_is_cg_unlocked` 判定。
4. 退出前 `hal_mouse_flush()`（镜像 save_load_menu:189），再 `nb_load("mainmenu.nb")`——nb_load 内部 scene_end 清屏重建，无残留。
5. 需要的头已齐：draw_text → render.h（nb_mainmenu.c:12 已含）、hal_* → hal.h、nb_load → nb.h、KC_* 常量和 hal_kbd_is_down/hal_mouse_* 均来自已有 include 链。无需新增 include。

## §五 边界与失败路径

| 路径 | 行为 |
|------|------|
| cgview.nb 不存在/读取失败 | nb_load → vm_set_error → SCENE_STATUS_ERROR → ENGINE_EXIT(1)，串口日志 `ERROR: cannot open file` |
| 主菜单按确认键进入时遗留键 | 入口 drain 清除，画廊不会闪退（E8） |
| 画廊内重复按键 | 每次 `hal_kbd_is_down` 语义消耗式读取，退出只发生一次；退出后 nb_load 重建新脚本 |
| 鼠标点击边缘 | 任意左键点击即退出，无区域判定（阶段 4 语义） |
| 阻塞期间 F5/F6 | menu 场景类型 → 被 main.c 条件 `!nb_is_menu_scene()` 挡掉 |
