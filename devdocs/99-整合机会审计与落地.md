# 99-整合机会审计与落地

> 版本：0.2.107（R29）
> 日期：2026-09-15
> 状态：已执行（P0 五项 + P1 两项全部落地）

## 1. 背景

R28 之后，`symbol_audit` A/B 节浮出 4 个 0 调用方导出，同时定向扫描发现跨文件/文件内存在大量
同一表达式、同一序列、同一安全拷贝惯用式的重复。按 R16 "拆分/封装机会落库"与 AGENTS §九.10
"先借后造"的精神，对引擎核心做一次全面的整合机会审计并落地。

本轮的治理原则：

1. **行为等价**：除 `str_copy` 一处有 26 处调用面外，其余全部是"合并重复定义 / 收敛惯用式 /
   清理死代码"，不做语义变更（`str_copy` 的差异点在 §5.6 单列并逐站核验）。
2. **单一事实源**：重复的几何计算收敛到 `scene_layers.h` 宏，重复的槽位表收敛为一份 static。
3. **命名空间收口**：R28 临时放在 nb_save_dialog.c 的 static helper 提升为图层模块公共 API。

## 2. 审计方法

- **静态层**：`python -m tools.diag.symbol_audit -s A,B,E` 抓死导出与拆分簇；
  审计规则（§十九）里 C13（unused static）/C14（日志）等已覆盖一部分，但**没有一条规则
  能抓"两个文件各写一份同一数组"或"同一表达式散落 13 处"**——这类重复只能靠文本扫描。
- **文本层**：Grep 特征表达式（`LAYER_DIALOG_X + LAYER_DIALOG_INDENT`、
  `LAYER_DIALOG_W - ... - RIGHT_INDENT`、`strncpy(... sizeof(...)-1)`、
  `menu_save_item_palette();`、`hal_kbd_drain_advance();` 等）统计命中次数与分布。
- **人工复核**：对每个候选读实际调用上下文，排除"几何不同不该合并"（页码指示器、按钮组合、
  best-slot 时间戳三类）与"结构不同不该强行抽函数"（settings 的 bg 前置、question/save_dialog
  走 dialog 盒）。

## 5. 实现细节与注意点

### 5.1 死导出清理（①）

- `layer_dialog_restore`：删除。R28 记的"符号保留供外部"在 0 调用方事实下不再成立，
  删除更利于 A/B 节归零；若未来需要"合成盖回 VRAM"，用 `dialog_layer_blit()` 直接表达。
- `menu_layer_pixels` / `menu_layer_is_open`：内部连调用方都没有，整段删除。
- `layer_bg_snapshot_valid`：内部代码不依赖该函数，只删函数与声明。

### 5.2 内容几何宏（②）

```c
#define LAYER_DIALOG_CONTENT_X  (LAYER_DIALOG_X + LAYER_DIALOG_INDENT)
#define LAYER_DIALOG_CONTENT_W  (LAYER_DIALOG_W - LAYER_DIALOG_INDENT - LAYER_DIALOG_RIGHT_INDENT)
#define LAYER_DIALOG_CONTENT_Y  (LAYER_DIALOG_Y + LAYER_DIALOG_TEXT_Y)
#define LAYER_DIALOG_CONTENT_H  (LAYER_DIALOG_H - LAYER_DIALOG_TEXT_Y - LAYER_DIALOG_BORDER)
```

nb_question 的 `QUESTION_INDENT` 额外偏移保留：`LAYER_DIALOG_CONTENT_X + QUESTION_INDENT`。

### 5.3 槽位内聚（③）

```c
#define SLOTS_PER_PAGE 4
static const int slot_row_y[SLOTS_PER_PAGE] = { 90, 146, 202, 258 };
static int slot_abs(int page, int row) { return page * SLOTS_PER_PAGE + row; }
```

`total_pages = (SAVE_SLOTS + SLOTS_PER_PAGE - 1) / SLOTS_PER_PAGE`。

### 5.4 干净盒收口（④）

```c
void layer_dialog_clear(void)
{
    layer_dialog_show();
    dialog_layer_blit();
}
```

nb_save_dialog 删除静态 helper 改调公共 API；nb_question 两行合一。

### 5.5 标题去重（⑤）

```
drawn = 0;
if (blackletter && !cjk) { m = image_load(tid); if (m) { blit; drawn = 1; mag_release(m); } }
if (!drawn) draw_title_large(...);
```

### 5.6 str_copy（⑥）

```c
char *str_copy(char *dst, size_t n, const char *src)
{
    if (n == 0) return dst;
    strncpy(dst, src, n - 1);
    dst[n - 1] = '\0';
    return dst;
}
```

**行为差异（已验证安全）**：原 `strncpy` 会零填充 dst 剩余字节，`str_copy` 不填充。26 个站点
全部为 struct 字段或栈数组，NUL 之后的字节不被任何读取路径依赖（读回均按 C 字符串语义）。
若未来出现依赖填充的站点需单独检查。

替换面：nb.c×8、save_io.c×2、save.c×4、settings.c×3、nb_mainmenu.c×1、nb_dialog.c×1、
nb_saveload.c×1、nb_save_dialog.c×2、layer_dialog.c×2、nb_commands.c×2。
其中 `sizeof(dst)-1` → `str_copy(dst, sizeof(dst), src)`；固定尺寸 `N-1` → `str_copy(dst, N, src)`。

### 5.7 菜单退出序列（⑦）

menu_show 两处返回路径的 `menu_restore_item_palette(); ...; menu_layer_close(1);`
统一为 `menu_layer_close(1); hal_mouse_flush(); menu_restore_item_palette();`
（与 saveload/cggallery 的 close→restore 约定一致；palette 还原只影响渲染映射，
顺序对可视结果无影响）。

## 7. 审计系统检讨（§8 详见）

本轮发现的可整合内容**大多不被现有 39 条规则 + symbol_audit A/B 节覆盖**：

1. **已覆盖**：死导出（4 项）→ `symbol_audit` B 节能抓到，但**无自动化门禁**——
   它属于 `start.sh audit`/fullaudit 的报告项，未被规则引擎判定为 violation。
2. **未覆盖**：表达式重复（13+7 处）、数组重复（slot_y/slot_ys）、双语句惯用式
   （strncpy+NUL 26 处、clean-box 2 落点）、顺序不一致（restore/close）。
   这些是"重复度/一致性"类问题，现行 39 条规则全部是"单点错误"型（越界/泄漏/NUL 缺失等），
   **架构上没有"重复计数/同构检测"能力**。

建议（见 §8.3）：新增轻量 HEUR 规则对"高重复表达式"设阈值告警，并把 A/B 节纳入
fullaudit 的失败判据。
