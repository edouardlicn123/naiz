# 181 — 对话框净底缓存：消灭每页/每帧的逐像素重建

> **状态**：**已实施**——2026-10-28
> **创建于**：2026-10-28
> **承接**：`devdocs/180`（中段预载入队——本篇修其验证后用户仍感知的"文字切换卡顿"）、`devdocs/111`（光标 splice 契约，净底缓存必须保持 composite 纯净）、`devdocs/96`（ruling A 重组存活）
> **影响**：`core/engine/layer_dialog.c`（净底缓存 + 失效点）、`tools/tests/test_dialog_box_cache.py`（新增 2 契约）

---

## 一、问题定义

180 落地后用户实测：**文字切换（翻页）时仍有卡顿**。

### 1.1 根因：翻页帧的确定性重绘成本

180 消灭了解码 hitch（概率性），但翻页帧还有一笔**每次必付**的账：对话框合成重建。

- `layer_dialog_render_page` 每次渲染都执行 `dialog_seed_base()`（55KB memcpy）+ `dialog_paint_box()`（**55,200 次逐像素填充循环**，emulated CPU 上 ~10-30ms）
- 该循环运行在：**每个打字机 reveal 帧** + **每次翻页**（且 `layer_dialog_show` 与 `render_page` 在翻页帧各跑一次 = 双份）
- 而框的像素在页与页之间**完全不变**——变的只有 occluder 底（立绘/背景）与 style

另两个每帧成本（`draw_text` 重绘已显文本、55KB VRAM 写）是语义必需，不动。

## 二、修复：净底缓存（clean-box cache）

新增堆缓冲 `dialog_box_base`（480×115，随 dialog 系列缓冲一起懒分配；OOM 时退化为原 seed+paint 路径）：

- **发布**：`dialog_box_base_sync()`——脏时重建（seed + paint 一次），随后一次 `memcpy` 把净底刷进 `dialog_layer`，再叠文本
- 三个渲染入口（`layer_dialog_show` / `layer_dialog_render_page` / `layer_dialog_recompose`）全部改走 sync
- **失效**（`dialog_box_base_dirty = 1`）仅两处：
  - `dialog_occluder_reset_base()`——立绘变更/背景切换改变了框下内容（`layer_sprite_sync_dialog_base` 先走这里再叠 sprite，单一咽喉）
  - `dlg_set_style()`——填充图样变了
  - **调色板不失效**：缓存存的是调色板**索引**，颜色在 VRAM 写出时解析（`dlg_update_palette` 只改 DAC）
- `layer_dialog_reset()` 释放缓存；光标 splice 仍只写一次性 `dialog_blit_tmp`，净底与 composite 纯净性不受影响（111 契约保持）

### 2.1 效果

| 场景 | 改前 | 改后 |
|---|---|---|
| 翻页帧 | seed memcpy + 55K 循环 ×2 + 文本 + blit | 55KB memcpy + 文本 + blit |
| 打字机帧 | seed memcpy + 55K 循环 + 文本 + blit | 55KB memcpy + 文本 + blit |
| 立绘变更帧 | 同上（重组路径） | 同上（失效一次后恢复缓存） |

预计每页/每帧省 ~10-30ms；翻页帧的残余成本收敛到一次 55KB memcpy + 一次 55KB VRAM 写（语义下限）。

## 三、验证

- `python3 -m pytest tools/tests/`：857 通过（851 基线 + 180 篇 4 条 + 本篇 2 条），15 失败 = 14 项既有类别 + 构建陈旧门（构建后转绿）
  - `test_box_cache_exists_and_renders_use_one_memcpy`：三个渲染入口必须走 `dialog_box_base_sync()`，paint 循环只许存在于缓存重建内（OOM 直写 VRAM 的 `dialog_paint_box(NULL, 0)` 降级路径保留）
  - `test_cache_invalidated_by_occluder_and_style_changes`：失效点必须是 occluder reset + style change 两处；调色板不得失效；reset 必须释放缓存
- `bash core/build.sh` 零诊断；`bash makegame.sh make demo-a2` 重打 HDI；NP2kai 无头冒烟通过
- 实机观感待用户确认：翻页与打字机应显著顺滑；若连点快速翻页仍偶有掉帧，残余为 55KB VRAM 写的语义下限

## 四、遗留

- `draw_text` 每帧重绘全部已显字形（reveal 增量绘制可再省，但动 `draw_text` 契约，收益递减，不做）
- 55KB VRAM 写是 R20 语义下限（对话框必须整体重写以保持 dither 伪透传），不动
