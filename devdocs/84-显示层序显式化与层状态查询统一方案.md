## 一、问题陈述

### 1.1 当前层序是隐式的

引擎的显示层按"谁先画谁后画"的隐式规则组织，没有显式定义：

```
VRAM 写入顺序（隐式）：
  1. bg         (vram_blit)           — 背景
  2. sprite     (vram_blit_sprite)    — 立绘，clip_h 保护对话框
  3. dialog     (fill_rect_pattern)   — 对话框边框+背景
  4. text       (draw_text)           — 对话文字
  5. animation  (vram_blit)           — 动画，可覆盖 1-4
  6. cursor     (cursor_render)       — 光标
```

问题：
- 新开发者无法从代码中快速理解层序关系
- 每个模块各自维护自己的"哪层可以写哪区域"的约定
- 添加新层类型（如字幕、转场效果）时没有参考框架

### 1.2 层状态查询分散且不一致

当前调用者需要手动查询层状态来决定操作路径：

| 查询函数 | 调用位置 | 用途 |
|---------|---------|------|
| `layer_dialog_drawn()` | nb_anim.c, layer_sprite.c, nb_commands.c, nb_dialog.c, nb_question.c | 判断对话框是否打开 |
| `layer_has_sprite(id)` | nb_commands.c, layer_sprite.c | 判断立绘是否存在 |
| `layer_bg_snapshot_valid()` | layer_bg.c | 判断背景快照是否有效 |

调用者必须在每个使用点手动查询状态，然后选择不同的操作路径：

```c
// nb_commands.c cmd_bg() — 调用者必须知道7步仪式
vram_blit(img, 0, 0);
if (!layer_dialog_drawn())        // 查询状态
    layer_capture_bg_dialog();    // 条件操作
layer_redraw_sprites();           // 固定操作
...
layer_capture_bg();               // 固定操作（隐式清除对话框状态）
```

```c
// nb_dialog.c dialog_show() — 调用者必须知道3步模式
if (!layer_dialog_drawn()) {      // 查询状态
    layer_dialog_open();          // 路径A
} else {
    layer_dialog_snap();          // 路径B
}
layer_dialog_restore();           // 固定操作
```

### 1.3 硬编码的层区域常量

对话框区域在多处硬编码或通过不同常量引用：

| 位置 | 常量/值 | 说明 |
|------|--------|------|
| scene_layers.h | `LAYER_DIALOG_Y = 280` | 对话框起始Y |
| scene_layers.h | `LAYER_DIALOG_X = 80` | 对话框起始X |
| scene_layers.h | `LAYER_DIALOG_W = 480` | 对话框宽度 |
| scene_layers.h | `LAYER_DIALOG_H = 115` | 对话框高度 |
| nb_anim.c | `clip_h = LAYER_DIALOG_Y` | 动画裁剪 |
| layer_sprite.c | `calc_sprite_clip_h()` | 立绘裁剪 |

虽然大部分已使用常量，但缺乏统一的"层边界"概念。

## 二、方案：层序显式化 + 层状态查询统一

### 2.1 核心思路

1. **定义显式层序常量** — 在 `scene_layers.h` 中声明层序Z值
2. **统一层状态查询** — 用 `layer_is_active(z)` 替代分散的查询函数
3. **添加层边界查询** — 用 `layer_get_bounds(z)` 获取每层的可写区域
4. **添加层操作前置检查** — 用 `layer_can_blit_at(z, y)` 检查是否可写

### 2.2 层序常量定义

在 `scene_layers.h` 中添加：

```c
/*==== Layer Z-order (lower = drawn first, covered by higher) ==============*/
#define LAYER_Z_BG        0   /* 背景层：全屏640x400 */
#define LAYER_Z_SPRITE    1   /* 立绘层：最多16个精灵，clip_h保护对话框 */
#define LAYER_Z_ANIM      2   /* 动画层：clip_h限制在y<LAYER_DIALOG_Y */
#define LAYER_Z_DIALOG    3   /* 对话框层：(80,280) 480x115 */
#define LAYER_Z_TEXT      4   /* 文字层：在对话框内绘制文字 */
#define LAYER_Z_CURSOR    5   /* 光标层：最顶层，最后绘制 */
#define LAYER_Z_COUNT     6   /* 层总数 */
```

### 2.3 层状态查询函数

在 `scene_layers.h` 中声明，在 `layer.c` 中实现：

```c
/* 查询某层是否活跃（有内容显示） */
int  layer_is_active(int z_order);

/* 标记某层活跃/非活跃 */
void layer_set_active(int z_order, int active);
```

**实现逻辑**：

| z_order | is_active 判断条件 |
|---------|-------------------|
| LAYER_Z_BG | `layer_bg_snapshot_valid()` |
| LAYER_Z_SPRITE | 至少一个 `g_sprites[i].active` |
| LAYER_Z_ANIM | `anim_is_playing()`（需新增查询函数） |
| LAYER_Z_DIALOG | `layer_dialog_drawn()` |
| LAYER_Z_TEXT | `layer_dialog_drawn()`（文字与对话框联动） |
| LAYER_Z_CURSOR | 始终活跃 |

**内部状态存储**：

```c
/* layer.c */
static int g_layer_active[LAYER_Z_COUNT] = {0};
```

### 2.4 层边界查询函数

在 `scene_layers.h` 中声明：

```c
/* 层边界矩形 */
typedef struct {
    int x, y, w, h;
} LayerBounds;

/* 获取某层的可写区域 */
LayerBounds layer_get_bounds(int z_order);
```

**实现逻辑**：

| z_order | 返回值 |
|---------|--------|
| LAYER_Z_BG | `{0, 0, 640, 400}` |
| LAYER_Z_SPRITE | `{0, 0, 640, LAYER_DIALOG_Y}`（有对话框时裁剪） |
| LAYER_Z_ANIM | `{0, 0, 640, LAYER_DIALOG_Y}`（有对话框时裁剪） |
| LAYER_Z_DIALOG | `{LAYER_DIALOG_X, LAYER_DIALOG_Y, LAYER_DIALOG_W, LAYER_DIALOG_H}` |
| LAYER_Z_TEXT | `{LAYER_DIALOG_X + 16, LAYER_DIALOG_Y + 16, LAYER_DIALOG_W - 32, LAYER_DIALOG_H - 32}` |
| LAYER_Z_CURSOR | `{0, 0, 640, 400}`（光标可出现在任意位置） |

### 2.5 层操作前置检查函数

在 `scene_layers.h` 中声明：

```c
/* 检查在指定y坐标写入某层是否安全（不破坏更高层） */
int layer_can_blit_at(int z_order, int y);
```

**实现逻辑**：

```c
int layer_can_blit_at(int z_order, int y) {
    if (z_order == LAYER_Z_CURSOR)
        return 1;  /* 光标始终可写 */
    if (z_order == LAYER_Z_DIALOG || z_order == LAYER_Z_TEXT)
        return (y >= LAYER_DIALOG_Y);  /* 对话框/文字只在y>=280 */
    if (z_order == LAYER_Z_ANIM)
        return (!layer_is_active(LAYER_Z_DIALOG) || y < LAYER_DIALOG_Y);
    if (z_order == LAYER_Z_SPRITE)
        return (!layer_is_active(LAYER_Z_DIALOG) || y < LAYER_DIALOG_Y);
    if (z_order == LAYER_Z_BG)
        return 1;  /* 背景始终可写（被更高层覆盖） */
    return 0;
}
```

### 2.6 动画层查询函数

在 `nb_anim.h` 中声明，在 `nb_anim.c` 中实现：

```c
/* 查询动画是否正在播放 */
int anim_is_playing(void);
```

**实现**：

```c
int anim_is_playing(void) {
    return g_anim.active;
}
```

## 三、改动清单

### A. `scene_layers.h` — 新增层序常量和查询函数

```c
/* 新增：层序Z值定义 */
#define LAYER_Z_BG        0
#define LAYER_Z_SPRITE    1
#define LAYER_Z_ANIM      2
#define LAYER_Z_DIALOG    3
#define LAYER_Z_TEXT      4
#define LAYER_Z_CURSOR    5
#define LAYER_Z_COUNT     6

/* 新增：层边界结构体 */
typedef struct { int x, y, w, h; } LayerBounds;

/* 新增：层状态查询 */
int  layer_is_active(int z_order);
void layer_set_active(int z_order, int active);
LayerBounds layer_get_bounds(int z_order);
int  layer_can_blit_at(int z_order, int y);
```

### B. `layer.c` — 实现层状态管理

```c
static int g_layer_active[LAYER_Z_COUNT] = {0};

int layer_is_active(int z_order) {
    if (z_order < 0 || z_order >= LAYER_Z_COUNT)
        return 0;
    /* 动态层状态由各模块维护 */
    return g_layer_active[z_order];
}

void layer_set_active(int z_order, int active) {
    if (z_order >= 0 && z_order < LAYER_Z_COUNT)
        g_layer_active[z_order] = active;
}

LayerBounds layer_get_bounds(int z_order) {
    LayerBounds b = {0, 0, 640, 400};
    switch (z_order) {
    case LAYER_Z_BG:
        break;  /* 全屏 */
    case LAYER_Z_SPRITE:
    case LAYER_Z_ANIM:
        if (layer_is_active(LAYER_Z_DIALOG))
            b.h = LAYER_DIALOG_Y;  /* 裁剪到对话框上方 */
        break;
    case LAYER_Z_DIALOG:
        b.x = LAYER_DIALOG_X;
        b.y = LAYER_DIALOG_Y;
        b.w = LAYER_DIALOG_W;
        b.h = LAYER_DIALOG_H;
        break;
    case LAYER_Z_TEXT:
        b.x = LAYER_DIALOG_X + 16;
        b.y = LAYER_DIALOG_Y + 16;
        b.w = LAYER_DIALOG_W - 32;
        b.h = LAYER_DIALOG_H - 32;
        break;
    case LAYER_Z_CURSOR:
        break;  /* 全屏 */
    }
    return b;
}

int layer_can_blit_at(int z_order, int y) {
    if (z_order == LAYER_Z_CURSOR)
        return 1;
    if (z_order == LAYER_Z_DIALOG || z_order == LAYER_Z_TEXT)
        return (y >= LAYER_DIALOG_Y);
    if (z_order == LAYER_Z_ANIM || z_order == LAYER_Z_SPRITE)
        return (!layer_is_active(LAYER_Z_DIALOG) || y < LAYER_DIALOG_Y);
    return 1;
}
```

## 四、行为矩阵

| 层 | Z值 | 活跃条件 | 可写区域 | 被保护方式 |
|----|-----|---------|---------|-----------|
| 背景 | 0 | 有bg_snapshot | 全屏640x400 | 无（被高层覆盖） |
| 立绘 | 1 | 至少一个sprite.active | y<280（有对话框时） | clip_h |
| 动画 | 2 | anim_is_playing() | y<280（有对话框时） | clip_h |
| 对话框 | 3 | layer_dialog_drawn() | (80,280) 480x115 | prot_pal + anim_fill_border |
| 文字 | 4 | layer_dialog_drawn() | (96,296) 448x83 | 在对话框内绘制 |
| 光标 | 5 | 始终 | 全屏640x400 | save/restore |
