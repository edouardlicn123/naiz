## 1. FM3 压缩（FM3ex）—— 复音扩展 +2

- **描述**：YM2608 FM3 模式下 ch3 可拆 3 独立 2-op 声部，复音 6→8。naiz 现用普通 6 声部 +「最冷空闲」分配（c75）。
- **依据**：`F03 §7` 未确认项涉及 `$29`/`$27` 细节；需 ch3 专用寄存器语义（`$A4-$A6` 特殊模式）。
- **触发条件**：现曲实测复音挤压（icy_garden 三轨 >6 音并发现象）被用户听感判为问题；或未来素材明确需要。
- **量级**：中（分配器改造 + 寄存器模式切换 + 测试矩阵）。
- **风险**：高（FM3 模式寄存器语义复杂，`F03` 尚有未确认项；写错整 ch3 静音）。
- **依赖**：无；但与 `157` 分配器耦合（FM3 三子声部要进「最冷空闲」核算）。

## 2. PMD 式 fadeout 停止

- **描述**：`bgm(stop)` 由硬切改为 ~1s 音量渐出（PMD `pmd_fm_vol_out` 的 `fadeout_vol`，`fmdriver_pmd.c:1528-1636`：每 8ms −8/127，无重键）。
- **依据**：`158` A 节落地 CC7 载波 TL 路径后，fadeout = 「全局 vol 渐变 + 已有 TL 回写」的直接复用；PMD 有完整参考实现。
- **触发条件**：用户试听后认为场景切换的 BGM 硬切突兀（`scene()` → `audio_stop_all` 现为立即停）。
- **量级**：小-中（`audio_stop_all` 拆「开始渐出/立即停」两态；pump 内推进）。
- **风险**：低-中（渐出中场景已切、下一条 BGM 抢入的状态机要定义清楚）。
- **依赖**：**`158` A（CC7/TL 路径）**。

## 3. CC65/CC64 portamento（滑音）+ 弯音跨 block 归一

- **描述**：CC65 on + note-on 时向目标音高滑动；`pmd_blkfnum_normalize`（`fmdriver_pmd.c:1995-2068`）的 block 移位归一算法可防滑音/大弯音时 fnum 溢出（`FMOPN_FNUM_MAX=1023`，c66 后高端夹顶问题同源）。
- **依据**：MIDI 标准；PMD 算法蓝本齐备。
- **触发条件**：未来素材使用 portamento；或 bend range 放大（`158` C 的 ±12 声明生效后）实测出现高音区弯音失真。
- **量级**：中。
- **风险**：中（滑音时间曲线与 note 重叠语义要设计；跨 block 归一动共用音高路径）。
- **依赖**：`158` C（可变 bend range）；与 `160` 的调制步合流点相同。

## 4. 通道压力（0xD0）/复音压力颤音

- **描述**：channel pressure → 音高调制深度（与 CC1 取 max 或相加）；poly pressure 现状忽略（`fmseq.c:453-454` default）。
- **依据**：GM 惯例；`160` 的 LFO 框架落地后只需加一个深度源。
- **触发条件**：未来素材/键盘实录需要；现曲零使用。
- **量级**：小（依赖 `160`）。
- **风险**：低。
- **依赖**：**`160`（软件 LFO）**。

## 5. CC11 表情（与 CC7 分工）

- **描述**：CC11 动态表情 ≈ 逐事件音量包络；与 `158` A 的 CC7（静态混音）同机制叠加。
- **依据**：`158` A 的 TL 路径可直接复用；PMD `vol` 模型同源。
- **触发条件**：未来素材含渐强渐弱表情（AI 生成 MIDI 常见）；现曲无。
- **量级**：小（CC7 落地后）。
- **风险**：低-中（曲中高频 TL 回写对 pump 预算的影响要核算）。
- **依赖**：**`158` A**。
