## 一、系统总览

三块功能的依赖关系：

```
palette.c/h（纯原语：get_all/set_all/interp）
   ├──→ 转场系统 transition.c/pfade/blinds/checker  （画面上层，场景切换）
   └──→ NAIZ_ANIM 调色板轨（规划中：每帧 palette_set_all 换色）
NAIZ_ANIM 像素轨（规划中：整帧替换 + vblank 同步，独立于 palette）
```

- **palette 原语**：已实现（`core/engine/palette.c/h`），纯数据函数，供转场淡出与 NAIZ_ANIM 调色板轨复用。
- **转场系统**：已实现（`transition.c` 分发 + `transition_pfade.c`/`transition_blinds.c`/`transition_checker.c`），全部 palette 驱动，无逐像素 VRAM 覆盖。
- **NAIZ_ANIM**：规划中（本档 §四起），序列帧动画统一入口 `.ANI` 容器。

## 二、调色板原语（已实现）

### 2.1 API（`core/engine/palette.h`）

```c
#define PALETTE_SIZE 256
void palette_get_all(uint8_t pal[PALETTE_SIZE][3]);            /* 经 hal_read_palette 读全表 */
void palette_set_all(const uint8_t pal[PALETTE_SIZE][3]);      /* 经 hal_set_palette 写全表 */
void palette_interp(const uint8_t from[PALETTE_SIZE][3],
                    const uint8_t to[PALETTE_SIZE][3],
                    int step, int div, uint8_t out[PALETTE_SIZE][3]);
```

### 2.2 关键约定

- 数据布局固定 `uint8_t [256][3]`（{r,g,b} 序，index = 调色板索引），无动态分配、无越界风险（C1/C6/C9 天然满足）。
- `palette_interp` 整数运算，逐条目逐通道：`v = (from·(div-step) + to·step + div/2)/div`，div/2 舍入保证 step==div 时收敛到 to；`step` 先 clamp 到 `[0,div]`、`div<1` 时按 1 兜底，输出 clamp `[0,255]` 防溢出。
- **纯函数约束**：不写 vblank、不写鼠标、不写日志、无帧循环/阻塞逻辑——调用方（transition 阻塞驱动、NAIZ_ANIM 每帧换色）各自持有循环与时序。
- 调色板端口可读（gdc 端口 `0xA8(索引)/0xAA(g)/0xAC(r)/0xAE(b)`，`hal_read_palette`/`hal_set_palette` 封装，NP2kai 读回可靠）→ 无软件镜像需求。

## 三、转场系统（已实现）

### 3.1 类型表（`core/engine/transition.h`，当前代码）

```
TRANSITION_CUT       0   瞬时直切（无渐进）
TRANSITION_VBLINDS   1   竖向条带：细条增长至全黑
TRANSITION_HBLINDS   2   横向条带：细条增长至全黑
TRANSITION_DBLINDS   3   正向斜带扫掠
TRANSITION_RDBLINDS  4   反向斜带扫掠
TRANSITION_PFADE     5   调色板淡出：实时 palette 逐帧插值变暗
TRANSITION_CHECKER   6   棋盘错峰擦拭：方格呈错峰序逐格转黑
```

`transition_run(x, y, w, h, type, frames, color)`：阻塞式分发器（`transition.c`）：
1. `frames < 1` → 强制 1。
2. `type == TRANSITION_CUT` → `fill_rect(x,y,w,h,color)` 直填并 return（无渐进）。
3. 其余类型循环 `frames` 步，步骤循环内 switch 分派各 family 每步绘制，之后每步统一 `hal_vblank_wait()` + `hal_mouse_update()` + `hal_mouse_draw_cursor()`。
4. 未知 type → `NB_DEBUG` WARN（continue，不中断）。
5. 循环结束后兜底 `palette_set_all(transition_black)`：条带族整数取整可能差一点未覆盖远端，PFADE 末步向近黑插值，兜底保证整屏纯黑交接。

### 3.2 文件布局（C3 拆分，`core/engine/`）

| 文件 | 职责 |
|---|---|
| `transition.c` | 分发器（switch 各 family）；未知类型 `NB_DEBUG` WARN；末帧强制全黑 |
| `transition_pfade.c` | PFADE：首步 `palette_get_all` 捕获 basis，每步 `palette_interp(basis→black)` + `palette_set_all`；`transition_black[256][3]` |
| `transition_blinds.c` | `transition_pblinds_wipe`：条带增长遮挡 |
| `transition_checker.c` | `transition_checker_wipe`：方格错峰转黑 |
| `transition_internal.h` | 子系统内部共享声明（family 函数 + transition_black） |

### 3.3 分族实现要点

- **PFADE**（`transition_pfade_solid`）：全屏统一渐暗，无逐像素 VRAM 写。`step==0` 时 `palette_get_all(pfade_basis)` 捕获现场 256 条为基准；每步 `palette_interp(basis, black, step, frames, cur)` + `palette_set_all(cur)`。`basis` 首帧捕获后中途禁止外来 palette 写（脚本阻塞段已隔离）。**不写 VRAM 像素 → 背景像素索引不动，只改查表颜色**。
- **BLINDS（V/H/D/RD）**（`transition_pblinds_wipe`）：`PBLINDS_BANDS 20`（实施值；devdoc 75 设计稿为 8，实施已复核改动）。条带周期 `period = (type==HBLINDS) ? h/20 : w/20`（`period<1`→1）。每步计算条带前沿位移 `front = step·period/frames`（载入 `front_prev→front_cur`，clamp ≤period），差值 `delta = front_cur - front_prev`（≤0 直接 return，仅画新覆盖格）；V/H 按周期循环 `fill_rect × 20`，D/RD 走 `fill_diag_sweep` 单遍扫描原语（省去数千次 bank 切换）。
  - 轴定义：VBLINDS = `(col-x)`，HBLINDS = `(row-y)`，DBLINDS = `(col-x)+row`，RDBLINDS = `(col-x)+(h-1-row)`；像素当 `(pos % period) < front` 时被涂黑 → 20 条细条同步从起始边增长至全黑，场景保留到条带覆盖为止。
- **CHECKER**（`transition_checker_wipe`）：`CHK_CELL 40` 方格（640×400 恰为 16×10 格；不可整除时尾格 clamp）。格 (i,j) 秩 `r = i+j`，激活帧按秩分两波沿对角波前推进（`max_rank = (cols-1)+(rows-1)`）：
  - 偶秩格在时间轴前半：`act = (frames-1)·r / (2·max_rank)`
  - 奇秩格在时间轴后半：`act = (frames-1)·(max_rank+r) / (2·max_rank)`
  - act clamp 到 `[0, frames-1]`，`act != step` 的格跳过；同行格一次 `fill_rect` 填满。相邻格永远异色 → 波前全程保持棋盘纹理；末秩格必 ≤ 末帧触发，收尾全黑。
- **scene_end 链**（`layer.c:34`）：调用 `transition_run(0, 0, LAYER_SCREEN_W, LAYER_SCREEN_H, NAIZ_TRANSITION_TYPE, NAIZ_TRANSITION_FRAMES, 0)`；其后 `fill_rect(全屏黑)` 清屏保留（fade 后防 palette 恢复时旧画面闪现）。

### 3.4 配置链路（config.toml → nb_config.h）

```
projects/<game>/config.toml [transition]
  type   = "checker" | "cut" | "vblinds" | "hblinds" | "dblinds" | "rdblinds" | "pfade"
```

## 四、NAIZ_ANIM 序列帧动画（规划中，核心）

### 4.1 背景与需求

用一组静态图片按时间顺序连续展示得到动画（序列帧动画），面向"类似 galgame opening"的过场体验。

两类区域（type）：
- **fullscreen**：占满 640×400；对话框已开时走重建路径（§4.7）。
- **cine**：仅在对话框上方（y ≥ 0 且 y+h ≤ 280）播放，永不触碰对话框区域。

双轨（track）播放：
- **PIXEL**：每帧整图替换 + `vblank_wait()` 硬约束；帧间差异大的真动画。
- **PALETTE**：底图 blit 一次、每帧仅写调色板端口（循环首选、零撕裂）。

共同诉求：逐帧前进、一次性/循环、`waitanim` 阻塞与 NB 脚本同步、fps 可控。

### 4.2 调研结论（unlove / Love 参照）

`~/unlove`（Love = Escalator 反编译项目，`extracted/LOVE/EAR_FILES/`）实证：

| 格式 | 数量 | 事实（已实测） |
|---|---|---|
| `.ECG` | 702 | 单帧整图；头 4 字节魔数 **`5A 46 43 1A`（"ZFC\x1a"）**；~6–20KB/帧（原始 256KB，极高压缩率） |
| `.SPS` | 11 | 单文件打包多子图容器；子图头 `10 1c XX fa 00 10` 模式 |
| `.PCL` | 89 | 调色板重映射表：一串 `0x77 (from,to)` 索引对 |
| `.EQA` | 63 | 编排脚本（资源加载 + 跳转 + 调色板写命令 `52/50/54`），驱动 OP 逐帧切换 |

关键结论：
1. Love 动画主体 = SPS/ECG 打包容器 + PCL 调色板轨迹 + EQA 脚本驱动时序。
2. **上游 RE 完整性不足**（EQA 指令语义标"假设"、`STAGE_3/README` 明示"ECG 格式未知"）→ **Love 逐字节格式不可产出，位级兼容不可行**。
3. PCL/EQA 证实"调色板轨"思路真实有效：像素不动、只换调色板即 OP 动画主体。
4. 73 §四.2"OPTCG = 头部 N×u32 偏移表"与实测（偏移段长度 ≠ count）不完全吻合 → SPS 描述仅作**概念参考**。

### 4.3 naiz 侧管道约束（影响容器设计）

- `pack_images.py` 对 **ALL** img_map 条目构建**共享调色板**并逐图 remap；`image.c` 加载后 `image_set_palette` → **调色板轨每帧独立 256×3 表与共享调色板不变量冲突**。
- 结论：调色板轨的每帧调色板表**不能走 img_map/MAG 共享调色板路径**，必须存入 `.ANI` 容器内作为原始数据旁路。

### 4.4 帧数定义（60Hz 基准）

> **78 修订**：固定 fps 合法集已被**逐帧 tick 表**取代（`tick = max(1, round(sec×60))`，逐帧独立）；fps 字段退化为标称值（全帧等时长 → round(60/t)，变时长 → 0）。下表"默认与允许档"及 fps 校验细则随之作废。权威定义见 devdoc 78 §3.2/§4.3。

PC-98 640×400 非隔行 = 垂直同步 ≈60Hz；引擎以 `hal_vblank_wait()` 为节拍 → 上限 60fps。

**fps 合法集**：`{ 1, 2, 3, 4, 5, 6, 10, 12, 15, 20, 30, 60 }`（60 的整约数，`tick=60/fps` 恒整数，60Hz CRT 无 cadence 抖动）。

- 非约数（如 24）：**拒绝**。导入器导出时报错；引擎 `anim_start` 二次校验 `hal_log` 拒播。
- `{1..6}` 慢节奏仅限调色板轨循环特效（呼吸/闪烁/明暗），导入器输出警告。

**tick 语义**：`anim_tick()` 每 `nb_process()` 帧首被调；`g_anim.tick` 初值 = `60/fps`，每 tick 调用递减，减至 0 触发一次换帧并重装 `tick = 60/fps`。fps 必须整除 60 使重装值恒整数——整除性验证即由此公式得来。

**默认与允许档**：

| type | track | 默认 fps | 允许档 | 备注 |
|---|---|---|---|---|
| fullscreen | PIXEL | 12 | 10 / 12 / 15 | 全帧 MAG 解码 + 整幅 blit 需多个 vsync 窗口，486 上限档 |
| fullscreen | PALETTE | 30 | 30 / 60 | 每帧仅调色板端口写（≤768 字节），可满帧 |
| cine | PIXEL | 20 | 15 / 20 / 30 | 区域小、blit 快 |
| cine | PALETTE | 30 | 30 / 60 | 同全屏调色板轨 |

### 4.5 .ANI 容器格式（v1，全小端）

> **78 修订**：容器 v1 区段顺序改为 **偏移表 → MAG 块 → tick 表（nframes×u16）→ 调色板表**；本节装载校验表 #3（fps ∈ 60 约数集）取消，新增 tick ≥1 校验。权威定义见 devdoc 78 §4.1–§4.4。

```
Header（28 字节）
  0x00  magic   u32   0x5A494E41  ("ANIZ")
  0x04  version u16   1
  0x06  type    u8    0=fullscreen / 1=cine
  0x07  track   u8    0=pixel / 1=palette
  0x08  fps     u8    须为 60 的整约数（§4.4）
  0x09  loop    u8    0=一次 / 1=循环
  0x0A  nframes u16   帧数
  0x0C  w       u16   帧宽（导入校验用）
  0x0E  h       u16   帧高
  0x10  palsz   u32   palette 轨 = nframes×768；pixel = 0
  0x14  nblob   u32   数据块数：pixel = nframes；palette = 1（仅底图）

帧偏移表   nblob × u32      各 MAG 数据块首字节（相对文件头）
帧数据     nblob × MAG      MAG 编码帧（复用 mag_codec；pixel 帧共享场景调色板语义=SPR）
调色板表   [palette 轨]     nframes × 256 × 3 原始 RGB（旁路共享调色板不变量）
```

说明：
- PIXEL 轨：每块 = 一帧 MAG（帧共享场景调色板语义）；`palsz=0`。
- PALETTE 轨：仅一块底图 MAG + 尾部 per-frame 调色板表；换帧只读表。
- 尺寸/type/track/fps/loop 均以容器头为准（脚本不传 track/fps）。

**装载校验细则**（引擎侧 `anim_load`，防畸形 .ANI，C6/C24）：

| # | 校验 | 失败处理 |
|---|---|---|
| 1 | magic == 0x5A494E41 且 version == 1 | 拒载 + `hal_log` |
| 2 | type ≤ 1、track ≤ 1 | 拒载 + `hal_log` |
| 3 | fps ∈ 60 约数集（§4.4） | 拒播 + `hal_log`（导入器已拦，双保险） |
| 4 | nframes ≥ 1；palette 轨 nblob==1 / pixel 轨 nblob==nframes | 拒载 + `hal_log` |
| 5 | palsz == track 对应值（palette=nframes×768 / pixel=0） | 拒载 + `hal_log` |
| 6 | 偏移表逐项：offset ≥ 28+nblob×4 且 offset < 文件大小；末块 offset+块长 ≤ 文件大小（MAG 块长由其头解析） | 拒载 + `hal_log` |
| 7 | 帧尺寸 w×h 与 type 匹配（fullscreen=640×400）；cine 时 y+h ≤ LAYER_DIALOG_Y 由启动参数另行校验 | 拒启 + `hal_log` |

全部校验通过才置 active；任何一步失败即整体放弃，不留半初始化状态。

### 4.6 数据管线

> **78 修订**：素材组织与导入器已重设计——naizbook 脚本驱动（`animation/naizbook/<名>.nb`，`animconf`/`frame`/`base`/`pal` 命令）、素材在 `assets/aniframe/<动画名>/`、pal 文件为**显式索引 4 列**（`<index> <R> <G> <B>`）稀疏差异格式、CLI 改为 `anim_import <script.nb> [--out] [--project GAME]`、产物写 `animation/output/`（不入 ASSETS.DB）。本节以下内容仅存历史设计稿。权威定义见 devdoc 78 §二/§三/§5.3。

**素材组织**（内容方输入）：
```
PIXEL 轨：  projects/<game>/anim/<片段名>/frame_001.PNG  frame_002.PNG …
PALETTE 轨：projects/<game>/anim/<片段名>/base.PNG  pal_001.pal  pal_002.pal …
```
- 文件名按字典序即播放顺序（建议两位以上补零）；同段帧尺寸一致（fullscreen=640×400；cine 任意）。
- `pal_*.pal`：每帧 256 行 "R G B"；可只含差异条目，工具补全为完整 256 表。

**anim_import.py**（新增 `tools/naiz_build/`）：
- 入参：`<project> <anim_dir> --name <名字> [--type fullscreen|cine] [--track pixel|palette] [--fps N] [--loop]`

### 4.7 引擎设计

**新文件**：`core/engine/nb_anim.h` / `nb_anim.c`（命令注册进 cmd_table，独立文件先例：nb_scene.c/nb_question.c）；动画表照已有资产表生成。

**类型与状态**：
```c
typedef enum { ANIM_TYPE_FULLSCREEN = 0, ANIM_TYPE_CINE = 1 } AnimDefType;
typedef enum { ANIM_TRACK_PIXEL = 0, ANIM_TRACK_PALETTE = 1 } AnimTrackType;

typedef struct {
    int           active;
    const AnimDef *def;
    int           frame;        /* 当前帧下标（palette 轨 = 调色板表下标） */
    int           tick;         /* 帧间隔剩余计数 = 60/fps */
    AnimDefType   type;
    AnimTrackType track;
    int           x, y;         /* cine: 起始坐标；fullscreen: 固定 (0,0) */
    int           w, h;
    int           base_blitted; /* palette 轨：底图是否已 blit */
    MagImage     *img;          /* 当前帧 mag_retain 引用，收尾 release */
} AnimState;
static AnimState g_anim;        /* 全局单一活动动画 */
```

**image.c 容器读取辅助**：IMAGE.DAT TOC 无 type 字段 → 经 `anim_map` 拿 ANI asset id，用独立辅助按 id 取 TOC 原始块（校验落在 `g_image_data` 范围内）；ANI 条目不触发 `image_set_palette`。

**NB 命令**（注册进 cmd_table）：
- `anim(type, 名字, [x, y])`：type ∈ fullscreen/cine；查 anim 表启动（track/fps 取容器头）；已有活动动画先 `stopanim`；首帧立即绘制；cine 校验位置（越 280 拒启 + `hal_log`）。
- `waitanim`：阻塞语义（复用 `vm_pause_process` 风格）；停止/播完续行。
- `stopanim`：释放当前帧引用、清 active；fullscreen 后切静态背景时显式收尾。

**命令语义细则**：

| 命令 | 前置校验 | 成功路径 | 失败路径（均 `hal_log` + 脚本继续） |
|---|---|---|---|
| `anim` | 名字查表命中；cine 时 x≥0 且 y+h ≤ LAYER_DIALOG_Y；fps 合法 | 释放旧动画 → 装 AnimState → 立即绘首帧（PIXEL 含 vblank_wait） | 拒启，active 保持原状 |
| `waitanim` | 无活动动画时直接通过（幂等） | 暂停脚本进程，anim_tick 播完/停止时唤醒 | — |
| `stopanim` | 无活动动画时直接通过（幂等） | release 当前帧引用 → 清 active → waitanim 唤醒 | — |

**每帧推进**（`nb_process()` 帧首调 `anim_tick()`）：

> **78 修订提示（播放侧实施必读）**：容器 v1 已改逐帧 tick 表（devdoc 78 §4）——下述伪代码中 `g_anim.tick = 60 / fps` 的重装值应改为**按当前帧读取容器 tick 表 `ticks[frame]`**；`AnimState.tick` 初值装 `ticks[0]`，每次换帧重装 `ticks[新帧]`。fps 头字段仅标称显示用（变时长动画为 0，不可参与时序计算）。

```
anim_tick():
    if (!g_anim.active) return;
    if (--g_anim.tick > 0) return;
    g_anim.tick = 60 / fps;                  /* 重装间隔 */
    if (++g_anim.frame < nframes) { draw_frame(); return; }
    /* 末帧 */
    if (loop) {
        g_anim.frame = 0;
        draw_frame();                        /* 回卷后立即绘首帧 */
        /* PALETTE 轨回卷 = 继续读表换色，无额外动作；
           PIXEL 轨回卷同普通换帧（vblank_wait + blit）。
           回卷瞬间不触碰对话框快照（与普通换帧同一约束）。 */
    } else {
        anim_stop_internal();                /* release 引用、清 active、唤醒 waitanim */
        hal_log("anim: finished");
    }
```

**与 `bg` 的交互时序**：全屏动画期间静态背景快照（`bg_snapshot`）视为不可用——`bg` 命令若在动画活动时执行，先隐式 `anim_stop_internal()` 再载入新背景（引擎层保证，脚本无需手动 stop）；`scene_end` 本身转场+清屏已覆盖动画画面，但规范仍要求脚本显式 `stopanim` 以释放引用。

**换帧按 track 分派（draw_frame 内部）**：
- **PIXEL**：按 type 走下方像素路径（整帧 blit + 区域边界 + 对话框重建，blit 前 `vblank_wait()`）。
- **PALETTE**：每帧仅 `palette_set_all(每帧表)`；第一帧 blit 底图并置 `base_blitted`（含一次对话框重建）。

**对话框 × fullscreen/cine 交互**：
- **cine 像素轨**：`vblank_wait()` → `layer_bg_restore_rect` 恢复旧区 → `vram_blit_sprite`（clip_h 按 `calc_sprite_clip_h` 钳制，绝不写入 y ≥ LAYER_DIALOG_Y）→ 不触碰 dialog/bg_dialog snapshot。
- **fullscreen 像素轨**：`vblank_wait()` → `vram_blit(全幅)` → 若 `layer_dialog_drawn()` 执行对话框区域重建（更新 `bg_dialog_snapshot`/伪半透明合成/文本重绘/即时重截取快照）——**不得复用动画前过期快照**。
- **调色板轨**（type 任意）：仅底图 blit 时执行一次重建；之后每帧只换色，对话框随整体变色，快照保持有效。
- **通用硬约束**：任何动 VRAM 像素的帧 blit 前必须 `vblank_wait()`。
- 全屏动画期间 `bg`/`scene_end` 会破坏动画源 → 脚本须先 `stopanim`。

**fullscreen + 对话框已开：每帧重建流程（伪代码）**：

```
rebuild_dialog_over_anim():
    /* 1. 背景快照更新：从当前动画帧截取对话框区域 */
    layer_capture_bg_dialog();           /* bg_dialog_snapshot ← 动画帧对话框区 */
    /* 2. 伪半透明合成：PAT75 抖动填充 + 白边框 */
    scene_draw_dialog();
    /* 3. 文本重绘：经 dialog_show 同一路径重放当前 charname/text */
    dialog_show(nb_dialog_get_charname(), nb_dialog_get_text());
    /* 4. 快照即时重截取，dialog_dirty 复位 */
    layer_recapture_dialog_snapshot();
    /* 任一步失败（如文本超长）按现有 dialog_show 错误路径处理，
       不得静默跳过——重建不完整会留下 ghost 残留。 */
```

状态机（两轨 × 对话框开合）：

| 状态 | PIXEL fullscreen | PIXEL cine | PALETTE（任意 type） |
|---|---|---|---|
| 动画启动、对话框未开 | 无重建；动画中 `dialog_show` 打开时起转入每帧重建 | 无重建；对话框照常打开（区域不相交） | 底图 blit 无重建；后续同左 |
| 动画启动、对话框已开 | 每帧执行 rebuild_dialog_over_anim | 不重建（cine 永不触 280 以下） | 仅底图 blit 时重建一次 |
| 动画中对话框打开 | 自打开帧起每帧重建 | 正常打开，无交互 | 正常打开；快照在底图 blit 后仍有效 |
| 动画停止/播完 | `bg` 重建静态背景与快照（§bg 时序） | 同左 | 同左 |

**内存策略**：
- **PIXEL**：容器一次装载（TOC 块指针），逐帧 `mag_decode` + `mag_retain`/`mag_release`，仅持当前帧。
- **PALETTE**：底图 `MagImage` 只取一次持有；每帧调色板表为容器内静态段（768B/帧）。
- 不做全帧预载；**LRU 例外**：动画帧**不经 image_cache**（避免逐帧污染 8 槽缓存）。

## 六、防复发要点（并集）

**转场 / palette**：
- PFADE 期间禁止任何外来 palette 写；`basis` 首步捕获，中途被改导致漂移。
- 末步强制 `palette_set_all(black)`：杜绝 step 溢出/整除残差导致个别条目非纯黑（消灭静默不黑）。
- blinds 条带索引 240–247 全程只在本族内使用；图像素材若占用仅瞬态覆盖，转场后 `image_load`/`dlg_update_palette` 恢复。
- C3 拆分后新增 family 函数必须同步 `transition_internal.h` 声明与 `transition.c` 分发 case + default WARN。

**NAIZ_ANIM**：
- 新 C 文件过 C1–C25（malloc 检查、数组边界、clip_h、引用释放路径等）。
- **cine 位置校验**：`y >= LAYER_DIALOG_Y` 或 `x < 0` 拒绝启动并 `hal_log`（C6/C14）。
- **cine blit 钳制**：可见高度 `min(h, LAYER_DIALOG_Y - y)`，绝不写入 y ≥ 280（对齐 AGENTS §十一）。
- **像素轨 blit 前必须 `vblank_wait()`**；PALETTE 后续换色仅写调色板端口，禁止动 VRAM 像素。
- **PALETTE 首帧**：`base_blitted` 不置位不能换色；对话框重建只在底图 blit 时执行一次（C18 快路径副作用检查模式）。
- **fps 合法性**：导入器 + 引擎双重校验（60 约数集），非约数显式报错/拒播。（**78 修订**：60 约数集已废除——逐帧 tick 表取代固定 fps，校验改为容器 tick 表逐项 ≥1；fps 头字段仅标称值，变时长动画为 0）
- **shared-palette 旁路**：ANI 条目在 pack_images/export/build 全链路不得当作 IMG/SPR 处理。
- **fullscreen 对话框重建**：不得复用动画前 `dialog_snapshot`/`bg_dialog_snapshot` 过期快照；重建后即时重截取（消灭静默失败，明确日志）。
- `waitanim` 唤醒路径必须有明确日志。
- 新工具/扩展过 P1–P11。
