# 102-菜单UI整合机会审计与封装方案

> 版本：0.2.119（规划目标 0.2.120）
> 日期：2026-09-18
> 状态：**计划中** —— 本文档归档审计证据与 P1–P8 封装方案；源代码本轮未改动，待批准后按 §7 清单落地

## 1. 背景

对四个系统菜单（启动/选语言 `settings_menu.c`、主菜单 `nb_menu.c`+`nb_mainmenu.c`、
载入菜单 `nb_saveload.c`+`nb_save_dialog.c`、画廊 `nb_cggallery.c`）逐一核对输入循环、
绘制、命中测试与收尾逻辑，识别可封装/整合的重复内容。在 R29（devdoc 99）已完成的
"表达式/数组/惯用式收口"基础上，本轮聚焦**行为序列级与状态机级**的重复：

- 菜单退出收尾序列（close→flush→restore）跨 3 文件 5 处逐字重复；
- 分页条（`<`/`>`/`%d/%d`）与 Back 按钮在载入/画廊两处几何几乎一致；
- Yes/No 确认状态机在键盘路与鼠标路各写一遍；
- 2x 标题宽度公式独藏在画廊 static；
- 10 语言表在 C 引擎与 2 个 Python 工具三处漂移；
- 保存菜单的网格导航 / 行列换算文件内重复。

治理原则沿用 devdoc 99：**行为等价**（除 P5 工具侧与 P4 标题居中公式外无语义变更）、
**单一事实源**、**外科手术**（不强行统一布局不同的控件）。

## 3. 审计产出（证据）

### 3.1 菜单退出收尾序列（5 处 / 3 文件）

`menu_layer_close(1); hal_mouse_flush(); menu_restore_item_palette();` 的"退出契约"
在注释里被口头约定为"共享"，但实际散落：

| 文件:行 | 序列 |
|---|---|
| nb_menu.c:164-166 | mouse 命中退出 |
| nb_menu.c:241-243 | 键盘确认退出 |
| nb_saveload.c:428-429 | 缺 `hal_mouse_flush()`（不一致）|
| nb_cggallery.c:376-378 | 后接 `gallery_palette_restore()` |

R29（devdoc 99 §5.7）只把 menu_show 两处顺序对齐为 close→flush→restore，未收口为函数。

### 3.2 分页条 + Back 按钮（载入 vs 画廊）

载入 `nb_saveload.c:147-153`（箭头擦带 56/576,318,16,16 + 计数器 310,330）、
画廊 `nb_cggallery.c:146-149`（整带擦除）+`:166-169`（箭头 56/576,370,16,16 + 计数器 308,370）：

| 元素 | 载入 | 画廊 | 差异 |
|---|---|---|---|
| 前页箭头区 | (56,318,16,16) | (56,370,16,16) | 仅 y |
| 后页箭头区 | (576,318,16,16) | (576,370,16,16) | 仅 y |
| 页计数器 | x=310 | x=308 | 2px |
| fg | PAL_WHITE | GAL_FILL_LOCKED(=PAL_CURSOR_BLACK) | 色 |
| Back emboss | (66,352,80,30,4)+文本(90,359) | (66,356,80,30,4)+文本(76,363) | y=4px；画廊文本未居中 |

鼠标命中同样重复：载入 Back `:371`、箭头 `:381/:388`；画廊 Back `:339`、箭头 `:340/:343`。
键盘翻页 `page±±; sel/reset=0; 全量重绘; force; continue` 各 4 处。

### 3.3 Yes/No 确认状态机（键盘/鼠标两路重写）

| 文件 | 键盘路 | 鼠标路 |
|---|---|---|
| nb_saveload.c | :235-266 | :339-368（约 30 行，同逻辑二次实现）|
| nb_save_dialog.c | :79-97 | :135-151 |

LEFT/RIGHT 切 `confirm_yes`；ENTER-YES 执行（载入退出/保存刷新）；ENTER-NO / ESC 回列表；
鼠标点 Yes/No 按钮区等价。四段过渡逻辑**逐字同构**，仅按钮区和执行动作不同。

### 3.4 2x 标题宽度（独藏 static）

`nb_cggallery.c:85-97 gallery_title_width()`：`2*text_width + (n-1)*spacing`，与
`draw_title_large`（render_text.c:354）的 per-glyph advance 完全对应，本应是通用工具。
`nb_saveload.c:135` 标题现写死 `x=282`——已验算 `(640-(2*4*8+3*4))/2=282` 恰为
spacing=4 的居中结果，改公式零视觉变化。

### 3.5 语言表三处漂移

同一 10 语言表：`settings_menu.c:41-49`（LANG_NAMES/LANG_CODES）、`i18n_gen.py:26-29`
（VALID_LANGS，注释"must match engine"）、`gen_cjk_font.py:68`（RUNTIME_LANGS）。仅靠注释互相约束。

### 3.6 保存菜单文件内重复（nb_save_dialog.c）

- `row` 换行三目 `(row==2)?1:(row==1?0:2)` / `:0`（:100-102）晦涩且与鼠标 `rel_y/20`、
  `(mx-slot_start_x)/(CONTENT_W/6)` 行列换算（:130-134）为同一网格的两套实现；
- `slot_chapter_label` 三元 `si.chapter_title[0] ? ... : si.filename` 与 nb_saveload.c:88 重复。

### 3.7 同文件其它（nb_saveload.c）

- `slots_on_page` 夹逼（`SAVE_SLOTS - page*SLOTS_PER_PAGE` → clamp[1,SLOTS_PER_PAGE]）
  两处：`:268-270` 与 `:397-398`；
- `total_pages = (N+per-1)/per`：:204 与画廊 :280 同公式。

## 4. 封装方案 P1–P8

### P1 通用菜单收尾 `menu_finish()`

`nb_menu.c` 新增，声明进 `nb_internal.h`：

```c
void menu_finish(void)   /* menu_layer_close(1); hal_mouse_flush(); menu_restore_item_palette(); */
```

替换：nb_menu.c:164-166、:241-243 → `menu_finish();`
nb_saveload.c:428-429 → `menu_finish();`（补上缺的 flush）
nb_cggallery.c:376-378 → `menu_finish(); gallery_palette_restore();`
nb_question.c 无 menu_layer，不接入。

### P2 分页条 + Back 按钮 widget

全部放 `nb_menu.c`，声明进 `nb_internal.h`；绘制原语约定在
`menu_layer_begin_draw()` 与 `menu_layer_commit()` 之间调用（与 `draw_text` 同契约，
layer 未开时自动退化 VRAM）：

```c
void menu_pagenav_draw(int arrows_y, int count_y, uint8_t fg, int page, int total_pages);
    /* 擦 3 条带回 base（箭头 56/576,arrows_y,16,16；计数器 310,count_y,20,14），
       再画 < / > / "%d/%d"。计数器 x 归一为 310（画廊 308 → 310，2px）。 */
int  menu_page_hit(int arrows_y, int mx, int my);   /* 0 无 / 1 前页 / 2 后页 */
int  menu_pagecount(int count, int per);            /* (count+per-1)/per */

void menu_back_draw(int y, int focus, int emboss);  /* emboss(66,y,80,30,4)+居中 tr("Back")，
                                                       文本 x=66+(80-text_width)/2, y+7 */
int  menu_back_hit(int y, int mx, int my);          /* (66,y,80,30) */
```

调用面：
- `nb_saveload.c`：nav 传 (318,330,PAL_WHITE,...)，Back y=352，全量 emboss=1 / 增量 focus 切换 emboss=0；
- `nb_cggallery.c`：nav 传 (370,370,GAL_FILL_LOCKED,...)，Back y=356，同样全量/增量分流；
- 两处鼠标命中块替换为 `menu_page_hit` / `menu_back_hit`；
- 两处 `total_pages` 计算替换为 `menu_pagecount`（P6 合并）。

视觉副作用（已确认可接受）：画廊 Back 文本从 x=76 移到居中 x≈90（英文 "Back"
恰 =90，与载入一致）；画廊计数器右移 2px。

### P3 共享确认状态机 `menu_confirm_input()`

`nb_menu.c` 新增，声明进 `nb_internal.h`：

```c
enum { MENU_CONFIRM_TOGGLE=1, MENU_CONFIRM_CLOSED=2, MENU_CONFIRM_EXIT=3, MENU_CONFIRM_FAILED=4 };

/* 单次调用消化 confirm 态的全部输入（键盘 LEFT/RIGHT/ENTER/ESC + 鼠标点 Yes/No 按钮区）。
 * action(slot)：返回 1=成功退出菜单（load 流）；0=留在菜单刷新（save 流）；-1=操作失败。 */
int menu_confirm_input(int *confirm_yes, int slot,
                       int yes_x0, int no_x0, int y0, int y1,
                       int (*action)(int slot));

/* exit=True 时 action 返回 0 也会归入 EXIT（save_dialog 的 Yes 保存后即退出） */
```

调用面（两处循环的 confirm 分支重构为 `if (confirm) { 调 helper 并按返回码重绘/退出 }
else { 原列表 kbd+mouse }`）：
- `nb_saveload.c`：yes_x0=250, no_x0=330, y0=370, y1=392；
  `action` = 静态包装 `save_load_exec(slot)`：is_load 时 `load_game_slot` 成功→1、
  失败→-1（FAILED 由调用方 `show_error_msg`）；save 时 `save_game_slot`+`slot_cache_page=-1`→0。
- `nb_save_dialog.c`：yes_x0=`content_x+80`, no_x0=`content_x+200`, y0=`dlg_cy+60`,
  y1=`dlg_cy+80`，`exit=True`；`action` = `save_game_slot`→1。

「Overwrite Slot %d?」 / 「Load|Save to Slot %d?」提示语留在各调用方，不并入（文案上下文不同）。

### P4 标题宽度通用化 `text_title_width()`

`render_text.c` 新增、声明进 `render.h`：

```c
int text_title_width(const char *s, int spacing);   /* 迁入 gallery_title_width 逻辑 */
```

载入标题 :135 改 `x=(LAYER_SCREEN_W-text_title_width(str,4))/2`（验算现 282 恰为居中，零视觉差）。

### P5 语言表单一事实源（tools 侧）

### P6 nb_saveload.c 文件内小去重

### P8 nb_save_dialog.c 网格导航去重

## 5. 断言不整合（记录在案，避免将来重复评估）

- **settings_menu 的 `draw_text_outlined`**（:84-95）：独一份，无重复对象，保留 static；
- **menu_show 按钮网格**：已是合格通用 widget（唯一调用方 cmd_mainmenu），不动；
- **show_error_msg**（nb_saveload.c:43-55）：仅载入流用，暂不泛化；
- **全屏 save_load vs 对话框内 save_dialog 两套槽位布局**：UX 不同（载入是全屏系统菜单，
  F5 是对话内瞬态覆盖层，退出须还原剧情文本），不合一；
- **对话框区改 menu_layer 承载**：close 只还原"干净框"快照，省不掉文本重绘步骤，纯风格改动，不做；
- **保存菜单的 Back**（网格第 3 行文字 row==2 语义）与载入/画廊的 chrome Back 按钮语义不同，
  不并入 P2；
- **best-slot 时间戳查找**（nb_mainmenu.c:55-62）：独一份，不动。
