# 69 — 非开源内容审计与商业内容独立化方案

## 1. 背景

对 Naiz 仓库做全量内容审计，识别受版权保护/非开源（非 MIT）的二进制、字体、文档与镜像，评估独立化方案。动机：仓库主 LICENSE 为 MIT，但 AGENTS §十 明确"GPL v2 代码不得复制（传染性）"，README 声称引擎/工具链为全新书写 —— 需核实这些声明与仓库内第三方内容的边界。

审计范围：`git ls-files` 全量追踪文件（含 `!` 例外放行的 .hdi/.EXE/.ROM），按内容类型分组。

## 2. 审计结论

## 5. CJK 字体切换评估（暂缓）

### 5.1 当前状态

`tools/naiz_font/CJK.DAT`（magic `CJKF`）由 `gen_cjk_font.py` 从 **GNU Unifont `.hex`**（GPLv2+）生成。实际覆盖 6 个 range、共 3.2 万+ 字形：

```
U+0020..U+007E    Basic Latin（95）
U+3000..U+303F    CJK 标点（64）
U+3040..U+309F    平假名（96）
U+30A0..U+30FF    片假名（96）
U+4E00..U+9FFF    汉字（20992）
U+AC00..U+D7A3    韩文音节（11172）
```

### 5.2 GNU Unifont（GPLv2+）vs Noto Sans CJK（OFL 1.1）

| 维度 | GNU Unifont（当前） | Noto Sans CJK（候选） |
|---|---|---|
| 许可证 | GPLv2+（带字体嵌入例外） | SIL OFL 1.1（宽松，允许子集/嵌入/商业） |
| 传染风险 | 高。`CJK.DAT` 是 Unifont 衍生数据；游戏运行时资产分发时"嵌入例外"覆盖范围有解释空间 | 无传染，可自由分发 |
| 覆盖 | 全 Unicode 平面 | 44,806 字符 / 55 块（含 CJK 主平面 + Ext A–F、假名、韩文、拉丁），**完全覆盖当前 6 range，且更全** |
| 字形风格 | 点阵像素风，16×16 锐利 | 矢量黑体 → 16×16 光栅化可能发糊，需阈值/抗锯齿调优 |
| 生成方式 | `.hex` 位图直转（`gen_cjk_font.py` 现成） | `.otf` 矢量，需改 PIL 光栅化路径（`ttf2font.py` 可参考） |
| 源文件体积 | 无需额外源（生成产物已入库） | OTF 约 16–20MB |

**结论**：覆盖不是问题（Noto 更全）。唯一障碍是 16×16 光栅化质量与生成路径改造。

### 5.3 决策（用户确认）

- **暂缓切换**：不改变当前 CJK.DAT 与生成工具。
- **保留 `gen_cjk_font.py`（unifont 版）备用**。
- 后续如引擎开源分发，再评估：写 `gen_cjk_font_otf.py`（PIL 光栅化 Noto OTF → 16×16 位图，保留 6 range），生成后**人工目测验证**笔划密字清晰度。
- 语言变体候选：Noto Sans CJK SC（项目文案中文+英文 UI）。
