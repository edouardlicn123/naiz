## 一、目标

1. `naiz` 仓库只保留引擎、工具链、项目、素材、文档与 guildbook；`studio/` 成为独立仓库 `~/naiz-studio`。
2. Studio **必须与 naiz 仓库并列放置**在同一父目录，默认通过 `../naiz` 定位项目根。
3. guildbook（`guildbook_cn/`、`guildbook_en/`）与音频源（`assets/<game>/bgm/`）继续留在 naiz 仓库。
4. Python 虚拟环境统一为 `~/venv`，naiz 与 naiz-studio 共用一份，不再各自创建。
5. 主仓库 README 明确 GitHub 仓库指向；`naiz-studio` 新增英文 README，说明并列布局与共享 venv。
6. Studio 的 `audio_cache/` 仅作临时缓存，不迁移、不入库，缺失时从音频源重新生成。

## 三、venv 统一

### 3.1 路径

- 唯一目录：`$HOME/venv`
- 解释器：`$HOME/venv/bin/python3`
- Shell 唯一创建/安装入口：`tools/env_setup/ensure_venv.sh`
- Python 侧唯一常量来源：`tools/env_setup/env_utils.py` 的 `VENV_DIR` / `VENV_PYTHON`

### 3.2 直接引用点

| 文件 | 现状 | 目标 |
|---|---|---|
| `tools/env_setup/ensure_venv.sh` | `$ROOT/tools/env_setup/venv` | `$HOME/venv` |
| `tools/env_setup/env_utils.py` | 无 venv 常量 | 新增 `VENV_DIR = ~/venv`、`VENV_PYTHON` |
| `tools/env_setup/env_toolchains.py` | 从 `env_setup` 目录向上拼路径 | 引用 `env_utils.VENV_DIR` / `VENV_PYTHON` |
| `tools/naiz_build/build_game.py` | `ROOT/tools/env_setup/venv/bin/python3` | 引用 `env_setup.env_utils.VENV_PYTHON`，缺失时保留 `sys.executable` 回退 |
| `tools/naiz_lib/__init__.py` | `PROJECT_ROOT/tools/env_setup/venv` | 引用 `env_setup.env_utils.VENV_DIR` / `VENV_PYTHON` |
| `studio.sh` | 复用 naiz 的 `ensure_venv.sh`，缺失时回退系统 Python | 调用 `ensure_venv` 后强制使用 `$VENV_PYTHON`，不再回退 |

`start.sh`、`makegame.sh`、`anima.sh`、`market.sh` 只 source `ensure_venv.sh` 或使用导出的 `$VENV_PYTHON`，路径自动跟随，不改。

### 3.3 迁移方式

不直接 `mv` 旧 venv：venv 的 `pip` 等脚本 shebang 指向旧绝对路径，移动后不可靠。改为：

```bash
python3 -m venv ~/venv
~/venv/bin/pip install -r tools/env_setup/requirements.txt
```

验证依赖后删除旧 `tools/env_setup/venv`。

### 3.4 安装链路

```text
naiz/start.sh check|pip
  └─ install_env.py → env_toolchains.py → ~/venv

naiz/start.sh（首次）
  └─ ensure_venv.sh → python3 -m venv ~/venv
                    → pip install -r naiz/tools/env_setup/requirements.txt

naiz-studio/studio.sh
  └─ ../naiz/tools/env_setup/ensure_venv.sh → 复用 ~/venv
```

## 四、Studio 代码迁移

### 4.1 文件搬迁

- 搬迁：`studio/server.py`、`studio/midi_render.py`、`studio/static/`、`studio.sh`
- 不搬迁：`studio/audio_cache/`（临时缓存）、`studio/__pycache__/`（自动生成）
- 搬迁后删除主仓库 `studio/` 与 `studio.sh`

### 4.2 `server.py`

- 新增 `STUDIO_DIR = Path(__file__).resolve().parent`。
- 静态资源目录改为 `STUDIO_DIR / "static"`。
- `midi_render` 的 `sys.path` 改为 `STUDIO_DIR`。
- MIDI→WAV 缓存目录改为 `STUDIO_DIR / "audio_cache" / game`；源仍读 `ROOT/assets/<game>/bgm/`。
- `ROOT` 默认值改为 `STUDIO_DIR.parent / "naiz"`，可用 `--root` 或 `NAIZ_ROOT` 覆盖；仍校验 `ROOT/makegame.sh`。
- guildbook 路由继续从 `ROOT/guildbook_cn|en` 读取，不改。

### 4.3 `studio.sh`

- `STUDIO_DIR` 取脚本所在目录。
- 默认 `ROOT = STUDIO_DIR/../naiz`；支持 `--root` 与 `NAIZ_ROOT` 覆盖。
- 解析参数中的 `--root`，避免与传给 `server.py` 的 `--root` 重复。
- `source "$ROOT/tools/env_setup/ensure_venv.sh"` 后调用 `ensure_venv`，再以 `"$VENV_PYTHON"` 启动。
- 找不到 naiz 根时明确提示“需与 naiz 同父目录，或设置 NAIZ_ROOT / --root”。

### 4.4 `.gitignore`

`naiz-studio/.gitignore` 追加：

```gitignore
# Local temporary cache
audio_cache/
```
