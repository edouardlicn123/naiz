makegame.sh 使用说明

创建：2026-08-29
最后更新：2026-11-05

makegame.sh 是游戏数据构建脚本：把项目里的剧本、素材、配置打包成可在模拟器里运行的 HDI 镜像，并提供测试入口。引擎编译见 start.sh 的 Watcom 安装。日常最推荐直接运行、用数字菜单选择项目与操作；命令行子命令适合写进脚本或熟练后使用。

1. 交互式菜单（主要用法）

不带任何参数运行：

./makegame.sh

会进入两级菜单，每一步都输入数字并按回车：

  • 第一步：列出所有项目（如 1) demo-a2 …），选一个数字进入该项目。
  • 第二步：在该项目下选择操作，按数字选择：
序号操作
1makegame — 编译项目数据 + 制作 HDI（build + make，推荐）
2build — 只编译项目数据
3make — 只制作 HDI 镜像
4test — 启动 NP2kai 测试
5test --porttest — 串口硬件测试
6audio — 模拟器音频延迟设置（全局）
7pack — 切换打包方式（cmpack / openpack）
0返回上一级

菜单操作失败不会退出，会回到菜单让你重试。这种方式不用记命令和项目名，最适合日常使用。

新手提示：想跑起来看看效果，进项目后选「测试」那一项即可启动模拟器。

2. 命令行用法（进阶 / 脚本化）

熟练或要写进自动化脚本时，可直接跟子命令，跳过菜单：

./makegame.sh <子命令> <game> [选项] [--pack cmpack|openpack]
子命令作用
makegame <game>推荐：编译项目数据 + 制作 HDI（build + make 一步到位）
build <game>只编译项目数据：PNG→MAG、引擎、场景、IMAGE.DAT、运行时，并重新生成 nb_config.h
make <game>只制作 HDI 镜像：把 games/<game>/ 注入 disks/<game>.hdi
test <game> [--serial] [--porttest] [--auto]启动 NP2kai 测试
i18n-gen <game> [--force]生成/刷新国际化文本模板
audio模拟器音频延迟设置（全局，BGM 颤音/电流声）
pack [cmpack|openpack]查看/切换打包方式；带参数时写入 .naiz_pack 作为后续默认

两个防呆检查：

  • make 发现 games/<game>/engine.exe 落后于 core/ 下的引擎时会报错，避免把旧引擎打进 HDI。
  • test 发现 disks/<game>.hdi 比 games/<game>/engine.exe 旧时会报错，避免模拟器静默运行旧引擎。

3. 选项说明

3.1 全局打包选项

  • --pack cmpack：商业链，tools_commercial + DOS/4GW（默认）。
  • --pack openpack：开源链，tools_open + DOS/32A，extender 绑定进 EXE。
  • 优先级：--pack > 环境变量 NAIZ_PACK > 项目根 .naiz_pack > 自动探测（有 tools_commercial 用 cmpack，否则有 tools_open 用 openpack）。
  • pack 子命令可持久化选择：不带参数进入交互菜单，带参数则直接写入 .naiz_pack。

3.2 其它选项

  • <game>：项目目录名，位于 projects/<game>/（如 demo-a2）。
  • --serial：测试时通过串口输出调试信息（最可靠的排错通道）。
  • --porttest：只检测模拟器串口端口是否可用，不启动游戏。
  • --auto：若 games/<game>/engine_a.exe 存在，将其替换为 engine.exe 并重新注入 HDI 后再测试。
  • --force（i18n-gen）：忽略增量判断，强制重新生成文本。

4. 常见用法示例

# 交互菜单里选项目 → 选 1) makegame（推荐）
./makegame.sh
# 等效的命令行写法（编译数据 + 注入 HDI）：
./makegame.sh makegame demo-a2

# 分步执行：先编译数据，再打包 HDI
./makegame.sh build demo-a2
./makegame.sh make demo-a2

# 只重新打包 HDI（数据未变）
./makegame.sh make demo-a2

# 用串口模式在模拟器里跑起来看日志
./makegame.sh test demo-a2 --serial

# 切换到开源链并查看当前设置
./makegame.sh pack openpack
./makegame.sh pack
