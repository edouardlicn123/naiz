tag 场景锚点

创建：2026-11-05
最后更新：2026-11-05

tag() 在当前剧本里声明一个跳转锚点，供 jump 场景内跳转 与 jumpscene 跨场景跳转 定位。它本身没有任何运行时效果——脚本顺序执行到 tag 行时直接越过。

1. 语法

tag(name)
字段说明
name锚点名。只能是 ASCII 字母、数字、下划线（[A-Za-z0-9_]+），区分大小写
tag(m1)             ← 合法
tag(badge_01)       ← 合法（下划线）
tag(第一章)          ← 非法（非 ASCII 标识符）

2. 书写规则

  • 必须单独占一行：命令名与 ( 之间不能有空格，tag(m1) 与 tag (m1) 只有前者生效。
  • 行尾可以写 # 注释，例如 tag(m1) # 森林分支。
  • 同一场景内允许重复同名 tag：首个命中优先（从上往下扫描）。
  • tag 的作用域仅限当前场景文件；不同场景文件里的同名 tag 互不影响。
  • tag 不需要成对出现，也没有“跳回锚点”的隐式行为——回跳只是 jump 目标位于当前位置之前。
  • 构建期校验器只把括号内、独占一行的 tag(name) 收集为锚点；写进正文、注释或其它命令参数里的同名文本不会成为锚点。

3. 跳转落点

jump / jumpscene 命中某个 tag 后，执行位置是 tag 行的下一行；tag 行本身不会被执行（即使执行也是空操作）。

tag(branch_a)
host(){进入分支 A}   ← 跳转后从这里开始

因此 tag 通常写在某段剧情的“入口”上方。注意落到 tag 时，它前面的行不会补执行：若目标剧情需要特定背景/立绘/BGM，应把对应命令写在 tag 之后，而不是依赖 tag 之前已经“本该执行”的设置。跨场景落到 tag 时同理（见 sc22 §3）。

4. 构建期校验

  • jump 引用的 tag 必须存在于当前场景，否则校验器报错（不等到运行时）。
  • jumpscene 第三段给出的 tag 必须存在于目标场景，目标场景文件也必须存在。
  • 运行期兜底：万一 tag 缺失（例如脚本热改），引擎输出 WARN，不跳转，继续执行跳转命令的下一行；jumpscene 则从头播放目标场景。

5. 示例

# nbook001.nb
tag(m_start)
host(){清晨的森林}

jump(要去哪里？;森林,m_forest;城镇,m_town)

tag(m_forest)
bg(normal){forest}
host(){你走进了森林}

tag(m_town)
bg(normal){town}
host(){你来到了城镇}
