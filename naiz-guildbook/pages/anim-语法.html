动画脚本语法总览

创建：2026-08-29
最后更新：2026-08-29

本页用大白话讲清楚：怎么写那张分镜小本子（.na 文件）。它就像动画的「拍摄清单」——先写开场设定，再一行一行列出每一张画面（或每一次变色）。每个命令的详细写法见：animaconf / frame / base / pal。怎么生成动画见 制作工作流。

1. 小本子要用 .na 结尾

动画脚本的文件名必须以 .na 结尾（例如 眨眼.na）。这是和普通剧本文件（.nb）区分开的标记，写错后缀工具会拒绝处理。

2. 四种写法（命令）

写法用在哪种动画作用
animaconf(...)两种都用到开场设定：这段动画是全屏还是横条？是整图动画还是变色动画？属于哪个项目？
frame(...){...}整图动画放一张（或几张）画面，并写清楚停留几秒
base(){...}变色动画写出「变色前」的第一张底图
pal(...){...}变色动画写出每一次颜色该怎么变，以及停留几秒

括号里写数字或选项，大括号 { } 里写素材的「昵称」（就是你在登记时起的名字）。

3. 几个通用的小规矩

  • 开场设定放最前面：animaconf 必须是小本子的第一行（前面可以空行或写 # 备注）。
  • 整图动画用 frame；变色动画用 base + pal。两者不要混用。
  • 变色动画里，base 必须写在 pal 前面（先有底图，再有变化）。
  • 大括号里可以写多个昵称，用逗号分开，例如 {云1,云2,云3}——它们会一张接一张轮流播放，且共用同一个停留时间。
  • 行末加 # 可以写备注（例如 frame(0.3){云1} # 飘一下），工具会忽略备注，不影响动画。

4. 写动画时容易踩的坑（排错小抄）

工具报错时会告诉你「第几行、出了什么问题」。下面把常见情况翻译成人话：

现象通常是……
提示「脚本须为 .na 后缀」文件名没以 .na 结尾，改一下文件名就好
提示 animaconf 有问题开场设定忘了写、写了两次，或写在不是第一行的位置
提示区域/类型/项目名不对animaconf 里的选项拼错，或对应的项目文件夹不存在
提示「跨轨」或命令用错地方整图动画里混入了 base/pal，或变色动画里写了 frame（两者别混）
提示缺少画面 / 缺少底图整图动画至少要有 1 个 frame；变色动画要有 1 个 base 和至少 1 个 pal
提示「未登记的名字」大括号里的昵称在素材昵称表里找不到——回去跑一次 register
提示尺寸不对全屏动画的图片必须是 640×400；横条动画宽不超过 640、高不超过 400
提示 .pal 文件格式错变色用的色表里，每一行应是「编号 红 绿 蓝」四个数字，且别重复同一个编号
提示 pal 必须在 base 之后变色动画里把 pal 写在了 base 前面，调换顺序即可
