anima.sh 使用说明

创建：2026-08-29
最后更新：2026-08-29

anima.sh 是动画制作工具：把 .na 动画脚本编译成游戏可用的 .ANI 文件。脚本写法见动画设计分类的「制作工作流」页（本页为制作工具分类下的独立文档，不复用那边的内容）。日常最推荐直接运行、用数字菜单逐级操作；命令行子命令适合写进脚本或熟练后使用。

1. 交互式菜单（主要用法）

不带任何参数运行：

./anima.sh

会进入三级数字菜单，每一步输入数字并按回车：

① 项目列表（第一级）

列出所有动画项目（如 1) myanim …），此外还有：

  • i 新建一个动画项目（init 骨架）
  • 0 退出

选一个数字进入某个项目。

② 操作菜单（第二级，已选项目）

菜单数字功能
1检查素材登记（check）：看看脚本里用到的素材昵称是否都已登记、有无失效
2register 同步：把素材扫描登记进索引库
3生成动画：进入脚本子菜单去构建某段动画
0返回上一级（项目列表）

③ 脚本子菜单（第三级，选「3 生成动画」后）

列出该项目下所有 .na 脚本，选一个数字进入某段脚本，再选：

菜单数字功能
1build：构建这段动画（生成 .ANI）
2build --sync：构建前先自动同步登记库，再生成
0返回上一级（操作菜单）

新手提示：第一次做动画的顺序一般是 ②里先按 2 登记素材，再用 3 → 1/2 生成。

2. 命令行用法（进阶 / 脚本化）

熟练或要写进自动化脚本时，可直接跟子命令，跳过菜单：

./anima.sh <子命令> <参数>
子命令作用
init <项目>创建动画项目骨架：animation/projects/<项目>/{config.toml,scripts/,db/}
register <项目>扫描 assets/<项目>/anim/ 素材，登记进名字索引库
check <项目>只读双向对账：未登记 / 失效行 / 待更新；有差异时退出码非零
build <项目>/<脚本>生成 animation/output/<STEM大写>.ANI；可加 --sync 先同步登记库
buildall [--flags]全项目全脚本构建
list列出 <项目>/<脚本>

3. 常见用法示例

# 交互菜单里 i 建项目 → 选项目 → 按 2 登记 → 按 3→1 生成（推荐）
./anima.sh
# 等效的命令行写法：
./anima.sh init myanim
./anima.sh register myanim
./anima.sh build myanim/blink

# 构建前自动先登记
./anima.sh build myanim/blink --sync

# 检查素材登记是否齐全
./anima.sh check myanim

# 一次性构建所有动画
./anima.sh buildall

4. 注意事项

  • 脚本文件须以 .na 结尾，且放在 animation/projects/<项目>/scripts/ 下。
  • 构建前必须先 register（或 build 加 --sync），否则脚本里写的素材昵称无法对应到真实文件。
  • check 用于 CI/提交前自检：有未登记或失效素材时返回非零退出码。
  • 成品 .ANI 输出到 animation/output/，由游戏数据构建（makegame.sh build）一并打包进 HDI。
