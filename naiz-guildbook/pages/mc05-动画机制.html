动画机制

创建：2026-08-29
最后更新：2026-08-29

本文从制作者视角说明 Naiz 引擎的序列帧动画系统（NAIZ_ANIM）：动画如何制作、打包为 .ANI 容器，以及如何在剧本中播放，并与对话框并发显示而不产生残影。

1. 动画系统总览

NAIZ_ANIM 是引擎的序列帧动画统一入口，采用自研 .ANI 容器（v1），包含两条轨道：

  • 像素轨：逐帧整屏（或固定子区域）替换，vblank 同步绘制，复用 MAG 帧编解码。
  • 调色板轨：每帧 palette_set_all 整体换色（容器内嵌原始调色板表，旁路共享调色板不变量）。

两条轨相互独立，可仅用其一。动画与转场系统、调色板原语共用 palette.c/h 纯数据函数。

2. .ANI 容器与逐帧 tick 表

v1 容器以逐帧 tick 表取代固定 fps：每帧携带自身时长（tick 数），播放节奏由 tick 表唯一事实源决定。

尺寸策略（路线 S 定死）区域
fullscreen640×400 @(0,0)
cine640×280 @(0,0)（固定占据对话框上方整条）

坐标机制整体不存在——动画尺寸由容器头声明，播放命令不再指定类型/坐标（类型自省）。sec 修饰可覆盖总时长窗口：引擎按 ceil(sec×60) 换算 tick 预算，once 到期即停、loop 到期重置继续。

3. 制作工作流

动画由专属 .na 脚本描述（与剧本 .nb 严格分离），经 anima.sh 工具链产出独立 .ANI：

anima.sh init <项目>          # 创建 animation/projects/<项目>/{config.toml,scripts/,db/}
anima.sh register <项目>      # 裸名字 → 名字索引库 db/<项目>.db（仅存索引）
anima.sh check <项目>         # 只读对账未登记/失效/待更新（有差异 exit 1）
anima.sh build <项目>/<脚本>  # 解析 .na → 产出 .ANI（--sync 先同步登记库）
  • 脚本放 scripts/<名>.na，花括号内写裸名字（无路径无扩展名），由名字索引库映射到具体帧文件。
  • 帧素材放 assets/<项目名>/anim/，成品 .ANI 全局输出到 animation/output/。
  • 脚本语法支持 animaconf / frame / base / pal 裸括号区段与 V1–V8 校验；多图 {f1,f2} 显式交错序列共用秒数。

4. 播放命令

播放侧处理函数位于 core/engine/nb_anim.c，注册于 NB 命令表：

playanima(){name}                 # 缺省 once：播完自动停止
playanima(once){name}            # 显式一次（等价缺省）
playanima(loop){name}            # 循环播放（即发即忘的环境特效）
playanima(once,sec){name}        # 限定总时长 sec 秒（once 到期即停）
playanima(loop,sec){name}        # 循环 + 每轮预算 sec 秒（到期重置继续）
waitanima()                      # 阻塞至当前动画播完；无活动动画直接通过
stopanima()                      # 停止并释放当前动画；无活动动画直接通过
  • 动画名走花括号载荷，仿台词主载荷形态；命令不声明 fullscreen/cine/track/fps（容器头是唯一事实源）。
  • 拒启规则（消灭静默失败）：未知关键字、缺名、多余参数、sec≤0 一律拒启 + 日志，脚本继续。
  • waitanima 作用于 loop 动画时告警（循环永不播完，属作者错误）；waitanima/stopanima 收到参数时告警并忽略之、功能照常。

5. 对话框并发与 clip_h 裁剪

当动画落入对话框区域（y≥280）时，必须避免精灵 blit 写入对话框 VRAM 或留下残影：

  • vram_blit_sprite() 的 clip_h 参数（>0 时限定绘制行数）是架构级约束手段，强制只绘制对话框上方区域。
  • 若需写入对话框区域做全身替换，须用 layer_sprite_replace() 并主动调 layer_dialog_refresh()。
  • layer_sprite_face() 不得写入 y≥280 区域。

这与 mc03 图层渲染与换装机制 的对话框快照/恢复策略一致。

6. 与机制 / 脚本的关系

  • 动画帧的像素/调色板最终经 mc04 MAG 图片机制 同款 MAG 编解码与调色板通路。
  • 动画播放是独立于背景/立绘的一趟绘制，叠加在 mc03 描述的渲染顺序之上。
  • 制作命令与播放命令权威规范见 docs/B92-NB脚本命令参考.md 的 playanima / waitanima / stopanima 条目与 anima.sh 工作流。
