animaconf：开场设定

创建：2026-08-29
最后更新：2026-08-29

animaconf 写在小本子（.na 脚本）的第一行，用来交代这段动画的「基本设定」。就像拍视频前先说清楚：拍全屏还是拍一条横幅、是换图还是变色、素材归哪个项目。返回总览见 语法总览。

1. 怎么写

animaconf(全屏还是横条, 整图还是变色, 项目名)

三个选项用逗号分开，写在括号里，不要加大括号。例如：

animaconf(fullscreen,pixel,眨眼项目)
animaconf(cine,palette,标题流光)

2. 三个选项分别填什么

位置能填什么意思
第一个fullscreen / cinefullscreen=铺满整个画面的动画；cine=只占对话框上方的横条
第二个pixel / palettepixel=整图动画（一张张图轮流播）；palette=变色动画（画面不动，只让颜色变）
第三个你的项目名告诉工具去哪个项目的素材文件夹找图片；这个项目要先建好

3. 写的时候注意

  • 必须写、且只能写一次，并放在小本子最前面（前面可空行或写 # 备注）。
  • 「循环播放」不要写在这里——动画播一次还是循环播，是在游戏里调用时决定的，小本子不管这件事。
  • 选项拼错、或项目文件夹不存在，工具会报错提醒你。

4. 举个例子

# 一段全屏的整图动画（比如爆炸、花瓣飘落）
animaconf(fullscreen,pixel,特效合集)

# 一段对话框上方横条的变色动画（比如灯光忽明忽暗）
animaconf(cine,palette,标题流光)

5. 常见错误

  • 写成 animaconf(){...} 带了大括号 → 这里只用括号，不要大括号。
  • 忘了写、写了两次、或不在第一行 → 工具会提示 animaconf 有问题。
  • 项目名写错或项目还没建 → 工具会提示找不到项目。
