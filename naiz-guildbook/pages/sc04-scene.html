scene 场景跳转

创建：2026-07-27
最后更新：2026-08-13

scene() 命令用于跳转场景，支持无条件跳转和条件链跳转（依赖变量系统）。

1. 无条件跳转

scene(target)
参数类型说明
targetkeyword / 3-digit场景名或编号

target 取值：

值说明
logo启动 Logo 场景（logo.nb）
op开场场景（op.nb）
mainmenu主菜单场景（mainmenu.nb）
001–020故事场景 nbookXXX.nb
end结束游戏，返回主菜单

2. 条件链跳转

scene(var1,op1,val1,...,target1;var2,op2,val2,...,target2[;default])

每个 ; 段由 1 个或多个 var,op,val 三元组 + 末尾 target 组成。段内多三元组为 AND（全部满足才匹配），段间为 OR（首个匹配的段跳转）。

字段说明
var变量 id（须在 variables.json 中定义）
op比较运算符：== != > >= < <=
val比较值（整数）
target跳转目标（3-digit，如 002 → nbook002.nb）

每个段支持 1–8 个三元组（SCENE_MAX_CONDS = 8），最后的字段始终是 target。

默认值约定：最后一段若不含逗号（如 ;001），则作为显式默认跳转目标；若最后一段含逗号，则所有段均为条件段，无匹配时 fallback 到第一个段的 target。

3. 示例

scene(003)                                          ← 无条件跳转 nbook003.nb
scene(bond_fei,>=,5,005;001)                        ← 单条件：bond_fei≥5→005，否则→001
scene(bond_ira,>=,5,bond_neon,>=,3,005;001)         ← AND：两个好感度都达标→005，否则→001
scene(bond_ira,>=,5,005;bond_neon,>=,3,005;001)         ← OR：任一达标→005，否则→001
scene(bond_ira,>=,5,005;bond_neon,>=,3,004)         ← 无显式默认：任一达标→各自目标，否则 fallback→005（第一段 target）

4. sceneconf 场景配置

sceneconf 命令声明当前场景的配置信息：章节标题 + 场景类型。它不控制跳转。

sceneconf(){A normal day, normal}
sceneconf(){, menu}   # 菜单类场景：标题可省略
字段必填说明
title否章节标题。随存档记录，在存档/读档界面显示（未设置时回退显示场景文件名）
type否（默认 normal）场景类型，见下表

4.1 场景类型

类型说明
normal普通剧情场景（默认）
cgCG 展示场景
menu菜单类场景（主菜单/存档/读档/Logo 等）。此类场景中 F5 存档 / F6 读档热键被禁用

约定：sceneconf 通常写在场景文件第一行。菜单类场景（mainmenu / loadscene / logo / op）必须声明 type=menu，否则存档热键会误可用。
