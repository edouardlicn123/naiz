音频平台与工具

创建：2026-10-05
最后更新：2026-10-05

上一页讲了机制——音乐该做成什么形状。这一页讲现实：用什么平台、用什么软件，能真的做出那种形状的东西来。列的都是实际核对过条款与许可的选项，包括价格和踩坑点。

硬件与原理见 mc06 音频通路机制；脚本里怎么写音频命令，见 sc10 音频指令；素材怎么登记，见 cf07 图片登记。

1. AI 作曲平台

挑平台只看一件事：它能不能给你 MIDI 文件或者写好的乐谱。能给的才接得上 FM 通路，给不了的——哪怕曲子再好听——也进不来。

平台怎么用说明
Mureka商业服务，在云上跑，本机零负担官方明确写了 MIDI 导出是 Premier 会员专属；另外还有按量付钱的 API 路径，$0.2 一首就能拿到 wav + midi，不用订阅 —— 详见 §1.1
Magenta Studio开源（Apache-2.0），本机跑5 个模型，各自作用在你已有的 MIDI 小片段上，出来的还是 MIDI。需要 Ableton Live 10.1 以上，或它单独运行的版本
NotaGen开源（MIT），本机跑生成乐谱，可以再导成 MIDI
MIDI-LLM开源，但许可需自己核对（没有标准声明）把 MIDI 当文字来学的模型，进什么出什么，可以接着往下续写旋律

下面这些不能直接用来生成 MIDI——它们只吐音频波形，没有 MIDI 也没有乐谱：Suno、Udio、MusicGen、ACE-Step、YuE、Stable Audio、DiffRhythm，还有 Magenta RealTime 2（经常被列错：它官方模型卡上标的类别是 text-to-audio，也就是「文字生成音频」。MIDI 是它的输入——它把 MIDI 编成一个 128 维的数字向量再喂进去——而不是输出。模型文件约 15.6 GB。真正能在本地产出 MIDI 的是另一个项目 Magenta Studio，就在上表里）。

但「不能直接用」不等于「完全没用」：这些工具的音频可以拿去转写成音符（见 §1.4），甚至可以先拆成单轨再转写，避开混音互相遮蔽的问题。

1.1 Mureka：拿到 MIDI 的两条路

Mureka 是目前唯一一个在官方页面上白纸黑字写明「MIDI 导出」确实存在的商业平台。它的 MIDI 不在免费档，但有两条价钱差很远的路可以走。

路 A：Premier 会员（网页版）

官方订阅页原文：「通过对 Mureka Studio 和 MIDI/WAV 导出的独家访问权限，Premier 提供了专业音乐工作流所需的终极控制力和高保真制作能力。」据此可确认三档的能力边界：

档位能不能导 MIDI / WAV还有什么
免费档❌ 不能0 金币
Pro❌ 不能更高级的模型（V9.5 / V9 / V8 / O2）+ 商业版权 + 曲子延长与编辑
Premier✅ 能（MIDI + WAV）12 轨分离、任意风格混音、任意声音当 AI 演唱者

⚠️ Premier 到底多少钱，本页查不到——官方页面上的价格是网页脚本动态画上去的，抓下来只有能力表，没有数字。坊间流传的说法（比如 $27 一个月）没有得到官方证实，别当事实；要付费之前请自己打开官网订阅页确认。

路 B：API 按量付钱（推荐给「只想做几首草稿」的人）

官方 platform.mureka.ai 的 Export Stem Audio（导出分轨音频）这个能力，把 MIDI 做成了按首计价的商品，不需要订阅：

模型给你什么单价拆成几轨
V1wav$0.06 / 首5
V3wav, midi$0.2 / 首2（人声 + 伴奏）
V2wav, midi$0.7 / 首12（人声 / 贝斯 / 鼓 / 吉他 / 钢琴 / 长笛 / 音效 / 弦乐 / 合成器 / 键盘 / 铜管与木管 / 其他）

官方 FAQ 另确认：下载曲子本身免费，只有拆轨（stems）这个功能要另外付费。

⚠️ 走 API 要知道的三件事（都出自官方 FAQ）：① API 和网站会员是两套完全独立的账本、不互通，想充值得单独买；② 充进去的点数，从最近一次充值那天算起 12 个月有效，过期没花完一律作废；③ 一律不退款——官方原文「所有 API 服务一经购买即视为已消耗」。

怎么选：只想试几首 BGM 草稿 → 路 B（10 首才 $2，没有月费、也没有过期压力）；长期做、还经常需要 12 轨分离 → 才考虑 Premier。

用之前先想明白一件事：它的 MIDI 本质是「先拆轨、再转写」，不是真的在写谱——所以它的质量上限和 §1.4 的转写工具一样高，不会更好。而 V2/V3 刚好把伴奏单独拆出来给你，正好满足「一次一件乐器」的前提。详见 §1.4。

1.2 免费档为什么帮不上忙

这是个有点反直觉但很关键的点：Suno 和 Udio 都有 $0 免费档、生成量还很大，但免费档拿不到 MIDI——能不能拿到，取决于你订到哪一档：Suno 要订 Premier 的 Studio 才有，而 Udio 是任何档都拿不到。卡法完全不一样，所以得分开看。

平台免费档（官方定价页）能拿到文件吗对本项目
Suno$0，每天 50 点（大概 10 首），只能用 v4.5-all 模型，没有商用权免费档：能下音频（下载次数另外有限制），没有 MIDI⚠️ 看档位：Premier 的 Studio 能导 MIDI（见下），免费档不能
Udio$0，每天 10 点、每月 100 点，完整长度（2 分 10 秒），但每天只限 3 首❌ 下载已经被彻底关掉了（见下）❌ 任何档都拿不到文件，自然也没有 MIDI

Udio 的下载是被服务条款禁止的，不只是功能下线。2025-10-29（与 Universal Music Group 和解的同一天）起关掉了音频 / 视频 / 分轨的下载，条款里明文写着「You may not download copies of any Output」（你不许下载任何输出），付费档同样不行。一个不给你文件的工具，对做素材来说等于零。

所以挑这类工具，「能不能给你 MIDI」比「便不便宜」重要得多——Suno 的 MIDI 锁在 Premier，Udio 则是彻底没有，两者都跟免费档的吸引力无关。而 Suno 的 Premier 也正说明了这件事：它靠的不是降价，是加档。反过来说，免费档拿不到 MIDI 时还有 §1.4 的转写这条路，所以「只出音频」只是不能直连，不是没有价值。

Suno Studio 能导 MIDI（已由官方证实）——早前这里写着「未核实」，现已确认，Suno 官方帮助中心原文说明导出方式：

  • 先用 Stems 面板把曲子拆成最多 12 条独立音轨，再右键其中一条 → Get MIDI，每次消耗 10 credits，Studio 分析该音轨并生成 .mid。官方还列出用途：换乐器重弹旋律、分析和声进行、把生成结果重新编曲、连同音频一起做成 sample pack。
  • 官方产品页（suno.com/landing/audio-editor）同样写明可导出 stem 级 WAV 与 MIDI。
  • 它还是双向的：Studio 2.0（2026-08-13）另加了 MIDI 导入、录音、钢琴卷帘，并能把 MIDI 片段当作生成时的提示用——也就是除了「导出」，还能「喂进去让它续写」。

但请注意它的性质：Get MIDI 是「拿音频反推音符」，不是把 AI 内部真正的作曲数据交给你。所以它和 basic-pitch、Mureka 的分轨导出属同一类——质量上限受转写精度限制（原理见 mc06 §4），单音旋律与干净的贝斯转得准，复杂和弦和人声会有错音、幻影和弦，要手工修。

顺序上它天然对路：必须先拆轨再逐条 Get MIDI，正好满足「一次只处理一件乐器」这个前提（见 §1.4）。

还剩一条没核实的线索（没拿到官方页面确认，别当成已验证的选项；要用之前请自己去核对官方条款和导出格式）：Veena 被第三方对比文章说成免费档就带 MIDI。这条说法出自竞品自己的营销页，可不可信要自己验。

怎么核实：直接去各家官方主域名看定价页和导出格式说明，不要采信对比文章。还有一条实操经验：搜「某平台 + pricing」会冒出一堆山寨站，域名像、却报互相矛盾的价格，能力表用空列打勾，还会编出不存在的型号。实例：本次核对时遇到一个域名多一个 n 的仿冒站，声称「Premier 约 $24–30 / 月」并罗列了 Studio 2.0 的细节，看起来极其可信——该价格未证实，因此不写入本文。只认官方主域名，其余一律不信。

1.3 开源模型：要什么条件才跑得动

NotaGen 和 MIDI-LLM 都得在你自己电脑上跑，而且对显卡显存的要求比一般桌面电脑高不少。跑之前先核对这三项，缺一项就白搭：

项目要多少显存Python还要装什么
MIDI-LLM
（音乐信息检索会议 2026 的成果，基于 Llama 3.2 1B）		16 GB 以上，需要 CUDA 12.x3.11（用 conda 环境）vllm、anticipation、FluidR3 GM 音源；CPU 想跑得快还需要 AVX512 支持

NotaGen
（中央音乐学院）		NotaGen-X 8 GB；NotaGen-large 24 GB3.10（用 conda 环境）torch==2.3.0 / cuda 11.8、accelerate、optimum

4 GB 级别的显卡（GTX 1650 这一档）两个都跑不动——NotaGen-X 差一倍，large 差六倍，MIDI-LLM 差四倍。这不是「慢一点」，是显存装不下直接失败。

另外提醒：NotaGen 出来的是用 ABC 记谱法写的古典乐谱（不是 MIDI），用途更偏「生成乐谱素材」，跟 FM BGM 通路不是同一条路；MIDI-LLM 的示例提示词明确要你写 electric guitar（电吉他）、church organ（管风琴）、saxophone（萨克斯）这类常见编制，而 YM2608 只有 6 个通道和 128 个 4 算子音色，转过去多半是「机器人音」（见 mc06「GM 音色 ≠ FM 音色」）。

确实要跑的话：① 先确认硬盘有 10–20 GB 空闲（环境和模型文件，硬盘往往比显卡更早成为瓶颈）；② 用 Google Colab 免费档之类按小时租一张 16 GB 显卡的实例，本机只留下 tracker 那一步；③ 硬盘不够时，另用外置存储或者清理包缓存腾地方——不要为了腾空间去删本仓的资源（assets/ 与 disks/ 尤其不能动）。

1.4 转写这条路：音频 → MIDI

前面几个平台是「无中生有」，这条路是「把已有的音频还原成音符」。它有一个前面都没有的好处：不依赖任何平台、不用账号、不用订阅，而且什么音频都能喂进去。为什么 WAV 转 MIDI 原理上就成立、而「从声音倒推 FM 音色」不成立，见 mc06 §4。

工具许可怎么用 / 要注意什么
basic-pitch
（Spotify 音频智能实验室）		Apache-2.0 或 GPL-3.0 双许可，取 Apache-2.0 那个就行pip install basic-pitch 装上，命令行用法 basic-pitch <输出目录> <输入音频>；ICASSP 2022 的模型，支持多个音同时响，也支持弯音（pitch bend）。默认不装 TensorFlow，而是按你的系统挑一个更轻的推理库（Linux 用 TensorFlowLite、Windows 用 ONNX、macOS 用 CoreML）；真需要完整的 TensorFlow 就装 basic-pitch[tf]
basic-pitch 在线 demo同上（免费）在浏览器里跑，把音频拖进去就出 MIDI，不用装东西、也不用占硬盘

这一节最要紧的是顺序：先拆轨、再转写，别直接拿整首混音去转。

basic-pitch 有一条硬限制，官方原话是「一次只处理一件乐器效果最好」——整首管弦乐混音里好几个声部互相遮蔽，转出来的东西会乱。而 §1.1 的 Mureka Export Stem Audio V3 / V2 给你的正是拆好的轨（V3 = 人声 + 伴奏，V2 = 12 轨），把伴奏单独拆出来再做单轨转写，刚好满足这个前提。所以对「手里只有一首多乐器混音」这个最常见的情况，正确顺序是：

生成（用什么工具都行）→ 拆轨 → 单轨转写 → MIDI → tracker

这不是「可选的优化」，是决定成败的前提。反过来说，自己哼一段单音旋律仍然是最干净的做法——demo 页自己就写着「按下录音，对着麦克风哼一段小调」。旋律想清楚之后哼一遍转成 MIDI，比任何生成式工具都快也更准。

2.1 两个容易踩的坑

FamiTracker 不适合干这件事。它官网自己写着是「a free windows tracker for producing music for the NES/Famicom-systems」（一个给任天堂红白机做音乐用的免费 Windows 作曲软件），最后一版是 0.4.6（2015-02-04），GPL。有两个事实特别容易搞混：

  • 官网确实还挂着「MIDI input devices are supported」（支持 MIDI 输入设备）——但那说的是接 MIDI 键盘实时弹，不是导入 .mid 文件；
  • 导入 MIDI 的功能在 0.4.3（2014-06-07）就被删掉了（更新日志原文「Removed MIDI import」），而且它根本没有 MIDI 导出——能导出的是 NSF / WAV / 文本格式。

也就是说，想用 FamiTracker 走「AI 生成 MIDI → FM」这条路，两头都缺：进不去 MIDI，也出不来 MIDI。

FamiStudio 也不支持 YM2612。它常被误当成「支持多种音源的 tracker」。它只管任天堂那一侧：2A03、VRC6 / VRC7、FDS、N163、MMC5、5E01 等，不支持 YM2612 / YM2608。

3. 推荐工作流

① Mureka Premier / Suno Studio / Magenta Studio ──▶ MIDI  ┐
② 任意工具 ──▶ 分轨 ──▶ 单轨转写 ──▶ MIDI   ┤
③ 自己哼一段 ──▶ 单轨转写 ──▶ MIDI          ┘
                                            │
                                            ▼
tracker（BambooTracker / Furnace）          │
├─────▶ libOPNMIDI dumper ──▶ VGM ──▶ OPNplug 试听（试听闭环）
                                            ▼
└─────▶ 引擎（YM2608 后端）
旁支（音效 / 语音）：
任意 WAV ──wav_convert.py──▶ .pcm ──▶ 引擎（占 PCM 单通道）
  • MIDI 是「交换用」的格式，FM 只负责把声音做出来。这是上面所有 AI 工具能接进来的唯一前提——别指望 AI 直接给你 FM 音色，它没这个本事（原因见 mc06 §4）。
  • 音色可以从 WOPN 或社区音色库起步，但要一个个核实许可（见 §4）。
  • tracker 的 GPL 只管软件本身，用它做出来的音乐数据不会被传染（见 §4）。
  • 音效和语音走 PCM 那条旁支时，两者之间必须隔一页对白（因为 PCM 只有一个通道，见 mc06 §1）。

AI 该放在哪：它省的是「想旋律」的工夫，不是「出成品」的工夫。AI 给你的是通用的 GM MIDI，而 YM2608 只有 6 个通道、128 个 4 算子音色，直接转过去多半是「机器人音」（见 mc06「GM 音色 ≠ FM 音色」）。

所以 AI 出来的 MIDI 必须在 tracker 里重做一遍：换 FM 音色、改织体、删掉用不上的声部来适配 6 个通道。把它当「旋律草稿」，别当「成品」。要是打算干脆不用 AI、直接在 tracker 里作曲，零成本零依赖，做出来的东西质量反而更高——AI 不是必需品。

三个入口按花多少钱排（按本机 4 GB 显存、没有 AVX512 的情况）：③ 零成本零依赖——旋律想清楚了直接哼一遍；② 几乎零成本——Mureka API 的 V3 一首 $0.2；① 最贵或者最折腾——Premier 要月费，Magenta Studio 要 Ableton。先走③，别一上来就订阅。

顺便分清两件事：作曲类 AI 是「无中生有」，给你一段从来没存在过的旋律；转写是「把已有音频还原成音符」，它不省「想旋律」的工夫，只省「把旋律敲进 tracker」的工夫（见 §1.4）。

4. 许可须知

  • GPL 的「传染」只对代码生效，不对产出的数据生效。FamiTracker、BambooTracker、Furnace、mdxtools 都是 GPL，但用它们做出来的音乐可以放进任何引擎里发布，不必因此开源你的引擎。
  • 「参考它的代码」是另一回事。libOPNMIDI 主体是 LGPL-3.0，但里面嵌了许可不兼容的第三方核心（MAME 的 YM2612 / OPN 核心、Genesis Plus GX）。要参考或移植它的代码，必须逐个文件核对顶部的 SPDX 许可声明，不能只看仓库最外层那个 LICENSE。
  • 从社区音色库取音色参数时，如果库本身没写许可，就按「来源不明」处理，核实之后再用。
  • 本项目的规定见 AGENTS.md §十：GPL v2 的代码不能直接复制；复制代码必须附上来源项目 + GitHub 地址 + 许可证注释。
