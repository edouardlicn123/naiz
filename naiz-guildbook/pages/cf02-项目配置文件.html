项目配置文件（config.toml）

创建：2026-08-04

每个项目根目录有 config.toml，集中管理项目级全局配置（语言、标题、版本、过渡、黑花字开关）。构建时由多段工具读取并分配到 settings.txt、引擎头文件等。

1. 值类型约定

类型写法示例
字符串 双引号包住 title = "Demo-A2"
布尔 true / false，不带引号 title = false
整数 十进制整数 frames = 2
字符串列表 中括号，逗号分隔 targets = ["chi", "jpn"]
嵌套段 用 [段名] [blackletter]
提醒：布尔值不要加引号。"false" 是字符串而非布尔，构建工具会把它当成"存在 → 开"，导致原本想关的功能被打开。

2. 完整配置与注释

# =============================================================
# Naiz 游戏工程配置 (TOML) — 支持 # 注释
# 唯一例外: 下面的 version 行由 bump_version 工具自动维护，
# 请勿手动修改，其余行均可随意编辑、增删注释。
# =============================================================

# ---- 国际化（i18n）----
[i18n]
# 源语言（文案基准），必填。i18n_gen 以此为基准生成翻译。
source_lang = "eng"
# 需要生成翻译的目标语言列表（i18n_gen 用）。不能包含 source_lang 本身。
targets = ["chi", "jpn"]

# ---- 项目信息 ----
[project]
# 游戏标题（主菜单 / 启动画面显示）
title = "Demo-A2"
# 游戏描述（简短说明，仅用于项目内辨识）
description = "Naiz Engine 技术演示"
# 版本号 X.Y.ZZZ —— 由 bump_version 自动维护，请勿手动修改
version = "0.1.053"

# ---- 场景转场 ----
[transition]
# 场景切换转场类型：cut | fade | vblinds | hblinds | dblinds | rdblinds
type = "vblinds"
# 转场帧数（1-64），数值越大转场越慢
frames = 2

# ---- 黑花体（Blackletter）----
[blackletter]
# 读/存档页标题 LOAD / SAVE 是否用黑花体 MAG
title = false
# 正文 ASCII 是否用黑花体 16×16（BLACK.DAT）
dialog = false

黑花体相关字段说明见 cf06 黑花字。

3. 键速查表

段字段类型默认说明
i18nsource_langstring— 源语言（文案基准），必填。供 i18n_gen 使用。
i18ntargetsstring[]— 需生成翻译的目标语言列表，不能包含 source_lang。
projecttitlestring— 游戏标题。
projectdescriptionstring— 游戏描述。
projectversionstring— 版本号 X.Y.ZZZ，由 bump_version 自动维护，勿手改。
transitiontypestringvblinds 场景转场类型。— cf05 详情
transitionframesint16 转场帧数（1–64）。— cf05 详情
blacklettertitle / dialogtable— 黑花字开关（仅非 CJK 语言生效）。— cf06 详情

4. 工具链消费矩阵

段字段读取工具去向 / 用途
i18nsource_lang、targets tools/naiz_conv/i18n_gen.py 生成 / 合并翻译文件。
project / blacklettertitle、version、title / dialog tools/naiz_build/build_game.py 注入到 settings.txt（version= / blacktitle= / blackdialog=）。
transitiontype、frames tools/naiz_build/export_config.py 生成引擎头文件 nb_config.h（宏 NAIZ_TRANSITION_*），编译期内嵌。
projectversion tools/naiz_build/bump_version.py 版本自增（下方 §5）。

5. 版本自增

每次修改源码后运行：

python -m tools.naiz_build.bump_version <game>
  • 将 version 最右段 +1（如 0.1.052 → 0.1.053）。
  • 采用按行替换写回，只改 version = "…" 这一行，其余 # 注释与排版全部保留（TOML 读取库 tomllib 只读，故不再整文件序列化回写）。
  • version 行必须存在且恰为一行，否则工具报错。

6. 运行链路

  • 设置类（version / 黑花字等）：config.toml → build_game.py 注入 settings.txt → 引擎 settings_load() 解析到 GameSettings（settings.c/settings.h）。
  • 编译期类（转场）：config.toml → export_config.py → nb_config.h 宏 → 引擎编译期内嵌。
