黑花字（Blackletter）

创建：2026-08-04

黑花字（Fraktur / Blackletter）是西文的古典印刷花体字型，Naiz 用它为读/存档页标题与对话正文提供装饰性的拉丁字体效果。

1. 是什么

  • 基于 UnifrakturMaguntia 字体（SIL OFL 1.1 开源许可）制作。
  • 只含拉丁字母与标点，不含 CJK 字形。
  • 部署数据分两块：
    • BLACK.DAT — 16×16 点阵字库，供对话正文等 ASCII 文字使用。
    • loadtitle.MAG / savetitle.MAG — 整幅花体标题图（"LOAD" / "SAVE"），供读/存档页标题使用。

2. 适用范围（重要）

黑花字只含拉丁字符，因此仅当运行时语言为非 CJK（如 eng）时生效。当语言为 chi / jpn / kor 时，无论开关如何设置，都会自动回退到原字体，不会出现缺字或串字。

3. 如何开启

在项目 config.toml 的 [blackletter] 段设置开关：

[blackletter]
# 读/存档页标题 LOAD / SAVE 是否用黑花体 MAG
title = true
# 正文 ASCII 是否用黑花体 16×16（BLACK.DAT）
dialog = true
字段默认作用范围
titlefalse 读档 / 存档页顶部的大标题（LOAD / SAVE）。开启后以居中花体标题图替换默认大字标题。
dialogfalse 对话、问题选项、存档菜单等处的 ASCII 文字。开启后正文拉丁字符改用 16×16 黑花体点阵。

值必须是 true / false 布尔，不要加引号（"true" 会被当作字符串而误判为"开"）。

4. 生效流程

修改后重新构建游戏即可：

./makegame.sh build <game>
  1. build_game.py 读取 config.toml 的黑花字开关，写入 settings.txt 的 blacktitle= / blackdialog=。
  2. 引擎启动时读取 settings.txt，得到两个开关。
  3. 运行时语言为非 CJK 时生效；为 CJK 时自动回退原字体。

5. 与其它设置的关系

  • 黑花字作用于拉丁文字；CJK 文字始终走 CJK 点阵字库，不受影响。
  • 对话框样式（dlgstyle）、字体等设置与黑花字相互独立，可同时使用。
  • 完整配置格式见 cf02 项目配置文件。

6. 注意事项

  • 黑花体字型偏装饰、可读性低于默认字体，长句正文建议保持默认，仅在标题或短句使用。
  • 开关仅影响非 CJK 语言；多语言发布时，CJK 玩家看到的仍是原字体，属预期行为。
  • 修改开关后需重新 makegame.sh build 才会部署到 settings.txt。
