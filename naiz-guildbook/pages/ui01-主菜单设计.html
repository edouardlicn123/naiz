主菜单设计

创建：2026-06-27
最后更新：2026-06-27

本文说明主菜单的场景流程、编辑方法和多语言翻译。命令语法见 sc07-mainmenu。

1. 场景流程

游戏启动后的场景链为：

logo.nb → op.nb → mainmenu.nb
                       │
            start ─────┤
              ↓        │
         nbook001.nb   │
           ⋮           │
        scene(end) ────┘
                       │
            exit ──────┘
                 引擎关闭
  • 主线故事由 start 触发，从 nbook001.nb 开始
  • 故事结尾的 scene(end) 自动返回主菜单
  • 游戏进行中按 Esc 可随时返回主菜单
  • 选择 exit 直接关闭引擎，返回 DOS

2. 编辑示例

主菜单由 mainmenu.nb 文件定义。去掉某个选项即可隐藏对应的按钮：

# 两列，只保留 start、gallery、settings 和 exit
mainmenu(400, 200, 2, 0, start, gallery, settings, exit)
规则说明
exit 必须排在最后引擎按顺序解析，后面的选项不显示
最多 16 项一个 mainmenu 命令最多容纳 16 个选项
不能新增选项名引擎只识别上表列出的选项名，自定义名称无效

3. 翻译

菜单选项的显示文字通过多语言系统自动翻译。无需在脚本中写不同语言的菜单——引擎在显示时从 i18n/role_*.txt 查找翻译。

翻译文件示例：

# i18n/role_chi.txt
start=开始游戏
exit=退出游戏
continue=继续游戏
