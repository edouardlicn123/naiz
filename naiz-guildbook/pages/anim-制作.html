动画制作工作流

创建：2026-08-29
最后更新：2026-08-29

本页是给不写程序的 galgame 制作者看的动画制作指南。做一段游戏动画其实就三步：① 准备好图片素材；② 写一张「分镜小本子」（.na 脚本，写法见 语法总览）；③ 用动画小工具生成最终的 .ANI 文件。本文讲第①步和第③步。

1. 动画放在哪里

每一段动画都属于一个动画项目（比如「主角眨眼」「标题界面流光」）。项目就是一个文件夹，里面分两处：

  • 素材文件夹：放你画的图片（和变色动画用的「色表」文件）。
  • 脚本文件夹：放那张分镜小本子 .na。

工具会自动建好这些文件夹，你不用手动摆弄路径。

2. 用动画小工具（anima.sh）生成动画

在终端里输入下面这些命令（把「项目名」「脚本名」换成你自己的）：

你想做的事输入什么
新建一个动画项目（自动建好文件夹）anima.sh init 项目名
把素材登记进「昵称表」anima.sh register 项目名
检查有没有漏登记的素材anima.sh check 项目名
按脚本生成动画文件anima.sh build 项目名/脚本名
一次性生成项目里所有动画anima.sh buildall
看看这个项目有哪些动画anima.sh list

如果直接输入 anima.sh 不加任何参数，会弹出一个菜单一步步带你操作，适合不熟悉命令的时候用。

小提示：生成动画前最好先 register 一次（也可以直接在 build 后面加 --sync，它会先自动登记再生成）。

3. 给素材起「昵称」（素材昵称表）

写脚本时，你不用写图片的真实路径和文件名，只需要写一个简单的「昵称」。例如脚本里写 {微笑}，工具就会去找那张叫「微笑」的图片。

这些昵称由 register 这一步自动登记好——它扫描你的素材文件夹，把每张图记进一张「昵称表」。所以：

  • 先 register，再 build；
  • 如果脚本里写了某个昵称、但素材没登记（或图片被删了），工具会报错提醒你，不会悄悄生成一个坏掉的动画。

4. 生成的产物：.ANI 文件

工具按你的脚本，把图片打包成最终的 .ANI 文件，这就是能放进游戏里播放的动画。

  • 全屏动画：铺满整个画面，尺寸固定 640×400。
  • 对话框上方的横条动画：只占对话框上面那条，固定 640×280。

5. 还想了解

  • 语法总览 —— 怎么写那张分镜小本子（.na 脚本）。
  • 动画机制 —— 在游戏里怎么播放这段动画。
  • MAG 图片机制 —— 图片在引擎里是怎么显示和调色的。
