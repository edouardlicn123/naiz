图层渲染与换装机制

创建：2026-06-27
最后更新：2026-08-13

本文从制作者视角说明 Naiz 引擎的图层渲染架构——立绘、对话框、背景之间的堆叠关系，以及换表情、换装时的渲染策略。

1. 图层堆叠（从下到上）

PC-98 PEGC 提供 2 个图像平面（Graphic Plane A + B）组合为单层 8-bit 256色 VRAM（640×400），另有一独立硬件文字平面（Text Plane）。引擎只使用图像 VRAM，文字平面不可用——DOS/4GW 保护模式下不可见，见 fd01 §1.4。引擎通过四趟渲染顺序在单层 VRAM 上实现多层堆叠效果：

Layer 0: 背景（bg MAG）
Layer 1: 对话框背景区还原
Layer 2: 精灵（立绘/角色，最多 16 个）
Layer 3: 对话框（透明/半透明/实心底色）
Layer 4: 文字（对白文本，覆盖在对话框之上）

每趟渲染只写入该层对应的区域，不会覆盖下方已绘内容。

2. 精灵（立绘）机制

引擎通过 char 命令控制立绘。详见 mc02-立绘与角色。

2.1 显示与定位

char charlie l            # 左侧显示 charlie（默认 body，左位自动水平翻转）
char charlie r expr_happy # 右侧显示 charlie，表情 happy（face）
char charlie c body       # 中央显示 charlie（body 全身）

2.2 换表情 / 换装

char charlie l expr_angry # 只刷新面部区域（face 模式，不重绘对话框）
char charlie c body       # 从 body 切换，不受 clip_h 限制

face 约束：face 模式只能写入 y < 280 的 VRAM 区域，不触及对话框范围。

clip_h：引擎通过 calc_sprite_clip_h() 计算每个立绘允许绘制的行数。如果立绘位置（左/中/右）在对话框之上，则不受限；如果部分区域落在对话框范围内，自动裁剪。

3. 对话框渲染

对话框的外观样式见 cf03-对话框样式方案。本节说明对话框在渲染管线中的出现、更新与清理机制。

3.1 出现时机

对话框由文本指令触发：剧本中第一条台词（host{...}、对白命令等）出现时，引擎自动弹出对话框。具体流程：

  1. 文本指令调用 dialog_show()（nb_dialog.c）
  2. 若对话框尚未显示 → layer_dialog_open()：画出对话框并拍摄快照
  3. 若对话框已显示（翻页/后续台词）→ 跳过重画，直接更新文字

也就是说：同一个场景内对话框只弹出一次，后续台词复用同一框，只替换文字内容。

3.2 首次弹出（layer_dialog_open）

首次出现时按以下顺序构建：

  1. 绘制对话框底色（半透明图案或实心，按样式设定）+ 2px 白色边框
  2. 把对话框区域（x=80, y=280, 宽480, 高115）的画面拍摄成快照（dialog_snapshot）
  3. 标记「对话框已显示」

之后每次文字刷新，只需在快照之上写新文字，无需重绘底色和边框。

3.3 两份快照的分工

引擎维护两份不同的快照，用途相反：

快照内容用途
dialog_snapshot带对话框的画面（含底色/边框/文字）角色身体压住对话框后，用它把对话框区域恢复原样
bg_dialog_snapshot纯背景（不含对话框）对话框消失时，把它还原回画面，露出背后背景

要点：bg_dialog_snapshot 必须始终是「纯背景」。因此每次换背景、角色增减之后都要重新拍摄，否则对话框消失时会还原成错误的画面。

3.4 对话框的消失 / 清理

按触发原因分为三种，清理程度不同：

场景触发做了什么
正常隐藏bg(hidedialog) 或 char(hideall)把「纯背景」快照还原到画面 → 对话框消失；快照内存保留，方便再次弹出
更换背景bg(...)背景已整体重画，只清标记，不做画面还原
切换场景scene(...)清空全部状态，释放快照内存；下个场景首次台词再重新弹框

3.5 与角色的联动清理

角色身体与对话框区域重叠时，清理需要按顺序处理：

  • 隐藏单个角色：若该角色身体压住对话框 → 隐藏后把对话框那部分重画并刷新快照
  • 最后一个角色消失：先把角色区域（对话框上方）的背景还原，再重新拍摄一份「纯背景」快照（因为对话框上方的画面已变化）
  • char(hideall)（隐藏所有角色）—— 完整链路：
    1. 逐个隐藏所有角色（压住对话框的依次重画对话框）
    2. 隐藏对话框：把「纯背景」还原回画面
    3. 清空台词状态（角色名、台词缓冲归零）

4. 背景与场景切换

  • bg(...)：加载新背景 MAG，捕获全屏快照和对话框区域纯背景快照，关闭对话框
  • bg(hidedialog)：只关闭对话框并还原对话框区域背景，不加载新背景
  • 每次 scene(...) 切换：自动清屏为黑屏，然后执行新场景的 bg(...) 指令

5. 精灵操作速查

NB 命令效果渲染策略
char name pos显示立绘（默认 body）覆盖式 blit，capture bg dialog
char name pos expr换表情clip_h 限定区域，不触发 dialog rebuild
char name pos body换全身完整重绘，触发 dialog rebuild
char(hideall)隐藏所有立绘 + 对话框 + 清空台词逐精灵隐藏 → 还原对话框背景 → 清空台词状态（见 §3.5）
