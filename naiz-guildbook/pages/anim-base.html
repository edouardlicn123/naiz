base：变色动画的底图

创建：2026-08-29
最后更新：2026-08-29

base 用于变色动画（开场设定里选了 palette 的那种）。它写出「变化之前」的第一张底图——后面每一次颜色变化都是在这张底图的基础上改。返回总览见 语法总览。

1. 怎么写

base(){素材昵称}

大括号里写正好一个素材昵称（底图），不用写括号里的数字。

2. 举个 galgame 里的例子

# 灯光忽明忽暗：先有一张正常亮度的底图，再让它变暗、变亮
animaconf(cine,palette,标题流光)
base(){正常亮度}
pal(0.2){暗一点}
pal(0.2){亮回来}

底图本身的颜色，会被后面每一张「色表」叠加修改——没被点名的颜色就保持底图的样子。

3. 写的时候注意

  • 只用在变色动画（开场设定选了 palette）。整图动画里写 base 会报错。
  • 变色动画里 base 只能写一次。
  • 必须写在 pal 前面（先有底图，再有变化）。如果先写 pal 再说 base，工具会报错。
  • 底图的昵称也要先 register 登记过。

4. 常见错误

  • 整图动画里误用了 base → 改用 frame。
  • 写了两次 base → 保留一个就好。
  • 把 pal 写在了 base 前面 → 把 base 挪到最前。
