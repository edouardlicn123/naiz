frame：放一张画面

创建：2026-08-29
最后更新：2026-08-29

frame 用于整图动画（开场设定里选了 pixel 的那种）。每一行 frame 就是动画里的「一张画面」，并写明这张画面停留几秒。连续写几行，就成了会动的画面。返回总览见 语法总览。

1. 怎么写

frame(停留秒数){素材昵称}
  • 括号里写一个数字（秒，可以是小数，比如 0.5 表示半秒）。
  • 大括号里写这张画面用的素材昵称（登记时起的名字，不用写路径）。
  • 想让几张图轮流播、且共用同一个停留时间，就写在一行里用逗号分开：{图1,图2,图3}。

2. 举个 galgame 里的例子

# 角色眨眼：睁眼半秒、闭眼半秒，来回切换
animaconf(fullscreen,pixel,主角)
frame(0.5){睁眼}
frame(0.5){闭眼}

# 云慢慢飘：三张图各停 0.3 秒，轮流出现
frame(0.3){云1,云2,云3}

工具会自动把「秒数」换算成动画内部的计时（每秒 60 格），你只要填秒数就行，不用管那些细节。如果秒数乘以 60 不是整数，工具只会嘟囔一句提示，不影响生成。

3. 写的时候注意

  • 只用在整图动画（开场设定选了 pixel）。变色动画里写 frame 会报错。
  • 整图动画至少写一行 frame，否则没有画面。
  • 大括号里的昵称必须已经在素材昵称表里登记过（回去跑 register），否则工具说「找不到这个名字」。
  • 全屏动画里的每张图片都必须是 640×400 大小。

4. 常见错误

  • 变色动画里误用了 frame → 改用 base + pal。
  • 提示「未登记的名字」→ 素材没登记，先 register。
  • 提示尺寸不对 → 全屏动画图片要正好 640×400。
