变量系统

创建：2026-06-27
最后更新：2026-07-28

Naiz 项目通过 4 个 JSON 文件集中管理配置。这些文件位于 projects/<game>/ 目录下，构建时自动编译到引擎中。

修改后需同步更新本文档，确保文档与实际定义一致。

1. variables.json — 变量定义

定义游戏运行时变量（好感度、剧情 flag、计数等）。

{
  "variables": [
    {
      "id":       "bond_fei",
      "name":     "Fei好感度",
      "desc":     "Fei对玩家的好感度",
      "initial":  0,
      "min":      0,
      "max":      100
    }
  ]
}
字段类型说明
idstring变量标识符（小写+下划线），供脚本命令和内部查找使用
namestring显示名称（存档界面、调试输出）
descstring说明文字
initialint初始值，引擎冷启动/开始新游戏时重置为此值
minint最小值（默认 0），超限时自动截断
maxint最大值（默认 9999），超限时自动截断

构建管线：variables.json → export_vars.py → nb_var_table.h（NbVarDef 结构体数组 + NB_VAR_COUNT）。

当前项目 demo-a2 定义了 3 条变量：

idname范围初始
bond_feiFei好感度0–1000
bond_iraIra好感度0–1000
bond_neonNeon好感度0–1000

2. characters.json — 角色定义

定义游戏中可用角色，供 char 命令和 expressions.json 关联使用。

{
  "characters": [
    {"id": 9,  "key": "fei",  "name": "Fei"},
    {"id": 10, "key": "ira",  "name": "Ira"},
    {"id": 11, "key": "neon", "name": "Neon"}
  ]
}
字段类型说明
idint角色数字 ID。与 expressions.json 的 char_id 对应，char_map[] 中 id 字段也使用此值
keystring角色键名。供脚本 char(ira, ...)、fei{...} 等命令使用。全局唯一
namestring显示名称。对话框角色名标签使用此值

构建管线：characters.json → export_asset_table.py → nb_asset_table.h（char_map[]：key→id→name 查找表）。

3. expressions.json — 表情映射

定义每个角色的表情与精灵资源的对应关系，供 char(name, pos, expr) 命令查找。

{"expressions": [
    {"char_id": 9,  "expr": "normal",    "asset_id": 1},
    {"char_id": 9,  "expr": "sad",       "asset_id": 8},
    {"char_id": 9,  "expr": "smile",     "asset_id": 9},
    {"char_id": 9,  "expr": "surprised", "asset_id": 10},
    {"char_id": 10, "expr": "normal",    "asset_id": 2},
    ...
]}
字段类型说明
char_idint角色 ID（对应 characters.json 的 id）
exprstring表情名称（如 normal、sad、smile）。供 char(name, pos, expr) 命令使用
asset_idint精灵资源 ID（对应 ASSETS.DB 中 type='SPR' 的 id）

构建管线：expressions.json → export_asset_table.py → nb_asset_table.h（expr_map[]：(char_id, expr)→asset_id 查找表）。

4. config.toml — 项目配置

项目级全局配置，涵盖语言、标题、版本和过渡效果。构建时自动注入到 settings.txt 中。采用 TOML 格式，支持 # 注释；version 行由工具自动维护。完整说明见 cf02 项目配置文件。

构建管线：config.toml → export_config.py → nb_config.h（过渡相关宏）；版本号 → build_game.py → 注入到 settings.txt。
