market.sh 使用说明

创建：2026-09-27
最后更新：2026-09-27

market.sh 是资产市场下载工具：从公开 GitHub 市场仓库按需整包下载资源（如场景背景）到本地，不占用本仓体积。下载是只读 HTTPS（GitHub API + raw），不需要写权限。项目内图片登记见 cf07 图片登记。

1. 基本概念：包

  • 市场仓库顶层目录 = 一个资源包，永远整包下载，不做文件级选择。
  • 包显示名规律：目录名按 _ 切分，首段用 () 包裹、余段空格连接（如 images_sample_scenebg → (images)sample scenebg）；命令行接受原始目录名或后缀种类名两种写法。
  • 下载落点默认 assets_samples/（已 gitignored），目标路径已有同名文件时默认跳过（打印 SKIP (exists)），加 --force 才覆盖。

2. 配置（market.toml）

仓库根目录 market.toml：

[market]
repo = "edouardlicn123/naiz_assets"  # 市场仓库 owner/repo
ref = "main"                          # 分支/版本
dest = "assets_samples"               # 本地落点

3. 子命令

子命令作用
list列出全部包（显示名 / 文件数 / 总大小）
cats仅包显示名 + 文件计数
menu（默认）交互式数字选包（支持 1 2、1-3，回车即整包下载）；启动时清屏一次，后续重绘不清，下载日志保留在菜单上方
get <包>...命令行整包下载（原始目录名或后缀种类名）
get-all下载全部包

通用参数（置于子命令后）：--repo / --ref / --dest / --config / --dry-run（只规划不写盘）/ --force（覆盖已存在文件）。

清屏只作用于 menu，且仅在输出是终端时生效（重定向到文件、过管道时写入纯文本，不含转义序列）。

4. 常见用法示例

# 交互菜单（推荐）
./market.sh
# 等效写法
./market.sh menu

# 看看有什么包
./market.sh list

# 下指定包（两种写法等价）
./market.sh get images_sample_scenebg
./market.sh get scenebg

# 刷新已下过的文件
./market.sh get scenebg --force

下载后的文件在 assets_samples/ 下是原始素材；要进游戏，拷到 assets/<game>/png/ 后按 cf07 图片登记三步入库。
