MAG 图片机制

创建：2026-08-29
最后更新：2026-08-29

本文从制作者视角说明 Naiz 引擎的图像格式 MAG、归档存储、共享调色板与透明色约定——即所有背景与立绘在引擎侧的加载与显示机制。更低层的字节规范见仓库内 docs/B11-MAG图片加载与显示规范.md。

1. MAG 格式与 256 色模式

MAG (MAKI02) 是 PC-98 平台主流图像格式，支持 16 色（4bpp）与 256 色（8bpp）。Naiz 引擎固定使用 256 色模式（PEGC，bpp=8，num_colors≤256）：解码后的像数值 0–255 直接对应硬件调色板索引，无需位平面拆分或额外颜色映射。

组件16 色256 色（引擎采用）
像素数据4bpp（Flag A/B + color stream）8bpp
内嵌调色板16 组 GRB最多 256 组 GRB
屏幕模式screen_mode=0x00screen_mode=0x80

2. 两种图像类型与 user-string 约定

MAG 头部 16 字节 user 域用于标识图像类型，引擎据此决定加载行为：

User String类型引擎行为
"naiz\x1a"背景 / 全屏调用 image_set_palette() 设全场景调色板 + vram_blit() 整屏写入
"sprt\x1a"立绘 / 精灵不调 image_set_palette()，用 vram_blit_sprite(idx=15) 跳过透明像素

精灵（char 命令使用的立绘）与背景共享同一套 256 色调色板：背景先加载设调色板，精灵后加载只写像素，以背景调色板渲染。详见 mc03 图层渲染与换装机制。

3. 归档 IMAGE.DAT 与逻辑 ID

多张 MAG 在构建时被打包为单一归档 IMAGE.DAT，减少 HDI 根目录条目，引擎通过逻辑 ID 直接 O(1) 索引。

  • 资源映射表 ASSETS.DB 的 img_map 表：id（logical_id，即场景命令参数值）、filename、type（'IMG'/'SPR'）。
  • pack_images.py 读取 img_map 将列出的文件打包为 IMAGE.DAT；TOC 条目数组下标 = logical_id，引擎 image_load(id) 直接数组寻址，无需文件名匹配。
  • 角色与表情另由 characters.yaml 定义，char_expressions 将 expr 映射到 img_map.id。

4. 共享调色板与预留索引

256 色模式下所有图像像素 + UI 元素共用同一调色板。为避免 UI 色（文字、透明、对话框底色）与图像像素冲突，引擎采用10 个预留索引：

索引默认色用途
7白文字 / 边框 / 提示
15黑精灵透明色（blit 时跳过）
248黑对话框底色（dlgstyle 动态改色）
249–255—备用 UI 色（250=菜单文字，251=菜单选中）

三段保护层次（任一阶段阻断冲突）：

  • 阶段 1 素材生成：mag_convert.py --reserved 7,15,248,...，量化即避开预留索引。
  • 阶段 2 归档打包：pack_images.py 全部图像 remap 到共享调色板时跳过 PROTECTED_IDX。
  • 阶段 3 引擎运行：image_set_palette() 跳过 7/15/248–255，永不覆写 UI 色。

5. 透明色约定

  • 精灵 PNG 经 mag_convert.py --sprite 转换：alpha<128 区域映射为索引 15（透明标记），不 resize 保持原始尺寸，写入 "sprt\x1a"。
  • 精灵 --reserved 不含 15，因为需要在索引 15 存储透明标记。
  • 立绘底部 y≥280 区域需与对话框布局一致（pack_images.py 对多套表情做 y≥280 一致性校验），避免半透明对话框下露馅。

6. 构建流程

mag_convert.py  PNG → MAG（--sprite / --256 / --reserved）
        │
pack_images.py  ASSETS.DB(img_map) → IMAGE.DAT
        │         （共享调色板量化 + remap + 后校验）
        ▼
makegame.sh build <game>  注入 HDI

精灵镜像由 char 命令位置参数隐式决定（l 左位自动镜像，c/r 不镜像），见 mc02 立绘与角色。

7. 与脚本命令的关系

  • bg 命令：加载背景 MAG → 设调色板 → 整屏 blit → 重绘精灵 → 恢复对话框底色(248) → 保存背景快照。调色板必须先于像素写入，否则闪烁。
  • char 命令：加载精灵 MAG → 只写像素（共享背景调色板）→ 透明索引 15 跳过。

命令语法详见 sc02-bg 背景切换 与 sc03-char 立绘与对话。
