pal：让颜色变化

创建：2026-08-29
最后更新：2026-08-29

pal 用于变色动画（开场设定里选了 palette 的那种）。它写出「这一次颜色要怎么变」，以及变完停留几秒。画面本身不动，只让颜色发生改变——很适合做灯光闪烁、魔法光晕、色调渐变。返回总览见 语法总览。

1. 怎么写

pal(停留秒数){色表昵称}
  • 括号里写一个数字（秒，可小数）。
  • 大括号里写这次变化用的色表文件昵称（一个色表描述「哪些颜色改成什么」）。可以写多个、用逗号分开，它们会轮流生效并共用同一个停留时间。

2. 色表文件（.pal）长什么样

色表是个很简单的文本文件，每行写一条「把某个编号的颜色，改成红绿蓝数值」：

# 灯光例子：把编号 0 改成红色，编号 15 改成黑色
0 255 0 0
15 0 0 0
  • 每行四个数字：编号 红 绿 蓝，数值都在 0–255 之间。
  • 行首加 # 是备注，会被忽略。
  • 同一个编号不要在一份色表里写两次。
  • 没被点名的颜色，就沿用上一步的样子（所以一连串 pal 是「在前一步基础上接着改」）。

3. 举个 galgame 里的例子

# 标题界面灯光：正常 → 暗 → 亮，来回呼吸
animaconf(cine,palette,标题流光)
base(){正常}
pal(0.2){暗}
pal(0.2){亮}

4. 写的时候注意

  • 只用在变色动画（开场设定选了 palette）。整图动画里写 pal 会报错。
  • 必须写在 base 之后（先有底图，再谈变化）。
  • 变色动画至少写一次 pal。
  • 色表昵称也要先 register 登记；色表文件格式写错（不是每行四个数字等）工具会报错。

5. 常见错误

  • 整图动画里误用了 pal → 改用 frame。
  • 把 pal 写在了 base 前面 → 把 base 放到最前。
  • 提示 .pal 格式错 → 检查每行是不是「编号 红 绿 蓝」四个数字、编号有无重复。
