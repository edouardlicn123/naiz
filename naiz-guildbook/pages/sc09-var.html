var 变量操作

创建：2026-07-27

var() 命令用于独立读写变量。变量定义见 cf01 变量系统。

1. 语法

var(id, op, value)
参数类型说明
idstring变量标识符（须在 variables.json 中定义）
opstring操作符：=（赋值）、+（加）、-（减）
valueint数值

2. 行为

  • = 将变量设为 value
  • + 将变量加上 value
  • - 将变量减去 value
  • 所有操作受 variables.json 中 min / max 限制，超出自动截断

3. 示例

var(bond_fei, +, 3)    # bond_fei += 3
var(bond_ira, =, 50)   # bond_ira = 50
var(bond_neon, -, 10)  # bond_neon -= 10
